## ก่อนซื้อหัวชาร์จ: ดู มอก. (ข้อมูลปี 2024)

<div class="split">
<div class="prose">

ตอนนี้ใครจะนำเข้าหัวชาร์จ หรือจริงๆ ต้องเรียกว่าอุปกรณ์เต้าเสียบทุกชนิด ต้องผ่านมาตรฐาน มอก. 62368 เล่ม 1-2563 ซึ่งตรงกับ IEC 62368-1 และมีผลบังคับใช้แล้ว (บังคับใช้ 17 ต.ค. 2566)

หากเลือกซื้อ Adapter สำหรับมือถือ ผมแนะนำเบื้องต้นดังนี้ครับ

1. ผ่านมาตรฐานอุตสาหกรรม (มอก.)
2. ตรวจสอบ มอก. ได้ผ่าน QR บนตัวผลิตภัณฑ์
3. รุ่นของ Adapter บนใบอนุญาตต้องตรงกับเอกสารที่ สมอ. (TISI) ออกให้

</div>

## รอบ 1: หัวชาร์จ RIZZ เทียบ GIZMO (ราคาปี 2024)

<div class="split">
<div class="prose">

เกณฑ์ทดสอบหัวชาร์จ: ชนิดวัสดุ ขนาด/น้ำหนัก ความนิ่งของกระแสไฟ เทคโนโลยีการชาร์จที่รองรับ และความปลอดภัย ให้คะแนนเต็ม 5 ราคาเท่ากัน (229 บาท) เลยไม่เป็นประเด็น

**RIZZ RWC-336G** จุดเด่นคือเล็ก เบา พกง่าย QR และสัญลักษณ์บนตัวใหญ่มาก สายที่แถมยาวถึง 1.5 เมตร มีสายรัด ข้อเสียคือสร้างความสับสน หัวชาร์จ Type C ที่รองรับ PD ปกติจะ 20W ส่วน Type A ปกติ 18W แต่ Packaging บอกเป็น Type A และสายที่แถมก็ดูไม่ออกว่าต้นทางเป็น Type ไหน คนอาจซื้อผิดได้ และยังไม่รองรับ Power Delivery

**GIZMO GA-021** ข้อดีหลักคือรองรับ PD และยังมีพอร์ต Type A ติดมาด้วย รวมสองพอร์ตในราคาเท่าคู่แข่ง ข้อเสียคือแถมสาย Type A เป็น Type C ซึ่งควรแถม C เป็น C จะได้ใช้ PD ได้ แต่ก็เข้าใจว่าถ้าแถมราคาอาจกระโดด และขาปลั๊กยื่นออกมา ตัวเลยยาวและใหญ่กว่า

**ความปลอดภัย** ทั้งสองตัวมีใบรับรองชัดเจน ตรวจผ่าน QR Code แล้วเป็นใบรับรองจริง ผมลนไฟแช็กที่ตัวหัวชาร์จ พลาสติกละลายและไม่ลุกลามต่อ

**สรุปของผม** ถ้าต้องการ Adapter ฉุกเฉิน พกง่าย ใช้ได้ 2 ช่อง ไม่มีสาย C เป็น C ก็ใช้ A เป็น C ได้ GIZMO จ่ายไฟตามโปรโตคอลได้เกินสเปกและนิ่งด้วย ผมแนะนำตัวนี้มากกว่าครับ ติดอย่างเดียว ถ้าแถมสาย C เป็น C มาด้วยจะดีมาก

</div>

## รอบ 8 (โบนัส): ชุดหัวชาร์จ Type A + สาย Lightning (179 บาททั้งคู่)

<div class="split">
<div class="prose">

อแดปเตอร์พร้อมสายชาร์จไอโฟน ที่พึ่งสุดท้ายยามลืมแล้วต้องหาซื้อ ทดสอบกับ iPhone 14 Pro ด้วยสายในกล่อง

**สรุปของผม** ราคาเท่ากัน ผมแนะนำ GIZMO เพราะได้ช่องชาร์จ 2 ช่อง และจ่ายไฟเต็ม 12W แต่ไม่ใช่ว่า Wealth ไม่ดีหรือไม่ได้มาตรฐาน ชาร์จได้ราว 8W ถือว่าผ่านเกณฑ์สำหรับหัวชาร์จ 10W แต่ถ้ามองประโยชน์ GIZMO เหนือกว่าแทบทุกด้าน

</div>
<div class="grade-grid">
  <article class="grade-card"><h3>Wealth TT1-L · 179 บาท</h3><p>วัสดุ 4 · ขนาด/น้ำหนัก 5 · ความนิ่ง 4 · เทคโนโลยี 2 · ปลอดภัย 5<br />มี มอก. ช่อง USB-A 1 ช่อง 5V/2A (10W) โปรโตคอล Apple 2.4A และ DCP 1.5A ชาร์จ iPhone 14 Pro ได้ <b>7.7–8.1W</b> สำหรับคนหา Adapter ฉุกเฉิน พอถูๆ ไถๆ ไปได้</p></article>

## สรุป

<div class="split">
<div class="prose">

สายชาร์จที่ผมลองในรอบนี้โอเคหมด ต่างกันที่ดีไซน์ ถ้าเป็นหัวชาร์จผมแนะนำ GIZMO เพราะได้ PD ด้วย แถมช่อง Type A ก็มี ราคาก็ถูก ส่วนตัวผมไม่ได้เชียร์ยี่ห้อไหนเป็นพิเศษ ของในเซเว่นก็ดีระดับนึง อาจไม่ดีสุด แต่จากที่ทดสอบโอเคระดับนึงเลย

ผมรีวิวเฉพาะของที่หาได้ตามเซเว่น เน้นราคาประหยัด เน้นสะดวกกรณีลืมสายหรือหัวชาร์จ ถ้า baseus, zmi, aukey, anker มีขายที่เซเว่นผมก็จะเอามารีวิวเหมือนกันครับ

**ชาร์จ iPad** ต้องใช้สาย C เป็น C ที่รองรับ PD และหัวชาร์จ PD อย่าง GIZMO GA-021 ที่ผมใช้ชาร์จ iPad อยู่ สาย A เป็น C ไม่ใช่ PD เลยไม่ไวเท่าของแท้

**ฉบับอื่น** ราคาและผลวัดแยกตามปี: <a href="/knowledge/seven-eleven-charging-cables-2018/">ฉบับปี 2018</a> · <a href="/knowledge/seven-eleven-charging-cables-2023/">ฉบับปี 2023</a>
