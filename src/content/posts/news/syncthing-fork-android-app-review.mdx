## Syncthing-Fork คืออะไร

<div class="split">
<div class="prose">

เริ่มจากตัวแม่ก่อนครับ Syncthing เป็นโปรแกรมซิงก์ไฟล์แบบเปิดซอร์ส ไม่มีเซิร์ฟเวอร์กลางเก็บไฟล์ของเรา ไฟล์วิ่งตรงระหว่างเครื่องที่เราอนุญาตเท่านั้น

หน้า F-Droid เขียนว่า Syncthing มาแทนบริการซิงก์และคลาวด์แบบปิด ด้วยของที่เปิด น่าเชื่อถือ และกระจายศูนย์ ข้อมูลเป็นของเราคนเดียว จะเก็บที่ไหน แชร์กับใคร ส่งยังไง เราเลือกเอง

Syncthing-Fork คือแอปที่ห่อ Syncthing ให้ใช้บน Android มีหน้าจอของแอปเอง ไม่ต้องเปิด Web GUI (หน้าตั้งค่าผ่านเบราว์เซอร์) ของ Syncthing

**ต้องรู้ก่อน:** แอปนี้ไม่ใช่บริการคลาวด์ครับ ลงเครื่องเดียวไม่มีประโยชน์ ต้องมี Syncthing อีกเครื่องให้ซิงก์ด้วย เช่น คอมพิวเตอร์ที่ลง Syncthing จาก <a href="https://syncthing.net/downloads/" rel="noopener">syncthing.net</a> หรือมือถือเครื่องที่สองที่ลง Syncthing-Fork

</div>
<figure class="split-fig"><img src="/media/posts/news/syncthing-fork-android-app-review/igv-1.jpg" width="1600" height="1613" loading="lazy" alt="อินโฟกราฟิกข้อมูลเร็ว ๆ ของ Syncthing-Fork สำหรับ Android ใช้ฟรี โอเพนซอร์ส MPL-2.0 ต้องใช้ Android 6.0 ขึ้นไปตามหน้า F-Droid รุ่นล่าสุด 2.1.7.0 วันที่ 21 ต.ค. 2569 บน GitHub ติดตั้งจาก F-Droid หรือ GitHub ซิงก์ตรงระหว่างเครื่อง ไม่ผ่านคลาวด์ ต้องมี Syncthing อีกฝั่ง" /></figure>
</div>

## Fork ของอะไร และต่างจากแอปทางการอย่างไร

<div class="prose">

ที่ชื่อมีคำว่า "Fork" เพราะแตกมาจากแอป Android ตัวทางการของ Syncthing ครับ (fork คือการก๊อปโค้ดโครงการเดิมมาพัฒนาต่ออีกสาย) ผมไล่ดูที่ต้นทางมาแล้ว เรื่องเป็นแบบนี้

<div class="news-cards">
<div class="news-card is-ok"><b>แอปทางการเลิกพัฒนาแล้ว</b>หน้า GitHub ของ <a href="https://github.com/syncthing/syncthing-android" rel="noopener">syncthing/syncthing-android</a> ขึ้นประกาศ "Discontinued" ไว้บนสุด รุ่นสุดท้ายบน GitHub กับ F-Droid คือ Syncthing เวอร์ชันธันวาคม 2567 และ repo ถูกเก็บถาวร (archived) แล้ว ผู้ดูแลให้เหตุผลว่า Google ทำให้การเผยแพร่บน Play ยากจนแทบเป็นไปไม่ได้ และไม่มีคนดูแลต่อ ประกาศนี้โพสต์ไว้ใน <a href="https://forum.syncthing.net/t/discontinuing-syncthing-android/23002" rel="noopener">ฟอรัมของ Syncthing</a> เมื่อ 20 ตุลาคม 2567</div>
<div class="news-card is-ok"><b>Syncthing-Fork แยกออกมาจากแอปนั้น</b>README ของ Fork เขียนว่า "forked from syncthing/syncthing-android" และขอบคุณอดีตผู้ดูแลอย่าง Catfriend1, imsodin และ nutomic มีหัวข้อ "Switching from the deprecated official version" ไว้ให้คนที่ย้ายมาจากแอปทางการด้วย</div>
<div class="news-card is-ok"><b>ยังอัปเดตอยู่</b>repo ตอนนี้อยู่ที่ <a href="https://github.com/researchxxl/syncthing-android" rel="noopener">github.com/researchxxl/syncthing-android</a> (ลิงก์เดิมของ Catfriend1 พามาที่นี่) ไม่ได้ถูกเก็บถาวร หน้า GitHub ขึ้นว่าอัปเดตล่าสุดเมื่อ 12 พฤศจิกายน 2569</div>
</div>

มีอีกเรื่องที่ควรรู้ ผมไม่เจอข้อความจากทีม Syncthing ที่รับรอง Fork นี้โดยตรง เอกสารของ Syncthing บอกไว้กว้าง ๆ แค่ว่ามี "community flavors" หลายแบบที่ใช้แกน Syncthing เดียวกัน พูดง่าย ๆ คือ Fork นี้เป็นโครงการของชุมชน ไม่ใช่แอปของทีม Syncthing ครับ

</div>

</section>

<ol class="news-steps">

## เริ่มใช้: จับคู่มือถือกับคอมพิวเตอร์ แล้วแชร์โฟลเดอร์

<div class="split">
<figure class="split-fig"><img src="/media/posts/news/syncthing-fork-android-app-review/igv-2.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกเริ่มใช้ 4 ขั้น จับคู่มือถือกับคอมพิวเตอร์ ขั้นที่ 1 ติดตั้ง Syncthing ทั้งสองเครื่อง ขั้นที่ 2 คัดลอก Device ID ของอีกเครื่อง หรือสแกน QR ขั้นที่ 3 Add Device ทั้งสองฝั่ง เลือกโฟลเดอร์ที่จะแชร์ ขั้นที่ 4 รอสักครู่ เครื่องเชื่อมกัน ไฟล์เริ่มซิงก์ ต้องทำทั้งสองฝั่ง ไม่งั้นไม่เชื่อมกัน" /></figure>
<div class="prose">

หัวใจของเรื่องนี้มีข้อเดียวครับ คู่มือทางการ (Getting Started) บอกว่า สองเครื่องจะคุยกันได้ก็ต่อเมื่อ **ทั้งสองเครื่องใส่ Device ID ของกันและกัน** Device ID คือรหัสประจำเครื่องที่สร้างตอนเปิดโปรแกรมครั้งแรก ไม่ต้องเก็บเป็นความลับ

ในภาพคือขั้นตอน 4 ข้อที่ผมสรุปไว้ รายละเอียดแต่ละข้ออยู่ข้างล่างนี้ครับ

<ol class="news-steps">
<li><b>ติดตั้งทั้งสองเครื่อง</b>ฝั่งคอมพิวเตอร์โหลดจาก <a href="https://syncthing.net/downloads/" rel="noopener">syncthing.net/downloads</a> มีทั้งตัวหลักสำหรับ Windows, macOS, Linux และตัวห่อสำหรับ Windows กับ macOS ที่ใช้ง่ายกว่า ส่วนมือถือลง Syncthing-Fork</li>
<li><b>ดู Device ID ของอีกเครื่อง</b>บนคอมพิวเตอร์ เปิดหน้า GUI ที่ http://127.0.0.1:8384 แล้วเลือก Actions → Show ID บนมือถือ เปิดเมนูข้างของแอปแล้วแตะ Show device ID</li>

<li><b>รอสักครู่</b>หลังบันทึก อุปกรณ์ใหม่จะขึ้นในรายการ ตอนแรกยังขึ้นว่าไม่ได้เชื่อมต่อ คู่มือบอกว่าจะเชื่อมกันภายในประมาณ 1 นาที ย้ำอีกทีว่าขั้นที่ 3 ต้องทำทั้งสองฝั่ง ทำฝั่งเดียวไม่เชื่อมครับ</li>

คู่มือเตือนไว้ด้วยว่า Syncthing เวอร์ชันที่เสริมฟังก์ชันของระบบ เช่นแอป Android อาจต้องเข้า Web GUI เพื่อเปิดซิงก์โฟลเดอร์หรือตั้งค่าบางอย่าง

## เทียบกับ LocalSend ที่แนะนำไปก่อนหน้านี้

<div class="prose">

ผมเคยแนะนำ <a href="/news/localsend-app-review/">LocalSend</a> ไปแล้ว สองแอปนี้ดูคล้ายกัน แต่จริง ๆ ทำคนละงานครับ

| | LocalSend | Syncthing-Fork |
|---|---|---|
| งานหลัก | ส่งไฟล์ครั้งเดียวหาเครื่องใกล้ ๆ | ซิงก์โฟลเดอร์ต่อเนื่องระหว่างเครื่องที่จับคู่ไว้ |
| ตั้งค่า | เปิดแอปทั้งสองเครื่อง ส่งได้เลย | จับคู่ด้วย Device ID ทั้งสองฝั่ง แล้วเลือกโฟลเดอร์ |
| เครือข่าย | Wi-Fi หรือ LAN วงเดียวกัน ไม่ต้องใช้อินเทอร์เน็ต | ใช้ในวงเดียวกันได้ และตามเอกสารมีเซิร์ฟเวอร์ค้นหา (discovery) ช่วยหาเครื่องที่อยู่นอกวง |
| ฝั่งที่ต้องลง | LocalSend ทั้งสองเครื่อง | Syncthing ทั้งสองเครื่อง |

ผมว่าถ้าแค่อยากส่งรูปไม่กี่ใบเข้าคอมตอนนี้เลย LocalSend ง่ายกว่า แต่ถ้าอยากให้โฟลเดอร์ เช่น รูปถ่ายหรือโน้ต ตรงกันเองทุกครั้งที่มีไฟล์ใหม่ Syncthing เหมาะกว่า แลกกับการตั้งค่าที่มากกว่าครับ
