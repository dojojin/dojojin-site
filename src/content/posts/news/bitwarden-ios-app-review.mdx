## Bitwarden คืออะไร

<div class="split">
<div class="prose">

Bitwarden เป็นแอปจัดการรหัสผ่านที่เปิดซอร์สโค้ดครับ ตามที่หน้า App Store อธิบาย

- เก็บรหัสผ่านและ passkey ไว้ในตู้นิรภัย (vault) ที่เข้ารหัสแบบ end-to-end
- มีตัวสร้างรหัสผ่าน และช่วยกรอกให้อัตโนมัติ
- ใช้ได้หลายเครื่อง

บน App Store ไทยดาวน์โหลดฟรี ผู้พัฒนาคือ Bitwarden Inc หน้าร้านเขียนว่าใช้ Bitwarden ฟรีได้ โดยไม่มีโฆษณาและไม่ขายข้อมูล ส่วนแผน Premium มีฟีเจอร์ขั้นสูงเพิ่ม

ซอร์สโค้ดแอป iOS อยู่บน <a href="https://github.com/bitwarden/ios" rel="noopener">GitHub</a> ไลเซนส์ GPL-3.0 ครับ

</div>
<figure class="split-fig"><img src="/media/posts/news/bitwarden-ios-app-review/igv-1.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกข้อมูลเร็ว ๆ ของ Bitwarden บน iPhone ฟรี ไม่มีโฆษณาและไม่ขายข้อมูลตามที่ App Store ระบุ ซอร์สโค้ดแอป iOS ไลเซนส์ GPL-3.0 บน GitHub รุ่น 2026.10.1 วันที่ 29 ต.ค. 2569 ต้องใช้ iOS 15.0 ขึ้นไป และใช้ได้บน iPad กับ Apple Watch" /></figure>
</div>

## หน้าตาและวิธีใช้

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/bitwarden-ios-app-review/img-1.jpg" width="738" height="1600" loading="lazy" alt="ภาพหน้าจอ Bitwarden บน iPhone หน้า My vault แสดงช่องค้นหา ประเภทรายการ Login, Card, Identity, Secure note และ SSH key พร้อมรายการ Apple, AWS, Github และแถบเมนู My vault, Send, Generator, Settings มีข้อความ Secure your digital life and protect from breaches" /></div><figcaption><span class="news-fig__credit">ภาพ: Bitwarden Inc (ภาพจาก App Store) · <a href="https://apps.apple.com/th/app/bitwarden-password-manager/id1137397744" rel="noopener">apps.apple.com</a></span></figcaption></figure>
<div class="prose">

หน้าแรกคือ My vault ครับ ในภาพมีช่องค้นหาอยู่บนสุด ตามด้วยรายการแยกตามประเภท คือ Login, Card, Identity, Secure note และ SSH key ถัดลงมาเป็นรายการที่ยังไม่อยู่ในโฟลเดอร์ เช่น Apple, AWS และ Github มุมขวาล่างมีปุ่มบวกสีน้ำเงิน

แถบเมนูล่างมีสี่แท็บ คือ My vault, Send, Generator และ Settings ตามคำอธิบายบน App Store ยังมี Bitwarden Send ไว้ส่งข้อมูลให้คนอื่นแบบเข้ารหัส และจำกัดการเปิดเผยได้

</div>
</div>

<div class="split">
<div class="prose">

แท็บ Generator สร้างรหัสผ่านยาว ๆ ให้ครับ ในภาพ

- เลือกได้สามแบบ Password, Passphrase และ Username
- เลื่อนแถบ Length ได้ (ในภาพตั้ง 18 ตัว)
- เลือกว่าจะใช้ A-Z, a-z, 0-9 หรือไม่
- ตั้งจำนวนอักขระพิเศษกับตัวเลขขั้นต่ำได้

ได้รหัสที่ถูกใจแล้วกด Copy

App Store บอกว่าตัวสร้างนี้ช่วยทำรหัสผ่านและชื่อผู้ใช้ที่ไม่ซ้ำกันสำหรับทุกเว็บ ผมว่าข้อดีที่ชัดที่สุดคือไม่ต้องใช้รหัสเดียวทุกที่อีกแล้วครับ

</div>

## กรอกรหัสอัตโนมัติและสแกนใบหน้า

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/bitwarden-ios-app-review/img-3.jpg" width="738" height="1600" loading="lazy" alt="ภาพหน้าจอ iPhone หน้า Sign in to GitHub ช่องอีเมลและรหัสผ่านถูกกรอกแล้ว และแถบเหนือคีย์บอร์ดมีข้อความ for github.com Bitwarden พร้อมอีเมลที่เลือกได้ มีข้อความ Quickly autofill logins and use passkeys for websites" /></div><figcaption><span class="news-fig__credit">ภาพ: Bitwarden Inc (ภาพจาก App Store) · <a href="https://apps.apple.com/th/app/bitwarden-password-manager/id1137397744" rel="noopener">apps.apple.com</a></span></figcaption></figure>
<div class="prose">

ในภาพเป็นตอนล็อกอินเว็บ GitHub ครับ แถบเหนือคีย์บอร์ดขึ้นข้อความ "for github.com — Bitwarden" พร้อมอีเมลที่บันทึกไว้ แตะแล้วช่องอีเมลกับรหัสผ่านจะถูกกรอกให้เลย

App Store เขียนว่ากรอกล็อกอินอัตโนมัติและใช้ passkey กับเว็บได้ ส่วนบันทึกรุ่น 2026.4.0 บอกว่าแอปชวนเปิด Bitwarden เป็น credential provider (ตัวกรอกรหัสผ่านอัตโนมัติของ iOS) ได้จากในแอปเลย ไม่ต้องไปงมในตั้งค่าครับ

</div>
</div>

<div class="split">
<div class="prose">

ปลดล็อกแอปด้วย master password หรือใช้ชีวมิติอย่าง Face ID ก็ได้ครับ ในภาพคือหน้าล็อกที่มีไอคอน Face ID กับปุ่ม Unlock

เรื่องความปลอดภัย ผมสรุปตามที่หน้าร้าน App Store เขียนไว้ครับ

- เข้ารหัสด้วย AES-256 bit, salted hashing และ PBKDF2 SHA-256
- ตรวจสอบโดยบริษัทภายนอกทุกปี
- รองรับการยืนยันสองขั้น เช่น แอป authenticator, รหัสทางอีเมล หรือกุญแจ FIDO2

</div>
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/bitwarden-ios-app-review/img-4.jpg" width="738" height="1600" loading="lazy" alt="ภาพหน้าจอ Bitwarden หน้าล็อกที่มีไอคอน Face ID ซ้อนอยู่ ช่อง Master password และปุ่ม Unlock พร้อมข้อความ Secured by biometrics and world-class encryption" /></div><figcaption><span class="news-fig__credit">ภาพ: Bitwarden Inc (ภาพจาก App Store) · <a href="https://apps.apple.com/th/app/bitwarden-password-manager/id1137397744" rel="noopener">apps.apple.com</a></span></figcaption></figure>

## ฟรีกับ Premium ต่างกันตรงไหน

<div class="split">
<figure class="split-fig"><img src="/media/posts/news/bitwarden-ios-app-review/igv-2.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกเทียบฟรีกับ Premium ของ Bitwarden แบบฟรีตาม App Store รหัสผ่านและ passkey ไม่จำกัด ใช้ได้หลายเครื่อง มี Send และตัวสร้างรหัสผ่าน ส่วน Premium ตามหน้าราคาบนเว็บ 19.80 ดอลลาร์ต่อปี คิดรายปี ราคาสหรัฐฯ เพิ่มตัวสร้างรหัส 2FA ในแอป การแนบไฟล์ และการเข้าถึงฉุกเฉิน" /></figure>
<div class="prose">

**แบบฟรี** คำอธิบายบน App Store ไทยบอกว่า

- รหัสผ่านและ passkey เก็บได้ไม่จำกัด
- ใช้ได้ไม่จำกัดจำนวนอุปกรณ์
- มี Send กับตัวสร้างรหัสผ่านในตัว

**แผน Premium** ตามหน้าราคาบนเว็บ bitwarden.com คิด 19.80 ดอลลาร์ต่อปี (ประมาณ 1.65 ดอลลาร์ต่อเดือน คิดรายปี เป็นราคาที่หน้าเว็บแสดง ไม่ใช่ราคาเงินบาท) ฟีเจอร์ที่เพิ่มมามี

- ตัวสร้างรหัส 2FA ในแอป
- การแนบไฟล์
- การเข้าถึงฉุกเฉิน

รุ่น 2026.6.0 เพิ่มหน้าจัดการสมาชิกในแอปด้วย ส่วนราคาในบาท ดูที่หน้าสมัครในแอปอีกทีครับ

</div>
</div>

</section>

## รุ่นล่าสุด 2026.10.1

<div class="prose">

รุ่นล่าสุดบน App Store ไทยคือ **2026.10.1** วันที่ 29 ตุลาคม 2569 (GitHub ลงรุ่น v2026.10.1-bwpm วันเดียวกัน) หน้า App Store บอกว่ารุ่นนี้

- ปรับ VoiceOver และการใช้คีย์บอร์ดนำทางให้ดีขึ้น
- แก้ช่องที่กรอกอัตโนมัติแล้วว่างเปล่า หลังปลดล็อกด้วย Face ID
- แก้คำขอล็อกอินที่ไม่ขึ้น เมื่อปิดการแจ้งเตือน

ย้อนดูรุ่นก่อน ๆ ในไม่กี่เดือนมานี้ ก็มีของใหม่ทยอยมาเรื่อย ๆ ครับ

- 2026.8.1 ดูและจัดการอุปกรณ์ที่ล็อกอินอยู่
- 2026.7.0 บันทึกรหัสผ่านจากแอปและเว็บเพื่อกรอกอัตโนมัติ
- 2026.5.1 สแกนบัตรชำระเงินด้วยกล้อง

ส่วนข้อมูลความเป็นส่วนตัวบน App Store ผู้พัฒนาแจ้งเองว่าอาจเก็บ

- อีเมลและรหัสอุปกรณ์ (ผูกกับตัวตน)
- ชื่อและข้อมูลแครช (ไม่ผูกกับตัวตน)

ข้อมูลส่วนนี้ Apple ยังไม่ได้ตรวจสอบครับ
