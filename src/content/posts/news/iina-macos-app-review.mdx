## IINA คืออะไร

<div class="split">
<div class="prose">

IINA เป็นเครื่องเล่นวิดีโอและเพลงบน macOS ครับ หน้าแรกของเว็บเขียนไว้ว่า "The modern media player for macOS" แปลว่าเครื่องเล่นมีเดียยุคใหม่สำหรับ macOS

เว็บทางการบอกว่าออกแบบมาให้เข้ากับระบบ รองรับท่าทางบนทัชแพด ปุ่มควบคุมมีเดีย ภาพซ้อนภาพ (Picture in Picture) และ Live Text (เลือกข้อความในภาพนิ่งได้)

แล้วเบื้องหลังใช้อะไร? คือ mpv ครับ mpv เป็นเครื่องเล่นโอเพนซอร์สที่ทำหน้าที่ถอดรหัสไฟล์ภาพและเสียง ทีม IINA เขียนไว้ในหน้า GitHub ว่า mpv ถอดรหัสบน macOS ได้ดีที่สุด

พูดง่าย ๆ คือ mpv เป็นเครื่องยนต์ ส่วน IINA เป็นหน้าตาที่ทำมาให้ใช้ง่ายบนเครื่องยนต์ตัวนั้น

ผมว่าเหมาะกับคนที่อยากได้เครื่องเล่นที่ตั้งค่าได้เยอะ แต่ไม่อยากไปจัดการ mpv ผ่านไฟล์ตั้งค่าเองครับ

</div>

## ทำอะไรได้บ้าง

<div class="prose">

หน้า GitHub ไล่ฟีเจอร์ไว้ตามนี้ครับ

- เล่นได้ทั้งวิดีโอและเพลง มีคำบรรยาย (subtitle) เพลย์ลิสต์ และบท (chapter)
- มี Music Mode แยกต่างหาก ออกแบบมาสำหรับไฟล์เสียงโดยเฉพาะ
- ภาพตัวอย่างบนแถบเลื่อนเวลา (video thumbnails)
- ค้นหาคำบรรยายออนไลน์ และจับคู่ไฟล์คำบรรยายในเครื่องให้อัตโนมัติ
- เก็บประวัติการเล่นได้ไม่จำกัด
- ปรับตัวกรองภาพและเสียงผ่านหน้าจอได้เลย
- ตั้งค่าได้ทั้งคีย์บอร์ด เมาส์ ทัชแพด และท่าทาง
- ปรับสีหน้าต่างและตำแหน่งแถบควบคุมบนจอ (on screen controller) ได้
- คนที่ใช้ mpv อยู่แล้ว ใช้ไฟล์ตั้งค่าและสคริปต์ของ mpv ต่อได้
- มีเครื่องมือบรรทัดคำสั่ง (สั่งงานผ่าน Terminal) และส่วนเสริมสำหรับเบราว์เซอร์

เว็บทางการยังเน้นว่าไม่มีการติดตามผู้ใช้หรือเก็บข้อมูลการใช้งาน (tracking, telemetry) ครับ

</div>

## 1.5.0 ปรับหน้าตาใหม่หมด

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/iina-macos-app-review/img-2.jpg" width="1600" height="693" loading="lazy" alt="แผงควบคุมของ IINA แสดงตัวเลือก Compact Interface, Delay, Equalizer 10 แบนด์, Aspect Ratio, Crop, Rotation, Scale ตัวอักษรคำบรรยาย, Theme Dark Light Auto, Liquid Glass, ปุ่มเปิดปิด OSD OSC และ Sidebar, ความสว่าง คอนทราสต์ และความเร็วการเล่น" /></div><figcaption><span class="news-fig__credit">ภาพ: IINA · <a href="https://iina.io" rel="noopener">iina.io</a> (ภาพหน้าจอจากเว็บไซต์ทางการ วางบนพื้นสีโดย DOJOJIN.TECH)</span></figcaption></figure>
<div class="prose">

IINA 1.5.0 ออกวันที่ 28 กันยายน 2569 ครับ บล็อกของทีมเรียกว่าเป็นการปรับหน้าตาครั้งใหญ่ที่สุดนับตั้งแต่เปิดตัว และบอกว่าใช้เวลาทำเกือบหนึ่งปี

เปลี่ยนอะไรบ้าง? ตามนี้ครับ

- **ย่อขยายหน้าต่างได้อิสระ** มีแถบ Layout ให้ปรับหน้าตาขณะดูวิดีโอ และล็อกสัดส่วนหน้าต่างได้ทั้งจากแถบนี้และเมนู
- **แถบข้างซ้ายและขวาแสดงพร้อมกันได้** เช่น เพลย์ลิสต์ทางซ้าย ตั้งค่าทางขวา และตรึงแถบข้างหรือแถบควบคุมให้เห็นตลอดได้ ใกล้เคียงเครื่องเล่นแบบดั้งเดิมอย่าง VLC (เครื่องเล่นโอเพนซอร์สที่คนใช้กันเยอะ)
- **หน้าตั้งค่าเขียนใหม่ทั้งหน้า** เน้นให้เห็นข้อมูลในหน้าเดียว ไม่ซ่อนในเมนูย่อย
- **Compact Interface** ถ้าชอบความแน่นแบบรุ่นเก่า เปิดตัวเลือกนี้ได้
- **Liquid Glass** (ดีไซน์โปร่งแสงแบบกระจกของ Apple) รองรับบน macOS 26 และ 27 เปิดแยกได้ทั้ง OSD (ข้อความที่ขึ้นบนจอ เช่น ระดับเสียง), แถบควบคุม และแถบข้าง

ในภาพคือแผงควบคุมที่ใช้ปรับขณะเล่นครับ มีดีเลย์คำบรรยาย อีควอไลเซอร์ อัตราส่วนภาพ ธีม และความเร็วการเล่น

</div>

## ปลั๊กอินเสริม

<div class="split">
<div class="prose">

IINA มีระบบปลั๊กอินครับ เว็บทางการบอกว่าปลั๊กอินช่วยเพิ่มแหล่งคำบรรยาย เครื่องมือจัดการวิดีโอ หน้าจอใหม่ และฟีเจอร์อื่น ๆ ที่ชุมชนทำขึ้นมาได้

หน้า GitHub แยกปลั๊กอินเป็น 2 กลุ่มครับ

<div class="news-cards">
<div class="news-card is-ok"><b>ปลั๊กอินทางการ 3 ตัว</b>Online Media (ช่วยเล่นและดาวน์โหลดจากสตรีมออนไลน์), OpenSubtitles (ค้นหาและโหลดคำบรรยาย) และ User Scripts (รันโค้ด JavaScript สั้น ๆ ที่เขียนเอง)</div>
<div class="news-card is-ok"><b>ปลั๊กอินจากชุมชน</b>เลือกติดตั้งได้จากร้านปลั๊กอินในแอป ที่ Settings → Plugins</div>
</div>

ในภาพจะเห็นว่ามีช่องให้ใส่ลิงก์ GitHub เองได้ด้วย ผมว่าถ้าเป็นปลั๊กอินที่ไม่รู้จัก ควรดูก่อนว่าใครเป็นคนทำนะครับ

</div>

## วิธีติดตั้ง

<div class="prose">

ติดตั้งได้ 2 ทางครับ

<ol class="news-steps">
<li><b>โหลดไฟล์ DMG</b>DMG คือไฟล์ติดตั้งแบบดิสก์อิมเมจของ Mac โหลดจากปุ่ม Download ที่ <a href="https://iina.io" rel="noopener">iina.io</a> หรือจากหน้า <a href="https://github.com/iina/iina/releases/latest" rel="noopener">GitHub Releases</a> ไฟล์รุ่น 1.5.1 ชื่อ IINA.v1.5.1.dmg</li>
<li><b>ลากไปไว้ใน Applications</b>เปิดไฟล์ DMG แล้วลากแอป IINA ไปไว้ในโฟลเดอร์ Applications</li>
<li><b>หรือใช้ Homebrew</b>Homebrew คือโปรแกรมติดตั้งแอปด้วยคำสั่งบน Mac เปิดแอป Terminal แล้วพิมพ์ <code>brew install --cask iina</code> (cask คือสูตรติดตั้งแอปแบบมีหน้าตาของ Homebrew ตอนนี้มี cask ชื่อ iina รุ่น 1.5.1 ในรายการ)</li>
</ol>

มีรุ่นทดลอง (nightly) ให้โหลดด้วย แต่ทีมเตือนไว้ว่ารุ่นนี้สร้างอัตโนมัติทุกครั้งที่แก้โค้ด อาจมีบั๊กจนใช้ไม่ได้ ใช้งานทั่วไปผมว่าโหลดรุ่นปกติดีกว่าครับ

</div>

</section>
