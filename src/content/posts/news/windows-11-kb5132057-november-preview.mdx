## สรุปสั้น ๆ

<div class="prose">

วันที่ 19 พฤศจิกายน 2569 Microsoft ปล่อยอัปเดตแบบ **พรีวิว** KB5132057 ให้ Windows 11 เวอร์ชัน 26H2 และ 25H2 ครับ อัปเดตพรีวิวคือชุดแก้บั๊กกับฟีเจอร์ใหม่ ยังไม่ใช่แพตช์ความปลอดภัยประจำเดือน ใครอยากลองก่อนกดติดตั้งเองได้ ส่วนคนที่ไม่กดจะได้ของชุดนี้ในอัปเดตความปลอดภัยรอบหน้า

<div class="news-stats">
<div class="news-stat"><b>26300.10075</b>บิลด์ของ 26H2</div>
<div class="news-stat"><b>26200.10075</b>บิลด์ของ 25H2</div>
<div class="news-stat"><b>19 พ.ย.</b>วันที่ปล่อย ปี 2569</div>
</div>

ก่อนไปตามหาฟีเจอร์ในเครื่อง ต้องรู้ก่อนว่าหน้า KB ของ Microsoft แบ่งของใหม่เป็น 2 กลุ่มครับ

<div class="news-cards">
<div class="news-card is-warn"><b>ทยอยปล่อย (gradual rollout)</b>ฟีเจอร์ใหม่ส่วนใหญ่อยู่กลุ่มนี้ Microsoft เปิดให้เป็นรอบ ๆ ลงอัปเดตแล้วก็อาจยังไม่เห็น</div>
<div class="news-card is-ok"><b>ปล่อยปกติ (normal rollout)</b>เป็นการแก้บั๊ก เช่น Miracast ที่ตกไปใช้ความละเอียดต่ำ, passkey ข้ามอุปกรณ์บน Android ที่ขึ้น error และหน้ากู้คืนของ File History กลุ่มนี้ทุกเครื่องที่ลงอัปเดตจะได้เลย</div>
</div>

</div>

</section>

<section class="section">

## หน้าค้นหาใหม่ และดูไฟล์ได้ในผลลัพธ์

<div class="split">
<div class="prose">

Microsoft บอกว่าหน้าค้นหาใหม่แสดงผลเป็น "ลิสต์เดียวแบบเรียบง่าย" อ่านง่ายขึ้น และกินหน่วยความจำน้อยลง ดูจากภาพของ Microsoft จะเห็นไฟล์ แอป และการตั้งค่าที่เพิ่งใช้เรียงอยู่ในลิสต์เดียวกัน

จุดที่ผมว่าน่าสนใจคือ **inline action** ครับ สั่งงานบางอย่างจากช่องค้นหาได้เลย ไม่ต้องเข้า Settings เช่น เปิดโหมดมืด เปิด Bluetooth ปรับความสว่างจอ ปิดเสียง หรือจัดหน้าต่างที่เปิดอยู่ ถ้าต่อมือถือ Android ไว้กับ Phone Link ก็โทรออก ส่งข้อความ สั่ง Find my phone หรือ Do Not Disturb ได้จากตรงนี้

**ข้อจำกัด:** Microsoft บอกว่าหน้าค้นหาใหม่ "เริ่มที่ภาษาอังกฤษก่อน" ส่วนภาษาไทยยังไม่มีข้อมูลว่าจะมาเมื่อไรครับ

</div>

</div>

<div class="prose">

ในผลลัพธ์ยัง **ดูตัวอย่างไฟล์** ได้ทันที พร้อมรายละเอียดอย่างวันที่แก้ไขล่าสุด ที่เก็บไฟล์ และชื่อคนสร้าง ถ้าอยากรู้คำตอบสั้น ๆ เรื่องอากาศ หุ้น หรือข้อเท็จจริงทั่วไป ก็ถามจากช่องค้นหาได้โดยไม่ต้องเปิดเบราว์เซอร์ และ Microsoft บอกว่าระบบเข้าใจคำที่พิมพ์ผิดกับคำพ้องความหมายได้ดีขึ้น

ภาพนี้เป็นตัวอย่างจาก Microsoft ไฟล์พรีเซนเทชัน เอกสาร Word และรูปถ่ายขึ้นตัวอย่างให้ดูในหน้าค้นหาเลยครับ ใครค้นไฟล์งานบ่อยน่าจะชอบ

## Run dialog ใหม่ และของอื่นในอัปเดตนี้

<div class="split">
<div class="prose">

**Run dialog** (กล่องที่เรียกด้วยปุ่ม Windows + R) ได้หน้าตาใหม่ที่ทันสมัยและใช้ง่ายขึ้นครับ แต่ **ระบบไม่เปิดให้เอง** ต้องไปที่ Settings > System > Advanced แล้วเปิด New Run dialog

ภาพนี้มาจากบล็อกของ Microsoft ตอนแนะนำดีไซน์ใหม่ (พ.ค. 2569) ยังไม่ได้ยืนยันว่าหน้าตาจริงในบิลด์นี้ตรงกับภาพทุกจุดหรือเปล่า

</div>
<figure class="news-fig"><div class="news-fig__img"><img src="/media/posts/news/windows-11-kb5132057-november-preview/photo-3.jpg" width="1132" height="332" loading="lazy" alt="ภาพ Run dialog แบบใหม่ของ Windows 11 เป็นแถบยาวเหนือ Taskbar มีช่องพิมพ์ชื่อคำสั่งและปุ่ม Run" /></div><figcaption><span class="news-fig__credit">ภาพ: Microsoft (Windows Command Line blog, 1 พ.ค. 2569) · <a href="https://devblogs.microsoft.com/commandline/wp-content/uploads/sites/33/2026/04/runDialogLightBackground.webp" rel="noopener">ไฟล์ต้นฉบับ</a></span></figcaption></figure>
</div>

<div class="prose">

ส่วนฟีเจอร์อื่นในกลุ่มทยอยปล่อย หน้า KB ของ Microsoft ลงไว้ตามนี้ครับ

<div class="news-cards">
<div class="news-card"><b>Windows Hello เพิ่มแสงจอตอนสแกนหน้า</b>เพิ่มความสว่างหน้าจอชั่วคราวตอนสแกนหน้าในห้องมืด ต้องเปิดเองที่ Settings > Accounts > Sign-in options > Facial recognition แล้วติ๊ก Automatically adjust screen brightness during face recognition</div>
<div class="news-card"><b>ค้นหาจาก This PC ใน File Explorer เร็วขึ้น</b>ใช้ตัวทำดัชนี (indexer) แบบเดียวกับการค้นจากหน้า Home</div>
<div class="news-card"><b>โหมด XBOX: Quick settings ใน Task View</b>เปิด Quick settings ชุดเต็มแบบเดียวกับบน Taskbar ได้จาก Gaming Task View โดยไม่ต้องออกจากโหมด XBOX</div>
<div class="news-card"><b>Pointer indicator สำหรับคนสายตาเลือนราง</b>เปิดใช้ที่ Settings > Accessibility > Mouse pointer and touch แล้วกด Windows + Ctrl + Shift + X เพื่อเปิดหรือปิด อัปเดตนี้ยังลดอาการเคอร์เซอร์หน่วงตอนจับภาพหน้าจอ เช่นตอนสตรีมเกม</div>
<div class="news-card"><b>ของเล็ก ๆ</b>กรอบจับภาพหน้าจอเปลี่ยนจากสีเหลืองเป็นสีแดง, แจ้งเตือนเมื่อมีวิดเจ็ตใหม่หลังลงแอป, Live captions เลือกได้ว่าจะถอดเสียงจากระบบ ไมค์ หรือทั้งสองอย่าง, Magnifier มีเมนูช่วยเหลือ, Narrator อ่านสูตรคณิตศาสตร์ได้อีก 8 ภาษา</div>
</div>

</div>

</section>

<section class="section">

## วิธีติดตั้ง

<div class="prose">

ตามหน้า KB ของ Microsoft คนทั่วไปลงผ่าน Windows Update ได้เลยครับ อัปเดตนี้เป็นแบบเลือกลงเอง ระบบไม่ลงให้อัตโนมัติ

<ol class="news-steps">
<li>เปิด Start แล้วไปที่ Settings > Windows Update</li>
<li>เลือก Advanced options > Optional updates</li>
<li>ในส่วน Optional updates available จะมีลิงก์ดาวน์โหลดและติดตั้งให้กด</li>
</ol>

ลงแล้วยังไม่เห็นฟีเจอร์ก็ไม่ได้แปลว่าลงผิดนะครับ ฟีเจอร์ส่วนใหญ่ทยอยปล่อย และบางตัวต้องไปเปิดเอง อย่าง New Run dialog กับตัวเลือกความสว่างของ Windows Hello

</div>

## ปัญหาที่ Microsoft แจ้งไว้ และข้อควรรู้

<div class="prose">

<div class="news-cards">
<div class="news-card is-warn"><b>SQL Server linked server ค้างการเชื่อมต่อ</b><span class="news-pill">เครื่องเซิร์ฟเวอร์</span> เครื่องที่ลงอัปเดตตั้งแต่รอบ 13 ต.ค. 2569 เป็นต้นมา การเชื่อมต่อไปยังฐานข้อมูลภายนอก (เช่น Oracle, PostgreSQL) อาจค้างสะสมจนเซิร์ฟเวอร์ช้าลง Microsoft บอกว่ากำลังแก้อยู่ ระหว่างนี้คนดูแลระบบองค์กรต้องติดต่อ Microsoft Support</div>
<div class="news-card"><b>ไม่มีอัปเดตพรีวิวเดือนธันวาคม</b>Microsoft ประกาศว่าเดือนหน้าจะไม่มีอัปเดตพรีวิว แล้วกลับมาตามรอบปกติในเดือนมกราคม (ผมเขียนเรื่องนี้ไว้แล้วใน <a href="/news/windows-november-2026-changes/">Windows พ.ย. 2569 มีอะไรอีกนอกจาก Patch Tuesday</a>)</div>

อีกเรื่องคือ หน้า KB ระบุว่าอัปเดตนี้ใช้กับ Windows 11 เวอร์ชัน 26H2 และ 25H2 เท่านั้น ไม่ได้พูดถึงเวอร์ชันอื่น
