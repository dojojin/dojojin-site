## เกิดอะไรขึ้น

<div class="prose">

**Satya Nadella** ซีอีโอ Microsoft ให้สัมภาษณ์กับ **Gergely Orosz** ในรายการ *The Pragmatic Engineer* (เผยแพร่ 16 พฤศจิกายน 2569) โดยเล่าถึงจุดเปลี่ยนของเครื่องมือพัฒนาซอฟต์แวร์ครับ

แม้ Microsoft จะมี VS Code และ GitHub Copilot และไล่ตาม Cursor ในโหมด **AI agent** (ระบบ AI ที่รับเป้าหมายแล้วลงมือแก้ไฟล์ รันทดสอบ และทำงานหลายขั้นตอนได้เอง) ได้ทัน แต่สิ่งที่ทำให้บริษัทตั้งตัวไม่ทันคือการที่ Anthropic เปิดตัว **Claude Code** เมื่อ 24 กุมภาพันธ์ 2568 และดึงงานเขียนโค้ดมาอยู่บน **Terminal / CLI** (Command-Line Interface — หน้าจอพิมพ์คำสั่งแบบข้อความ)

Nadella เล่าว่าเมื่อโมเดล AI ก้าวกระโดดแบบไม่เป็นเส้นตรง รูปแบบเครื่องมือต้องเปลี่ยนเร็วตามไปด้วย พร้อมเตือนตัวเองว่า `"Don't be in love with what you built."` ("อย่าหลงรักสิ่งที่ตัวเองสร้างไว้") และตอบพิธีกรที่พูดถึงช่วงราว 6 เดือนว่า `"IDEs kind of faded away"` ("โปรแกรม **IDE** — Integrated Development Environment หรือเครื่องมือแก้ไขโค้ดและจัดการโปรเจกต์ครบวงจรอย่าง VS Code — ก็ค่อย ๆ จางหายไป") จากเวิร์กโฟลว์หลักของนักพัฒนาหลายคนครับ

</div>

## ทิศทางใหม่ของ IDE และจุดที่ยังแก้ไม่ตก

<div class="split">
<div class="prose">

แต่ Nadella มองว่านี่ไม่ใช่จุดจบถาวรของ IDE ครับ เขาพูดถึงโอกาสที่ `"there could be a rebirth even of an IDE"` ("อาจเห็นการเกิดใหม่ของ IDE ด้วยซ้ำ") โดยหน้าตาใหม่จะเปลี่ยนจากการนั่งพิมพ์โค้ดทีละบรรทัด ไปเป็นพื้นที่สำหรับป้อนสเปก จัดการไฟล์ **Markdown** (รูปแบบไฟล์ข้อความธรรมดาที่จัดหัวข้อและรายการได้ง่าย นิยมใช้อธิบายข้อกำหนดงานให้ AI) รอบระบบ software factory (โรงงานซอฟต์แวร์ที่ใช้ AI) ของทีม

ส่วนปัญหาใหญ่ที่สุดตอนนี้ Nadella ชี้ชัดว่า `"In a world where code generation has become cheap, what has become hard is verification"` ("ในโลกที่การสร้างโค้ดมีราคาถูกลง สิ่งที่กลายเป็นเรื่องยากคือการ **verification** — การตรวจสอบยืนยันว่าโค้ดทำงานถูกต้องและปลอดภัยจริง") เพราะถ้าให้โมเดลตรวจงานกันเอง อาจเจออาการบิดเบือนเป้าหมาย เช่น แอบลบชุดทดสอบที่พังเพื่อให้ผลเทสต์ขึ้นว่าผ่านครับ

Microsoft จึงหันไปเน้นใช้หลายโมเดลคู่กัน ทั้งโมเดลบนเครื่องพีซีกับคลาวด์ผ่านตัวจัดเส้นทางอย่าง Copilot Fusion

ภาพรวมในตลาดก็สอดคล้องกับสิ่งที่ Nadella เล่า ข้อมูลจากแบบสำรวจนักพัฒนาของ Stack Overflow ประจำปี 2569 (เผยแพร่ 6 ตุลาคม 2569) ระบุว่า Claude Code ครองสัดส่วนผู้ใช้สูงสุดในกลุ่ม coding agent ที่ 66% ตามด้วย GitHub Copilot ที่ 59% ขณะที่นักพัฒนา 84.3% ยังคงใช้ IDE ร่วมกับการทำงานอยู่

ด้าน Microsoft เองก็ออกอัปเดต VS Code 1.147 เมื่อ 18 พฤศจิกายน 2569 เพิ่มตัวจัดเส้นทางเลือกโมเดลอัตโนมัติ (ฟีเจอร์ทดลอง) หน้าจอ Inbox รวมงานของ agent (ฟีเจอร์ทดลอง) และเปิดให้องค์กรที่ตั้งค่าคุมผ่าน managed settings ของ Copilot ใช้ harness (ชุดตัวคุมการทำงานและเครื่องมือของ agent) ของ Claude กับ Codex ภายใน VS Code ร่วมกับ Copilot ได้

## นักพัฒนาในไทยควรจับตาอะไร

<div class="prose">

ฝั่ง Microsoft ยังไม่ได้ประกาศนโยบายหรือราคาที่เจาะจงสำหรับตลาดไทย แต่สำหรับนักพัฒนาในไทยที่ใช้ VS Code, GitHub Copilot หรือ Claude Code อยู่แล้ว ผลกระทบที่เห็นชัดคือเครื่องมือฝั่ง IDE กำลังปรับตัวมาเป็นห้องควบคุม agent แทนการบังคับใช้โมเดลเดียว ทำให้ VS Code เลือกใช้ agent ได้ทั้ง Copilot, Claude และ Codex ตามงานที่ถนัด

ผมว่าประเด็นที่น่าเอาไปใช้จริงที่สุดจากบทสัมภาษณ์นี้คือเรื่องการตรวจสอบโค้ดครับ (ข้อนี้เป็นความเห็นผม) ต่อให้ AI agent ช่วยเขียนโค้ดใน Terminal ได้เร็วขึ้นแค่ไหน นักพัฒนาในไทยยังต้องวางระบบเทสต์ รีวิวโค้ดส่วนสิทธิ์การเข้าถึง ฐานข้อมูล และการจ่ายเงินให้รัดกุมก่อนขึ้นระบบจริงเสมอ
