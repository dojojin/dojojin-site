## เปลี่ยนแปลงอะไรใน ChatGPT รอบนี้

<div class="split">
<div class="prose">

หน้าช่วยเหลือของ OpenAI (และ iPhoneMod สื่อไทย) ระบุว่า OpenAI จะรวมหน้าต่าง **Chat** และ **Work** (รวมถึงการทำงานสาย Codex) เข้าเป็นประสบการณ์เดียวกันใน ChatGPT โดยแพ็กเกจ Plus, Pro และ Business จะใช้โควตาการใช้งานร่วมกันระหว่าง ChatGPT กับ Codex ซึ่งวัดเป็น token ตั้งแต่เดือนธันวาคมครับ

## ผลกระทบต่อผู้ใช้งานแต่ละกลุ่ม

<div class="split">
<div class="prose">

OpenAI คาดว่าผู้ใช้ส่วนใหญ่จะไม่ต้องรอรีเซ็ตโควตาบ่อยกว่าเดิม ส่วนโฆษกของ OpenAI ตามที่ iPhoneMod รายงานบอกว่า**ผู้ใช้งานหนักที่สุดกลุ่มหนึ่งอาจชนลิมิตเร็วขึ้น** ครับ ทั้งนี้ OpenAI ระบุว่าการใช้โควตาขึ้นกับรุ่นที่เลือกและงานที่สั่ง รุ่นที่ล้ำกว่าและงานที่ซับซ้อนใช้โควตามากกว่า

ส่วนแชตรุ่น **Instant** OpenAI ระบุว่าไม่ถูกนับจากโควตา (iPhoneMod รายงานว่าถ้าโควตารวมหมดก็ยังสลับไปใช้ Instant ต่อได้) และดูโควตาคงเหลือรวมกับเวลารีเซ็ตได้ที่ Settings → Usage ครับ ถ้าถึงลิมิตก็รอรีเซ็ต อัปเกรดแพ็กเกจ หรือซื้อเครดิตเพิ่มได้

### กระแสตอบรับและข้อควรปรับตัว
iPhoneMod รายงานว่าสมาชิกบางรายในโซเชียลมีเดียและเว็บบอร์ดของ OpenAI กังวลว่าการรวมโควตาอาจทำให้ใช้โมเดลคิดวิเคราะห์ขั้นสูงได้น้อยลง ทั้งที่ค่าสมาชิกรายเดือนเท่าเดิม ผมมองว่าคนที่ใช้งานจริงจังน่าจะลองแบ่งงานสรุป/ร่างข้อความทั่วไปไว้ใช้กับรุ่น **Instant** เพื่อประหยัดโควตากลางไว้สำหรับงานโค้ดหรือ Agent ที่ซับซ้อนครับ
