## Files คืออะไร

<div class="split">
<div class="prose">

Files เป็นตัวจัดการไฟล์บน Windows ที่ชุมชนโอเพนซอร์สช่วยกันทำครับ หน้าเว็บเขียนว่า "The file manager Windows deserves" และบอกว่าใช้คู่กับ File Explorer ได้ ไม่ต้องทิ้งของเดิม

ของที่ได้เพิ่มจาก Explorer มีแท็บหลายอัน หน้าต่างสองฝั่ง (Dual pane) ในหน้าเดียว มุมมองแบบคอลัมน์ (เปิดโฟลเดอร์ไหน โฟลเดอร์ถัดไปก็ต่อเป็นคอลัมน์ใหม่) แท็กสีให้โฟลเดอร์และไฟล์ แถบคำสั่ง (Omnibar) กับ Command Palette และข้อมูล Git ในโฟลเดอร์ที่เป็น repository

ในภาพเป็นหน้าต่างหลัก ด้านบนมีแท็บ Documents กับ Home แถบข้างมีโฟลเดอร์ที่ปักหมุด ไดรฟ์ และคลาวด์ (OneDrive, iCloud, Google Drive) ด้านขวาเป็นไอคอนโฟลเดอร์และไฟล์ขนาดใหญ่

</div>

ส่วนตัวติดตั้งแบบไฟล์ ผมยังยืนยันขั้นตอนเองไม่ได้ เพราะหน้าดาวน์โหลดซ่อนรายการ "Other ways to install" ไว้ในสคริปต์ เปิดลิงก์ตรง ๆ ไม่ได้ แต่คำสั่ง winget มีอยู่ในบล็อกของโปรเจกต์ ลงวันที่ 30 พ.ย. 2567 ครับ

## ฟีเจอร์เด่น

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/files-windows-app-review/img-2.jpg" width="1420" height="766" loading="lazy" alt="ภาพ Files แบบ Dual Pane ฝั่งซ้ายเป็นไอคอนไฟล์ C# และ XAML ฝั่งขวาเป็นรายการโฟลเดอร์และไฟล์พร้อมคอลัมน์ Name Tag Date modified" /></div><figcaption><span class="news-fig__credit">ภาพ: Files Community · <a href="https://apps.microsoft.com/detail/9NGHP3DX8HDX" rel="noopener">Microsoft Store</a></span></figcaption></figure>
<div class="prose">

ผมชอบ Dual pane ที่สุดครับ เปิดสองโฟลเดอร์ข้างกัน แล้วลากไฟล์ข้ามฝั่งได้เลย เหมาะกับคนที่ย้ายไฟล์บ่อย ในภาพฝั่งซ้ายเป็นไอคอนไฟล์ C# ฝั่งขวาเป็นรายการแบบละเอียด มีคอลัมน์ชื่อ แท็ก และวันที่แก้ไข

ฟีเจอร์อื่นที่หน้าเว็บบอกไว้ มี Command Palette ให้พิมพ์ชื่อคำสั่งแทนการไล่หาเมนู แท็กสีที่กดจากแถบข้างแล้วเห็นทุกอย่างที่ติดแท็กนั้น และ Git ในตัว

ที่เหลือเป็นของเล็ก ๆ แต่สะดวก ดูขนาดโฟลเดอร์ได้ในรายการ เปิดแท็บที่เพิ่งปิดคืนด้วย Ctrl+Shift+T กรองรายการด้วย Ctrl+Shift+F และตรวจค่าแฮช (MD5, SHA-1, SHA-256) ได้ในหน้า Properties

</div>
</div>

</section>

## รุ่น v4.3 มีอะไรใหม่

<div class="prose">

บล็อกประกาศ v4.3 (11 ต.ค. 2569) บอกว่ารอบนี้เน้นความเร็ว แต่มีตัวเลขให้ข้อเดียว คือขนาดดาวน์โหลดรวมลดลงกว่า 60% และตอนนี้ .NET Desktop Runtime มากับแอปแล้ว ไม่ต้องติดตั้งแยก ข้ออื่นเป็นคำบรรยาย ผมไม่ได้วัดเองครับ

</div>

<ol class="news-steps">
<li><b>เร็วขึ้น</b>เปิดแอปเร็วขึ้น เปลี่ยนโฟลเดอร์และค้นหาเร็วขึ้น ใช้หน่วยความจำน้อยลง</li>
<li><b>ภาพคมขึ้น</b>ไอคอนและภาพตัวอย่างในมุมมองกริดรองรับ DPI</li>
<li><b>Git ดีขึ้น</b>แสดงความคืบหน้าของคำสั่ง แสดงข้อความผิดพลาดจริงแทนข้อความหมดเวลา และใช้กับ repository ที่ clone ผ่าน SSH ได้</li>
<li class="is-key"><b>ของเล็กแต่ใช้บ่อย</b>เช็กอัปเดตอัตโนมัติขณะเปิดแอป เส้นขอบเน้นตอนลากไฟล์ไปแท็บหรือแถบข้าง และเรียงโฟลเดอร์แบบธรรมชาติ (Folder 2 มาก่อน Folder 10)</li>
</ol>

</section>
