# ชุดโพสต์รีวิวลง Facebook (ให้ Claude in Chrome ช่วยใส่ข้อความ)

ใช้เมื่อเจ้าของขอ "รูปต้นฉบับ + ข้อความรีวิวโพสต์เฟซ" ของรีวิวบนเว็บ เพื่อเอาไปให้ Claude in Chrome ใส่ข้อความและคำบรรยายรูปใน Facebook
ตัวอย่างจริง: anitech H9313 และ SlimQ F100 (`docs/fb-review-pack-template/*.example.*`)

## ผลลัพธ์ = โฟลเดอร์ `<slug>/` แล้ว zip ส่งให้เจ้าของ
| ไฟล์ | เนื้อหา |
|---|---|
| `01-<สิ่งที่เห็น>.jpg` … `14-….jpg` | รูปเด่นประมาณ 14 รูป เรียงเล่าเรื่อง: กล่อง → หลังกล่อง → ตัวเครื่อง → ช่อง → ฉลาก → โปรโตคอล → ผลวัด |
| `post.txt` | ข้อความโพสต์สไตล์เจ้าของ |
| `claude-in-chrome.md` | กติกา + ขั้นตอน + ตารางคำบรรยายทีละรูป |
| `prompt-for-chrome.txt` | ข้อความสั้นที่เจ้าของวางใน Claude in Chrome (คัดจาก `docs/fb-review-pack-template/prompt-for-chrome.txt` แก้จำนวนรูป) |

## ขั้นตอน
1. **เลือกรูป** จาก `src/content/posts/<type>/<slug>.shots.json` (มีชื่อ คำอธิบาย และค่าที่วัด) แล้วจับคู่กับไฟล์ต้นฉบับใน `_sources/posts/<type>/<slug>/` (เทียบภาพย่อ)
2. **ทำความสะอาดรูป** ต้นฉบับมี GPS:
   - `ImageOps.exif_transpose()` แล้ว save q92 **ไม่ใส่ EXIF** → ตรวจว่า `getexif()` ว่างทุกรูป
   - ดู contact sheet แล้ว **เบลอ QR code / บาร์โค้ด / serial / ป้ายทะเบียน / หน้าคนแปลกหน้า**
3. **post.txt** (รูปแบบรีวิวเฟซของเจ้าของ — ใช้ emoji ชุดนี้ได้):
   `🔥 #miniReview <ชื่อ> 🔥` · เส้น `-----------------------------------` คั่น · ที่มา (ทำไมซื้อ) · Model / ราคา / ที่ซื้อ ·
   📌 ช่อง/สเปกหลัก ⚡️ · ✅ มาตรฐาน / Protocol · 🔬 วัดจริงด้วย POWER-Z (`V × A = W`) · 🔥 สรุปสั้นๆ 📌 · 🔥 สรุป ควรซื้อไหม? ✅ / ❎ ·
   `📖 อ่านรีวิวเต็ม + ตารางสเปก + ผลวัดทุกรูป : https://dojojin.tech/<type>/<slug>/` · hashtag
   ตัวเลขทุกตัวต้องมาจากรีวิวที่ขึ้นเว็บแล้วเท่านั้น
4. **claude-in-chrome.md**: กติกา (ห้ามกดโพสต์เอง · ข้อความตรงตัว · ไม่เปลี่ยน privacy · หน้าจอไม่ตรงให้หยุดถาม) · 7 ขั้นตอน · ตาราง `| # | ไฟล์ | คำบรรยาย |` ใส่ค่าที่วัดของแต่ละรูป
5. zip โฟลเดอร์ ส่งให้เจ้าของ (SendUserFile)
6. **หลังส่ง zip ต้องพิมพ์ข้อความ prompt-for-chrome.txt ในแชทเป็น code block ให้เจ้าของ copy ได้ทันที** โดยแก้จำนวนรูปและช่วงเลข (เช่น 14 รูป · 01–14 · 01→14) ให้ตรงกับจำนวนรูปจริงในโฟลเดอร์

## ข้อสำคัญ
- Claude in Chrome **ห้ามกดปุ่มโพสต์** — เจ้าของตรวจแล้วกดเอง
- โพสต์ Facebook ทั่วไป (ไม่ใช่รีวิว) ใช้กติกา "ไม่มี emoji ใช้แค่ → ✓" ตาม memory `fb-post-drafts`
