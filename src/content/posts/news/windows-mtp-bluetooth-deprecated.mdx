## เลิกพัฒนาอะไร และยังไม่ได้ถอดอะไร

<div class="split">
<div class="prose">

Microsoft เพิ่ม **MTP over Bluetooth** ลงในรายการฟีเจอร์ที่เลิกพัฒนาประจำเดือนพฤศจิกายน 2569 ครับ คำว่า deprecated ในเอกสารนี้หมายถึงไม่พัฒนาต่อ และบริษัทบอกว่าอาจนำออกจาก Windows รุ่นอนาคต แต่ยังไม่ได้ระบุวันที่ถอด

**MTP (Media Transfer Protocol)** คือวิธีรับส่งข้อมูลกับอุปกรณ์พกพา ส่วนที่ประกาศเลิกพัฒนารอบนี้เป็นการทำงานผ่าน Bluetooth โดยเฉพาะ ไม่ได้เลิก MTP ทุกช่องทาง ในภาพเป็นตัวอย่างที่ Windows Latest ใช้ประกอบการเชื่อมต่อ OnePlus 8T ผ่านสาย USB ซึ่งเป็นช่องทางที่ Microsoft ระบุว่ายังใช้ได้

ผมว่าเวลาอ่านข่าวนี้ควรแยกคำว่า **เลิกพัฒนา** ออกจาก **ถอดออกแล้ว** ครับ เพราะสถานะในประกาศยังไม่ได้หมายความว่าฟีเจอร์หายจากเครื่องทันทีที่อ่านข่าว และยังไม่มีวันถอดที่แน่นอน

## MTP ผ่าน Bluetooth ใช้ทำอะไร

<div class="prose">

เอกสาร Windows Portable Devices อธิบายว่า MTP ผ่าน Bluetooth ใช้ส่งและซิงก์ข้อมูลระหว่างคอมพิวเตอร์กับอุปกรณ์พกพา ตัวอย่างคือการซิงก์เพลงและเพลย์ลิสต์จาก **Windows Media Player** ไปยังเครื่องเล่นเพลงที่รองรับ จึงเป็นเรื่องของการจัดการข้อมูลอุปกรณ์ผ่านช่องทางหนึ่ง ไม่ใช่ชื่อเรียกรวมของการส่งไฟล์ไร้สายทั้งหมดครับ

ฟีเจอร์นี้มีอยู่ใน Windows 7 และ Windows Vista ที่ติดตั้ง Platform Update ส่วน Vista รุ่นปกติไม่ได้รองรับตามตารางของ Microsoft ข้อมูลนี้ช่วยบอกที่มาของระบบ แต่ไม่ได้หมายความว่ามือถือหรือเครื่องเล่นเพลงทุกเครื่องใช้วิธีดังกล่าว

ส่วนชื่อ Windows 10 ในตารางหมายถึงระบบที่คู่มือยังแสดงขั้นตอนอยู่ครับ หน้า Microsoft Support ระบุว่า Windows 10 หมดการสนับสนุนเมื่อ **14 ตุลาคม 2568** การมีคู่มือเดิมอยู่ไม่ได้แปลว่าสถานะการสนับสนุนเปลี่ยนกลับมา

## ผู้ใช้ในไทยยังส่งไฟล์แบบไหนได้บ้าง

<div class="prose">

ประกาศไม่ได้แยกกำหนดสำหรับประเทศไทยครับ ถ้าคุณใช้สาย USB จัดการไฟล์อยู่แล้ว เอกสารยืนยันชัดว่าช่องทางนั้นยังใช้ได้ ผมว่าคนที่ใช้สาย USB อยู่แล้วไม่จำเป็นต้องเปลี่ยนวิธีเพียงเพราะเห็นคำว่า MTP ในพาดหัวข่าวครับ

ส่วนการส่งไฟล์ Bluetooth แบบทั่วไป คู่มือ Microsoft Support ยังมีวิธีรับไฟล์บน Windows 11 อยู่ครับ อุปกรณ์อีกฝั่งต้องจับคู่กับคอมไว้ก่อน และรองรับการส่งไฟล์ในวิธีนี้ด้วย ไม่ใช่อุปกรณ์ Bluetooth ทุกชนิดจะส่งไฟล์ได้เหมือนกัน

<div class="news-steps">
<div><b>เปิดหน้ารับส่งไฟล์</b>ไปที่ Settings › Bluetooth &amp; devices › Devices แล้วเลือก Send or receive files via Bluetooth ในส่วน Related settings</div>
<div><b>เตรียมคอมรับไฟล์</b>เลือก Receive files ให้คอมรอการเชื่อมต่อ จากนั้นเริ่มส่งจากอีกเครื่องตามคู่มือของอุปกรณ์นั้น</div>
<div><b>เลือกที่เก็บ</b>เมื่อส่งเสร็จ ตรวจโฟลเดอร์ปลายทางและกด Finish เพื่อจบขั้นตอน</div>
</div>

หากคุณดูแลอุปกรณ์เก่าที่ซิงก์เพลงหรือจัดการข้อมูลผ่าน MTP over Bluetooth โดยตรง ผมแนะนำให้ตรวจว่ามีทางเลือกผ่าน USB หรือไม่ และติดตามวันถอดจริงจาก Microsoft ก่อนเปลี่ยนระบบครับ ส่วนใครใช้ Bluetooth รับส่งไฟล์ทั่วไป ประกาศนี้ไม่ได้บอกว่าจะยกเลิกเครื่องมือนั้น
