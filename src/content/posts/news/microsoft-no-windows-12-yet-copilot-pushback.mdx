## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

วันที่ 24 พฤศจิกายน 2569 **Axios** รายงานบทสัมภาษณ์ **Pavan Davuluri** (Executive Vice President of Windows and Devices ของ Microsoft) จากงาน Microsoft Ignite เดือนพฤศจิกายน 2569 ครับ โดยมี **Windows Latest**, **DigitalToday** และ **The News International** นำเนื้อหามารายงานต่อ บทสัมภาษณ์นี้มีต้นทางเดียวคือ Axios ครับ

เมื่อถูกถามว่า Windows 12 จะมาเมื่อไร Davuluri ไม่ได้ปฏิเสธการมีอยู่ของรุ่นถัดไป แต่ก็ไม่ได้ให้กำหนดการ เขาย้ำว่าตอนนี้ Microsoft เน้นที่ `"the quality, the craft, the fundamentals, the performance, the reliability"` (คุณภาพ ความประณีต พื้นฐาน ประสิทธิภาพ และความเสถียร) ของ **Windows 11** ซึ่งปัจจุบันมีผู้ใช้มากกว่า **1 พันล้านคน** แล้ว

Davuluri บอกด้วยว่า Microsoft ต้องสร้างเทคโนโลยีรองรับแอป AI ในอนาคตและพิสูจน์ให้ผู้ใช้เห็นว่าฟีเจอร์ AI เหล่านั้นมีประโยชน์จริง เพื่อ `"earn permission"` (สร้างความยอมรับจากผู้ใช้ก่อน) จึงจะก้าวไปสู่ยุคถัดไปได้

Davuluri ยังคาดว่า **local AI** (AI ที่ประมวลผลบนเครื่องโดยตรงไม่ต้องส่งขึ้นคลาวด์) ขนาด **10,000–20,000 ล้านพารามิเตอร์** (พารามิเตอร์คือค่าถ่วงน้ำหนักที่ใช้กำหนดความสามารถของโมเดล AI) จะทำให้พีซีมีฟีเจอร์เก่งขึ้น Windows Latest เล่าว่า local AI เริ่มเป็นที่นิยมในกลุ่มนักพัฒนา ครีเอเตอร์ และคนทำงานสายความรู้อยู่แล้ว แต่ **Bob O'Donnell** หัวหน้านักวิเคราะห์ของ Technalysis Research เตือนกับ Axios ว่าฟีเจอร์เหล่านี้ต้องทำงานได้เสถียรและปลอดภัยตลอดเวลา ซึ่ง `"we're still not quite there yet"` (เรายังไปไม่ถึงจุดนั้น)

O'Donnell เสริมว่าองค์กรที่เพิ่งย้ายจาก Windows 10 มา Windows 11 คงไม่อยากเจอการอัปเกรดใหญ่อีกรอบ ส่วน DigitalToday ที่อ้าง Axios รายงานเพิ่มว่าช่วงนี้ราคาแรมกำลังพุ่งสูง ขณะที่โมเดล local AI ระดับสูงต้องใช้แรมถึง **32GB, 64GB ไปจนถึง 128GB**

O'Donnell จึงสรุป (ตามที่ DigitalToday อ้าง Axios) ว่า `"We will see Windows 12 when everything is in place and properly integrated into the user interface."` (เราจะได้เห็น Windows 12 เมื่อทุกอย่างพร้อมและผสานเข้ากับหน้าตาของระบบอย่างลงตัวแล้ว)

*หมายเหตุความชัดเจน:* บทสัมภาษณ์ในงาน Ignite รอบนี้มีต้นทางเดียวจาก Axios และ**ไม่ได้มีประกาศปรับลดปุ่ม Copilot รอบใหม่** ส่วนเรื่องการลดจุดเข้าถึง **Copilot** (ผู้ช่วย AI ของ Microsoft) เป็นแผนเดิมตั้งแต่เดือนมีนาคม 2569 ที่ Windows Latest หยิบมาเล่าทบทวนเป็นพื้นหลังครับ

## ทำไม Microsoft ต้องถอยกลับมาแก้ Windows 11 ก่อน

<div class="split">
<div class="prose">

ถ้าดูข้อมูลย้อนหลังตลอดปี 2568–2569 Windows Latest และ Windows Central มองว่าแรงต้านจากผู้ใช้เป็นจุดเปลี่ยนที่ทำให้ Microsoft หันมาแก้ Windows 11 ครับ Windows Latest ระบุว่าในปี 2568 เพียงปีเดียว Windows 11 มีปัญหาใหญ่จากการอัปเดตถึง **20 ครั้ง** ทั้งที่บริษัทเร่งใส่ Copilot เข้าไปในแอปพื้นฐานอย่าง Notepad, Paint และ File Explorer

จุดเดือดเกิดในเดือนพฤศจิกายน 2568 เมื่อ Davuluri โพสต์บน X ว่า Windows `"evolving into an agentic OS"` (กำลังพัฒนาไปสู่ระบบปฏิบัติการที่มีผู้ช่วย AI ลงมือทำงานแทนผู้ใช้ได้) เลยถูกนักพัฒนาอย่าง **Gergely Orosz** และผู้ใช้จำนวนมากวิจารณ์หนัก ตามรายงานของ ITPro และ Windows Central (Windows Latest เล่าเพิ่มว่า Davuluri ปิดช่องตอบกลับ) ต่อมาต้นปี 2569 Microsoft จึงส่งแถลงการณ์ถึง The Verge (ที่ Windows Central นำมารายงาน) ยอมรับว่าจะหันมาแก้ปัญหาที่ผู้ใช้ร้องเรียน

วันที่ **20 มีนาคม 2569** Microsoft ประกาศแผนปรับปรุงคุณภาพ Windows 11 โดยลดจุดเข้าถึง Copilot ที่ไม่จำเป็นใน **Snipping Tool, Photos, Widgets และ Notepad** รวมถึงทำให้ผู้ใช้รีสตาร์ตหรือปิดเครื่องได้โดยไม่ถูกบังคับอัปเดต

ส่วนในงาน Ignite เดือนพฤศจิกายน 2569 Microsoft ยืนยันกับผู้ร่วมงาน (ตามรายงานของ Windows Latest วันที่ 26 พ.ย. 2569) ว่าจะถอดแอปเสริม Microsoft 365 ที่อัด Copilot อย่าง **People, Files และ Calendar** โดยจะหยุดทำงานวันที่ **16 ธันวาคม 2569** เพราะ `"They were a source of a lot of memory and issues"` (เป็นตัวกินแรมและก่อปัญหาจำนวนมาก)

ฝั่งตัวระบบเอง รุ่น **Windows 11 26H2** ก็ปรับให้เก็บแอปที่เปิดค้างไว้ในแรมได้มากขึ้นสูงสุด **2GB** บนเครื่องแรม 8GB ส่วนรุ่นปีหน้าอย่าง **Windows 11 27H2** ยังมีรายงานว่า Microsoft กำลังเตรียมเป็นการอัปเกรดระบบเต็มรูปแบบของ Windows 11 (Windows Latest อ้าง Tom Warren จาก The Verge เมื่อ 7 พ.ย. 2569) แต่ Microsoft ยังไม่ยืนยันชื่อเรียกครับ

## กระทบผู้ใช้ Windows ในไทยแค่ไหน

<div class="prose">

ตอนนี้**ยังไม่พบประกาศเฉพาะสำหรับประเทศไทย** หรือรายงานในสื่อไทยที่พูดถึงบทสัมภาษณ์ของ Axios รอบนี้ครับ

แต่ในมุมการใช้งานจริง ถือเป็นข่าวดีทั้งสำหรับผู้ใช้ทั่วไปและองค์กรในไทย เพราะคนที่เพิ่งซื้อคอมใหม่หรือเพิ่งอัปเกรดจาก Windows 10 มา Windows 11 ยังไม่ต้องกังวลว่าจะโดนบีบให้ย้ายไป Windows 12 หรือต้องซื้อเครื่องแรม 32GB–128GB มารองรับระบบปฏิบัติการใหม่ในเร็ว ๆ นี้

ส่วนใครในไทยที่ใช้โน้ตบุ๊กราคาประหยัดหรือราคากลางแรม **8GB** การที่ Microsoft หันมาแก้เรื่องกินแรมใน Windows 11 26H2 และทยอยถอดแอป Copilot ที่ทำงานหนักเบื้องหลังออกไป น่าจะช่วยเรื่องความลื่นไหลในการใช้งานจริงมากกว่าการเพิ่มปุ่ม AI (อ่านรายละเอียดเพิ่มเติมเรื่องโน้ตบุ๊กแรม 8GB ได้ในข่าว <a href="/news/asus-windows-11-budget-pc-8gb-ram/">ASUS อาจลดแรมโน้ตบุ๊กจาก 16GB เหลือ 8GB</a>)

ผมมองว่าปี 2570 จะเป็นตัวชี้วัดจริงว่า Microsoft แก้ความเสถียรของ Windows 11 ได้นิ่งพอตามที่รับปากไว้หรือไม่ (ข้อนี้เป็นความเห็นผมครับ)
