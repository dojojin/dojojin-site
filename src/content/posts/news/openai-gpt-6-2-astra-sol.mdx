## เกิดอะไรขึ้น

<div class="prose">

OpenAI ออกโมเดลใหม่สองตัวพร้อมกันเมื่อ 17 พฤศจิกายน 2569 คือ GPT-6.2 Astra และ GPT-6.2 Sol ครับ

- **Astra** OpenAI เขียนในเอกสารนักพัฒนาว่าเป็น "our most capable model for your hardest projects" คือรุ่นที่เก่งที่สุด สำหรับงานยาก ๆ
- **Sol** เป็น "our go-to model for everyday work" คือรุ่นหลักสำหรับงานประจำวัน ตั้งแต่เขียนโค้ดไปจนถึงรัน agent (โปรแกรมที่ให้โมเดลทำงานหลายขั้นตอนเอง) จำนวนมาก

ข้อมูลรุ่น ราคา และวิธีใช้ในข่าวนี้ มาจากเอกสารนักพัฒนาของ OpenAI เอง ส่วนเรื่องแพ็กเกจ ChatGPT และผลทดสอบ อ้างจากสื่อต่างประเทศ 3 แห่งครับ

</div>

</section>

## Astra กับ Sol ต่างกันอย่างไร

<div class="split">
<div class="prose">

ในภาพคือหน้ารุ่น GPT-6.2 Astra ของ OpenAI บอกว่า Astra เขียนและแก้ซอฟต์แวร์ได้ สั่งงานคอมพิวเตอร์ได้ ทำงานกับเอกสารได้ รับข้อความกับรูป ตอบเป็นข้อความ

ตามเอกสาร สองรุ่นนี้สเปกเกือบเหมือนกันหมด ต่างกันแค่ราคากับวันตัดข้อมูลความรู้ คู่มือของ OpenAI แนะนำให้ใช้ Astra กับงานที่ยากที่สุด และใช้ Sol กับงานซับซ้อนที่อยากจ่ายถูกลง

<div class="news-card is-ok"><b>GPT-6.2 Sol</b><span class="news-pill">รุ่นประหยัด</span> งานเขียนโค้ดและ agent ประจำวัน ความรู้ถึง 1 มิ.ย. 2569</div>

## ราคา

<div class="prose">

ราคา API ต่อ 1 ล้านโทเค็น ตามหน้ารุ่นของ OpenAI ครับ (โทเค็นคือหน่วยที่โมเดลใช้นับข้อความ ประมาณคำสั้น ๆ หนึ่งชิ้น)

<div class="news-stats">
<div class="news-stat"><b>$8 / $40</b><span>Astra อินพุต / เอาต์พุต</span></div>
<div class="news-stat"><b>$2 / $10</b><span>Sol อินพุต / เอาต์พุต</span></div>
</div>

รายละเอียดอื่นในหน้ารุ่น

- ข้อความที่ส่งซ้ำ (cached input) Astra $0.40 และ Sol $0.10
- ส่งข้อมูลเข้าเกิน 272,000 โทเค็น ราคาอินพุตเพิ่มเป็นสองเท่า ราคาเอาต์พุตเป็น 1.5 เท่า
- งานแบบ Batch (ส่งไปเป็นชุด ไม่ต้องได้คำตอบทันที) ลดเหลือ 50% ของราคามาตรฐาน

เทียบกับรุ่นก่อน DataCamp และ MLQ รายงานว่า Astra ถูกกว่า GPT-6 Astra 20% ส่วน Sol ราคาเท่า GPT-6.1 Sol เดิม ตัวเลข 20% นี้อ้างตามสื่อครับ ผมยังไม่ได้เทียบกับหน้าราคารุ่นก่อนเอง

## ใช้ได้ที่ไหน

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/openai-gpt-6-2-astra-sol/img-2.jpg" width="860" height="456" loading="lazy" alt="ภาพหน้าจอบันทึกการเปลี่ยนแปลง API ของ OpenAI วันที่ 17 พ.ย. ระบุ gpt-6.2-astra และ gpt-6.2-sol ใช้ได้กับ Responses API และ Chat Completions" /></div><figcaption><span class="news-fig__credit">ภาพ: ภาพหน้าจอ OpenAI Developers · <a href="https://developers.openai.com/api/docs/changelog" rel="noopener">Changelog</a> วางบนพื้นสีโดย DOJOJIN.TECH</span></figcaption></figure>
<div class="prose">

ฝั่งนักพัฒนา บันทึกการเปลี่ยนแปลง (Changelog) วันที่ 17 พ.ย. ระบุว่าทั้งสองรุ่นใช้ได้กับ Responses API และ Chat Completions แต่ถ้าจะให้โมเดลเรียกใช้เครื่องมือ (tool calling) ต้องใช้ Responses API

OpenAI ยังเพิ่มตัวเลือกสำหรับงานที่ไม่รีบ ให้ระบบประมวลผลเบื้องหลังภายใน 2 ชั่วโมงหรือ 8 ชั่วโมง ราคาโทเค็นถูกกว่ามาตรฐาน 30% และ 40% (ยังเป็น public beta)

<div class="news-cards">
<div class="news-card is-ok"><b>ChatGPT และ Codex</b><span class="news-pill">ตามสื่อ</span> DataCamp, MLQ และ Gagadget รายงานตรงกันว่าผู้ใช้ Plus, Pro, Enterprise และ Edu ใช้ได้ตั้งแต่วันเปิดตัว ส่วน Enterprise และ Edu แอดมินของ workspace ต้องเปิดให้ก่อน</div>
<div class="news-card is-warn"><b>แพ็กเกจฟรี</b><span class="news-pill">ไม่มีข้อมูล</span> DataCamp บอกว่าประกาศของ OpenAI ไม่ได้พูดถึงแพ็กเกจฟรี</div>
<div class="news-card is-ok"><b>GitHub Copilot</b><span class="news-pill">ตามสื่อ</span> MLQ รายงานว่า GitHub เปิดให้ใช้ทั้งสองรุ่นวันเดียวกัน สำหรับแพ็กเกจ Pro+, Max, Business และ Enterprise แบบทยอยเปิด</div>

## เก่งแค่ไหน ตามที่ OpenAI บอก

<div class="prose">

ตัวเลขชุดนี้มาจาก OpenAI เองทั้งหมดครับ สื่อที่รายงานยังไม่มีผลจากผู้ทดสอบอิสระ Gagadget เขียนไว้ตรง ๆ ว่า "Both numbers come from OpenAI, not independent testers"

OpenAI เน้นว่า Astra เก่งงานระดับมืออาชีพ เช่น ทำสไลด์ ไฟล์การเงิน ร่างเอกสารกฎหมาย และงาน agent ที่ทำต่อเนื่องนาน ๆ

<div class="news-cards">
<div class="news-card"><b>Agents' Last Exam v1.1</b><span class="news-pill">OpenAI บอก</span> Astra 78.3% Sol 73.0% (ตามตารางที่ DataCamp สรุป) MLQ ว่า OpenAI อ้าง Astra นำ Claude Fable 5.2 อยู่ 5.5 คะแนน</div>
<div class="news-card"><b>GDPval v2</b><span class="news-pill">OpenAI บอก</span> Astra 50.4% Sol 46.9% เป็นชุดทดสอบภายในของ OpenAI</div>
<div class="news-card"><b>FrontierCode 2.0</b><span class="news-pill">OpenAI บอก</span> Astra 44.2% Sol 43.8% MLQ ว่า Sol ตามหลังไม่ถึง 0.5 คะแนนด้วยต้นทุนราว 1 ใน 5</div>
</div>

ที่น่าสนใจคือ ในชุดทดสอบเขียนโค้ดนี้ Sol ตามหลัง Astra นิดเดียว แต่ราคา API ตามหน้ารุ่นเหลือหนึ่งในสี่ (ส่วน MLQ เขียนว่าต้นทุนราว 1 ใน 5) ผมว่านักพัฒนาควรลอง Sol ก่อน แล้วค่อยขยับไป Astra เมื่อจำเป็นครับ

อีกด้าน DataCamp บอกว่า Claude Fable 5.2 ยังนำในผลทดสอบโค้ดและการให้เหตุผลบางชุด

## คนไทยใช้ได้ไหม

<div class="prose">

OpenAI ไม่ได้แยกประกาศเรื่องไทย และสื่อที่รายงานก็ไม่ได้พูดถึงภูมิภาคไหนเลยครับ

ที่เช็กได้คือหน้ารายชื่อประเทศที่ OpenAI รองรับ มี Thailand อยู่ในรายการ แต่หน้านั้นไม่ได้บอกว่าหมายถึง API อย่างเดียวหรือทุกบริการ และไม่ได้บอกว่ารุ่นใหม่เปิดในไทยวันไหน

ส่วนแพ็กเกจที่ใช้รุ่นนี้ได้ เป็นไปตามที่สื่อรายงานข้างบน ราคาที่ประกาศเป็นดอลลาร์สหรัฐ ราคาเป็นบาทหรือเรื่องภาษียังไม่มีข้อมูล
