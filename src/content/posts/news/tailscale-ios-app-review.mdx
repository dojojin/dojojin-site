## Tailscale คืออะไร

<div class="split">
<div class="prose">

Tailscale คือแอปที่ต่อเครื่องของเราหลาย ๆ เครื่องเข้าเป็นเครือข่ายส่วนตัวเดียวกันครับ iPhone, คอมพิวเตอร์ และ NAS ที่อยู่คนละที่ ก็คุยกันได้เหมือนอยู่ในวงแลนเดียวกัน

คู่มือของ Tailscale เรียกเครือข่ายนี้ว่า tailnet ใช้โปรโตคอล WireGuard เข้ารหัสการเชื่อมต่อแบบจุดต่อจุด และบอกว่าเชื่อมกันได้แม้มีไฟร์วอลล์หรือ NAT (ระบบที่เราเตอร์ใช้แชร์เน็ตให้หลายเครื่อง) ขวางอยู่ ไม่ต้องไปเปิดพอร์ตเอง

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-wireless" /></svg><div><b>เชื่อมเครื่องต่างที่</b>มือถือที่อยู่ข้างนอก เข้าเครื่องที่บ้านหรือที่ทำงานได้</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-chip" /></svg><div><b>เข้ารหัสด้วย WireGuard</b>ทุกการเชื่อมต่อเข้ารหัสแบบ end-to-end</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-globe" /></svg><div><b>ใช้เป็น VPN ได้ด้วย</b>เลือกเครื่องหนึ่งเป็น exit node แล้วทราฟฟิกทั้งหมดจะออกทางเครื่องนั้น</div></div>
</div>

ผู้พัฒนาคือ Tailscale Inc ดาวน์โหลดฟรีบน App Store ไทย และหน้า App Store ไม่มีรายการซื้อในแอปครับ

</div>

</div>

## ล็อกอินยังไง

<div class="split">

<div class="prose">

ตรงนี้ต่างจากแอปทั่วไปนิดหนึ่งครับ Tailscale ไม่มีรหัสผ่านของตัวเอง

คู่มือบอกว่าตั้งใจไม่รองรับการสมัครด้วยอีเมลกับรหัสผ่าน ให้ใช้บัญชีที่เรามีอยู่แล้วล็อกอินแทน ในภาพคือหน้าล็อกอิน มีปุ่มให้เลือก Google, Microsoft, GitHub, Apple และ passkey

ข้อดีคือถ้าบัญชี Google หรือ Microsoft ของเราเปิดยืนยันตัวตนสองขั้น (2FA) ไว้แล้ว ก็ได้ขั้นตอนนั้นมาใช้กับ Tailscale ด้วย หน้าแอปเขียนไว้ว่า "Use your existing identity & 2FA"

## หน้าจอหลักและ exit node

<div class="split">
<div class="prose">

หน้าหลักของแอปเรียบง่ายครับ ตามภาพ บนสุดมีสวิตช์เปิดปิดการเชื่อมต่อ ชื่อเครือข่าย (ภาพตัวอย่างใช้ example.com) และสถานะ Connected

ถัดลงมาเป็นช่อง Exit node ให้เลือกเครื่องปลายทางแล้วกด Enable ใต้ลงมาเป็นช่องค้นหาเครื่อง กับรายชื่อเครื่องแยกตามเจ้าของ แต่ละเครื่องมีที่อยู่ IP ของ Tailscale กำกับ เช่น 100.76.53.38 ในภาพตัวอย่าง จุดเขียวคือเครื่องที่เชื่อมอยู่

ผมว่านี่คือจุดที่เข้าใจง่ายที่สุดของแอปครับ ดูจากภาพก็รู้เลยว่าเครื่องไหนออนไลน์อยู่

</div>

## ข้อควรรู้ก่อนใช้

<div class="prose">

มีสามเรื่องที่ผมอยากให้รู้ก่อนครับ ทั้งหมดมาจากเว็บของ Tailscale เอง

<div class="news-cards">
<div class="news-card is-warn"><b>เปิดซอร์สบางส่วน ตัวแอป iPhone ไม่ใช่</b>หน้า opensource ของ Tailscale บอกว่าตัวโปรแกรมเบื้องหลัง (daemon) กับคำสั่ง CLI เป็นโอเพนซอร์ส ไลเซนส์ BSD-3-Clause อยู่บน GitHub แต่หน้าเดียวกันก็อธิบายหลักไว้ว่า บนระบบปิดอย่าง iOS ส่วนหน้าจอแอป (GUI) เป็นซอร์สปิด ส่วนเซิร์ฟเวอร์กลางที่คอยประสานงานเครื่องต่าง ๆ (coordination server) ของ Tailscale ก็เป็นซอร์สปิดเช่นกัน</div>
<div class="news-card is-ok"><b>อยากโฮสต์เซิร์ฟเวอร์กลางเอง มี Headscale</b>Headscale เป็นเซิร์ฟเวอร์กลางแบบโอเพนซอร์สที่ชุมชนทำ โฮสต์เองได้ ใช้กับเครือข่ายเดียว Tailscale บอกว่าไม่ได้เป็นผู้ดูแลโปรเจกต์นี้ และไม่นับเป็นผลิตภัณฑ์ที่ตัวเองซัพพอร์ต ผมไม่ได้ลองตั้งเอง แต่เห็นในบันทึกรุ่นของแอป iOS ว่ามีแก้ปัญหาเรื่อง custom coordination server อยู่</div>
<div class="news-card is-warn"><b>บางทีทราฟฟิกวิ่งผ่านรีเลย์</b>คู่มือบอกว่าเครื่องจะพยายามต่อตรงถึงกัน (peer-to-peer) ก่อน ถ้าต่อตรงไม่ได้ จึงค่อยวิ่งผ่านเซิร์ฟเวอร์รีเลย์ที่ชื่อ DERP ทั้งสองแบบเข้ารหัสด้วย WireGuard เหมือนกัน ต่างกันที่ความเร็ว การต่อตรงมักเร็วกว่า</div>

## รุ่นล่าสุด 1.104.7

<div class="prose">

รุ่นล่าสุดบน App Store ไทยคือ 1.104.7 ลงวันที่ 17 พฤศจิกายน 2569 ขนาด 30.6 MB ใช้ iOS 16.6 ขึ้นไป (iPad ใช้ iPadOS 16.6 ขึ้นไป)

รุ่นนี้แก้เรื่องเดียวครับ คืออุปกรณ์กลางทางบางตัวขัดขวางการเชื่อมต่อไปยังเซิร์ฟเวอร์ควบคุมของ Tailscale ตอนจับมือ TLS (ขั้นตอนเริ่มต้นของการเชื่อมต่อแบบเข้ารหัส) แก้โดยอัปเดต Go เป็น 1.27.4

ย้อนไปไม่กี่รุ่น ก็มีของใหม่และแก้บั๊กมาเรื่อย ๆ ครับ

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-download" /></svg><div><b>1.104.6 (11 พ.ย.)</b>แก้ปัญหาที่เกิดไม่บ่อย กับการเชื่อมต่อที่ไม่ได้ใช้งานนาน ๆ</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-alert" /></svg><div><b>1.104.4 (29 ต.ค.)</b>แก้ประเด็นความปลอดภัยที่เกี่ยวกับ Tailscale Serve และ SSH (รายละเอียดอยู่หน้า security bulletins ของ Tailscale)</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-wireless" /></svg><div><b>1.104.1 (9 ต.ค.)</b>ปักหมุดอุปกรณ์บน iOS ได้ และ Taildrop (ส่งไฟล์ระหว่างเครื่อง) รองรับลิงก์กับข้อความที่เลือก</div></div>
</div>

วันที่ของแต่ละรุ่นเป็นเวลาไทย แปลงจากเวลาในหน้า App Store แล้ว อีกเรื่องคือแอปมีภาษาอังกฤษอย่างเดียวครับ

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่มีคอมหรือ NAS ที่บ้าน แล้วอยากเข้าถึงตอนอยู่ข้างนอกโดยไม่ต้องตั้งค่าเราเตอร์เอง หรือคนที่อยากส่งไฟล์ระหว่างเครื่องของตัวเอง ถ้าเป็นงานส่วนตัวก็ใช้ฟรีได้

ก่อนลงมีสามอย่างที่ต้องรู้ครับ

- แผนฟรีสำหรับงานที่ไม่ใช่เชิงพาณิชย์
- ต้องล็อกอินผ่านบัญชี Google, Microsoft, GitHub หรือ Apple
- เซิร์ฟเวอร์กลางเป็นของบริษัท ใครไม่สบายใจเรื่องนี้ ดู Headscale เป็นทางเลือกได้ แต่ต้องดูแลเองทั้งหมด

บอกไว้ตรงนี้ว่าผมยังไม่ได้ลงแอปลองใช้เองนะครับ ข้อมูลทั้งหมดในข่าวนี้มาจากหน้า App Store และเว็บของ Tailscale
