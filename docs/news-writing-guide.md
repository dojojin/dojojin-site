# คู่มือเขียนข่าว /news/ (DOJOJIN.TECH)

อัปเดต 2026-11-12 ตามที่เจ้าของเว็บอนุมัติ — ใช้ทุกครั้งที่เขียนหรือแก้ข่าว (คน, Claude, sonnet subagent, cron)

## ขั้นตอน
1. สรุปข่าว (cron 08:20/16:20 → `~/news-digest/`) → เจ้าของเลือกเลข → เขียน → เจ้าของตรวจ → commit/deploy เมื่อสั่งเท่านั้น
2. ยืนยันข้อเท็จจริงกับต้นทาง (ผู้ผลิต/รัฐ) ห้ามแต่งตัวเลข ราคา วันที่ ถ้าไม่รู้ข้อมูลไทยให้เขียนตรง ๆ
3. ภาษา: ไทยง่าย ๆ เสียงเจ้าของ (ผม/ครับ) ไม่แปลทีละบรรทัด ไม่มี emoji
4. **Copywriter pass ทุกข่าว โดย agent Opus แยกอีกตัว** (เจ้าของสั่ง 13 พ.ย. 2569 หลังร่างของ Sonnet อ่านแข็งเหมือนแปลรายการแหล่งข่าว): Sonnet เขียนร่างเสร็จ → ส่ง agent Opus (model `opus`) เกลาสำนวนก่อนให้ main model ตรวจและก่อนส่งเจ้าของทุกครั้ง ห้ามข้าม
   - เกลาเป็นเสียงเจ้าของ **แบบเดียวกับที่เจ้าของเขียนรีวิว** (อ่าน `src/content/posts/review/` 2–3 เรื่องก่อนทุกครั้ง: ผม/ครับ เล่าตรงกับคนอ่าน บรรทัดสั้น มีความเห็นสั้น ๆ แบบ "ผมว่า…"): ประโยคสั้น ประเด็นก่อนรายละเอียด แตกย่อหน้าแน่น ๆ ตัวเลข/ชื่อหลายตัวทำเป็นลิสต์ อ้างสื่อครั้งเดียวต่อเรื่องให้อ่านลื่น ไม่ต้อง "(ตาม X)" ทุกวลี ศัพท์เฉพาะ/ชื่อย่อหุ้น (เช่น NVDA, FY, 8-K) อธิบายครั้งแรกหรือใช้คำไทยแทน ไม่ advertorial
   - ห้ามเปลี่ยนข้อเท็จจริง ตัวเลข วันที่ ชื่อ คำพูด ลิงก์ การอ้างที่มา โครงสร้าง HTML/split ภาพ alt เครดิต ส่วนแหล่งข้อมูล/ที่มาของภาพ
   - agent ต้องรัน build + lint + check-splits ผ่าน และรายงาน before → after

## ภาพ
- ห้ามใช้ภาพจากสำนักข่าวไทย/เว็บข่าวไทย · ภาพแบรนด์ทางการ ภาพหน้าจอ เว็บต่างประเทศใช้ได้พร้อมเครดิต
- ข่าวสินค้า: ปก = ภาพทางการของแบรนด์ · ไม่มีภาพทางการ: ภาพประกอบที่สร้างเอง
- **ห้ามเขียนว่า AI / Codex** ที่ไหนเลย (ข้อความ เครดิต alt หรือในภาพ) ใช้ "ภาพประกอบ" / "ภาพประกอบจาก DOJOJIN.TECH"
- ห้ามใช้ภาพที่เป็นแค่โลโก้หรือมาสคอตที่ไม่สื่อเนื้อหา
- **ภาพปก (cover) = 1600×1200 (4:3) เสมอ** (เจ้าของสั่ง 14 พ.ย. 2569 หลังปก Rectangle 2:1 โดนตัดข้อความ): หน้าข่าว (`.hero__media`) และการ์ด (`.spot__card`, `.shot__img`) crop เป็น 4:3, หน้ารวม (`.hub__lead`) 16:9, Facebook/og ราว 1.91:1 — ภาพที่ไม่ใช่ 4:3 จะโดนตัดซ้ายขวา
  - ภาพวาดปก: สั่ง codex แบบ 4:3 วัตถุหลักเต็มตัวอยู่ครึ่งขวา ซ้าย 45% โล่งไว้วางข้อความ
  - ข้อความไทยบนปก (HTML overlay) อยู่ซ้ายกลาง ภายในแถบกลาง y ≈ 180–1020 px (รอด crop 16:9 และ og) และห้ามทับวัตถุหลัก หัวเรื่องยาวให้ขึ้นบรรทัดใหม่
  - ภาพทางการ/ภาพหน้าจอที่ไม่ใช่ 4:3: วางทั้งภาพบนพื้นสีเดียวกับขอบภาพให้เป็น 4:3 (ห้ามปล่อยให้เว็บ crop เอง) · ภาพหน้าจอเล็ก ๆ ที่อ่านไม่ออกไม่ใช้เป็นปก
  - ตรวจ: เปิดหน้าข่าวที่ 1280 แล้ว screenshot `.hero__media img` ดูว่าไม่มีข้อความ/วัตถุโดนตัด
- ภาพ web: ≤1600px, JPEG q85, ล้าง EXIF · ต้นฉบับเก็บใน `_sources/posts/news/<slug>/` · `python3 scripts/content/thumbs.py`

## ข้อมูล ไทม์ไลน์ ตัวเลข (HTML ในเนื้อข่าว ไม่ทำเป็นรูป) — เจ้าของสั่ง 14 พ.ย. 2569
- กล่องข้อมูล ไทม์ไลน์ ตัวเลข ขั้นตอน → เขียนเป็น HTML ในไฟล์ .mdx ใช้สีจาก token ของเว็บ จึงเข้ากับโหมดสว่าง/มืดเอง (รูปที่มีตัวหนังสือไม่เปลี่ยนตามธีม)
- component ใน `src/styles/site.css`: `.news-tl` (ไทม์ไลน์), `.news-cards` + `.news-card.is-bad|is-warn|is-ok` + `.news-pill` (การ์ดสถานะ), `.news-stats` + `.news-stat` (ตัวเลขใหญ่), `.news-panel` + `.news-bar` (แท่ง) + `.news-band` + `.news-legend` (แถบช่วงเวลา), `.news-steps` (ขั้นตอนมีเลข, `.is-key` เน้น) — ดูตัวอย่างใน `src/content/posts/news/microsoft-365-outage-2026-11.mdx`
- ลดรายการหัวข้อย่อย (bullet) ยาว ๆ: เล่าเป็นย่อหน้า + กล่อง HTML หนึ่งชุดแทน
- **รูปประกอบ = ภาพบรรยายสถานการณ์แบบภาพจริง** (Codex แนวภาพถ่าย ไม่มีตัวหนังสือ/โลโก้/หน้าคนชัด) ไฟล์ `photo-N.jpg` ใส่เป็น `news-fig` คู่กับย่อหน้าใน `.split` เครดิต "ภาพประกอบจาก DOJOJIN.TECH" · ต้นฉบับใน `_sources/posts/news/<slug>/photo/pN/`
- รูปปก (4:3 + ตัวหนังสือทับ) ยังทำแบบเดิม

## ข่าวเหตุการณ์ (ระบบล่ม เหตุโจมตี เหตุใหญ่ที่มีลำดับเวลา) — แบบข่าว Microsoft 365 ล่ม 14 พ.ย. 2569
- เล่าตั้งแต่ต้นจนจบ: เกิดอะไรขึ้น (สั้น) → ไทม์ไลน์ `.news-tl` เวลาไทย (UTC+7) แบ่งช่วงถ้ายาว ใต้แต่ละจุดมีที่มา → กระทบอะไรบ้าง (`.news-cards`) → **คนไทยโดนช่วงไหน แค่ไหน** (`.news-stats`/`.news-bar`/`.news-band`) → สาเหตุตามที่บริษัทแจ้ง (`.news-steps`) → ถ้าเจออีกทำอย่างไร → ข้อควรรู้เพิ่มเติม
- แปลงเวลาเป็นเวลาไทยเองและบอกว่าแปลง · แหล่งให้เวลาไม่ตรงกันใช้ "ราว" และบอกทั้งสองค่า · ตัวเลขต้องบอกขอบเขตตามต้นทาง (เช่น "เกือบ 130,000 ครั้ง ตาม AP" ไม่ใช่ "ทั่วโลก" ถ้าต้นทางไม่ได้บอก)
- ผลกระทบในไทย: ใช้หลักฐานจริง (Downdetector ไทยผ่านสื่อ, ประกาศองค์กรไทย, แถลงบริษัทสาขาไทย) · ส่วนที่คำนวณเองติดป้ายว่า "ผมคำนวณเอง" · หาไม่เจอให้เขียนตรง ๆ ว่าไม่พบ ห้ามแต่งเพิ่ม
- เปิดหน้าทางการไม่ได้ (X, status page) ให้บอกในข่าวว่าอ่านคำชี้แจงผ่านสื่อ · คำพูดบริษัทยกภาษาอังกฤษสั้น ๆ แล้วอธิบายไทย · ไม่เดาเรื่องการโจมตี
- ภาพ: ภาพบรรยากาศ 2–3 ภาพ (เช่น คนเปิดเมลไม่ขึ้นตอนดึก, ออฟฟิศเช้าวันทำงาน, วิศวกรในศูนย์ข้อมูล) คู่กับไทม์ไลน์/ผลกระทบ
- รายงานฉบับเต็มของบริษัท (post-incident report) ยังไม่ออก → เพิ่มใน `~/news-digest/followups.md`

## Layout (ภาพอยู่ในเนื้อข่าว ไม่มีแกลเลอรีท้ายข่าว)
- ทุกภาพ (infographic หรือภาพถ่าย) อยู่ใน `<div class="split">` คู่กับ `<div class="prose">` ที่**อธิบายภาพนั้นจริง** · ห้ามซ้อน split · split ละ 2 ลูกพอดี
- ภาพถ่าย: `<figure class="news-fig"><div class="news-fig__img"><img …/></div><figcaption><span class="news-fig__credit">ภาพ: … · <a …>…</a></span></figcaption></figure>`
  - ใต้ภาพมีแค่เครดิต — สิ่งที่ภาพแสดงเขียนเป็นเนื้อข่าวปกติในย่อหน้าคู่ (ใช้คำว่า "ในภาพ" ไม่ใช้ "ภาพด้านบน/ล่าง")
  - ภาพแนวตั้ง: เพิ่ม `news-fig--tall` · ภาพที่มีตัวหนังสือ (หน้าจอ ตาราง ผัง ประกาศ): เพิ่ม `news-fig--zoom` (ได้แว่นขยาย ✕/Esc/คลิกพื้นหลังเพื่อปิด) — infographic ซูมได้อัตโนมัติ
- ซ้าย/ขวาสลับกันทั้งหน้า: รัน `python3 scripts/content/alternate-splits.py src/content/posts/news/<slug>.mdx`
- มือถือ (≤768px) ภาพขึ้นก่อน ตามด้วยข้อความของภาพนั้น (CSS จัดการเอง)
- ข่าวประชาสัมพันธ์ภาพเยอะ: ภาพหลัก 3–4 ภาพในเนื้อข่าว ที่เหลือ `## ภาพเพิ่มเติม` + ShotGallery

## Sitemap / SEO (อัตโนมัติ — ไม่ต้องทำมือ)
- `npm run build` สร้าง `sitemap-index.xml` (ทุกหน้า + `lastmod` จาก `date` ใน frontmatter; ถ้าแก้บทความเก่ามากให้เพิ่ม `updated: 2026-11-20T10:00:00+07:00` แล้ว lastmod จะใช้ค่านี้) และ `news-sitemap.xml` (ข่าว 2 วันล่าสุดสำหรับ Google News) — logic อยู่ใน `astro.config.mjs` และ `src/pages/news-sitemap.xml.js`
