## จุดเด่นใน Visual Studio Code 1.148 (25 พ.ย. 2569)

<div class="split">
<div class="prose">

Microsoft ปล่อย **Visual Studio Code 1.148** เวอร์ชันเสถียรเมื่อวันที่ 25 พฤศจิกายน 2569 ครับ รอบนี้เน้นให้ระบบ Agent (ผู้ช่วย AI ที่ลงมือทำงานต่อกันได้หลายขั้น) และ Remote Workspace (การเขียนโค้ดบนเครื่องอื่นผ่านเครือข่าย) เสถียรและเร็วขึ้น

### เบื้องหลังการปรับความเร็ว Agent Host
ทีม VS Code บอกว่าหลังย้ายการทำงานของ Agent มาอยู่บน **Agent Host** แบบใหม่ หลายคนบ่นว่าเริ่มตอบช้ากว่ารุ่นเดิม

รุ่น **1.148** เลยปรับจนเวลาเริ่มตอบเร็วขึ้นเฉลี่ย **30%** และใกล้เคียงระบบเก่า ต่างกันเพียงราว **5%**

ส่วน `sessions.keepAwakeWhileWorking` จะให้ host ที่รองรับไม่หลับระหว่างที่ Agent ทำงาน แม้ปิดหน้าต่างไปแล้ว และปล่อยให้หลับได้เมื่องานจบครับ
