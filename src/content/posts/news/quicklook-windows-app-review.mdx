## QuickLook คืออะไร

<div class="prose">

QuickLook คือโปรแกรมที่เอา Quick Look ของ macOS มาไว้บน Windows ครับ หน้า GitHub เขียนว่า "Bring macOS Quick Look feature to Windows"

วิธีใช้ง่ายมาก เลือกไฟล์ใน File Explorer แล้วกด Space หน้าต่างตัวอย่างก็เด้งขึ้นมา กด Space อีกทีก็ปิด ไม่ต้องดับเบิลคลิก ไม่ต้องรอโปรแกรมเปิด

ผมว่าเหมาะกับงานแบบเปิดดูแป๊บเดียวแล้วปิด เช่น คัดรูป ดูว่าเอกสารไหนคือตัวที่หา หรือเช็กไฟล์โค้ดสั้น ๆ ครับ

</div>

</section>

## ยังมีคนดูแลอยู่ไหม

<div class="prose">

ยังมีครับ ผมเช็กเพราะรุ่นล่าสุดออกมาเกือบ 7 เดือนแล้ว (เมษายน 2569)

รายการ commit บน GitHub ล่าสุดคือ 12 พ.ย. 2569 เพิ่มการดูไอคอนฟอนต์ WOFF2 ก่อนหน้านั้นก็มีแก้ให้จำค่าตั้งแสดงผลของตัวอ่านข้อความ และให้ไอคอนโปรแกรมมีโหมดสว่าง/มืด

แต่ของใหม่พวกนี้ยังไม่อยู่ในรุ่นเสถียรที่ออกเป็น Release ใครอยากได้ก่อน README มี Nightly build ให้ลอง ส่วนผมแนะนำรุ่นเสถียร 4.5.0 ครับ

<div class="news-cards">
<div class="news-card is-warn"><b>เรื่องวิดีโอ</b>รุ่น 4.5.0 อัปเดตตัวถอดรหัสวิดีโอ LAVFilters เป็น 0.81.0 หน้า Release เตือนว่าอาจเปิดวิดีโอไม่ได้บนการ์ดจอรุ่นเก่า หรือเครื่องที่ยังไม่มี Visual C++ Redistributable ล่าสุด ถ้าเจออาการนี้ให้ลงตัวนั้นก่อน</div>
<div class="news-card is-ok"><b>ของใหม่ในรุ่น 4.5.0</b>ตัวเลือกพื้นหลังหน้าต่าง (backdrop) · ไฮไลต์ไวยากรณ์ไฟล์ชนิดใหม่เพิ่ม · ดูไฟล์ Chromium .pak, Python .whl/.egg และ DICOM · กด F11 เต็มจอ</div>
<div class="news-card is-ok"><b>บั๊กที่แก้ในรุ่นนี้</b>ความโปร่งใสบน Windows 10 · ไอคอนบน taskbar หายหลัง Explorer รีสตาร์ต · ไฟล์ assimp.dll ที่ขาดหาย</div>

## วิธีติดตั้ง

<div class="prose">

มีหลายทาง เลือกตามที่สะดวกได้เลยครับ ข้อต่างหลักคืออยากให้กด Space ดูไฟล์ในหน้าต่าง Open/Save ได้ด้วยหรือเปล่า

<ol class="news-steps">
<li><b>Microsoft Store</b>ค้นหา QuickLook หรือเปิด <a href="https://apps.microsoft.com/detail/9NV4BS3L1H4S" rel="noopener">apps.microsoft.com/detail/9NV4BS3L1H4S</a> อัปเดตเองและรันแบบแซนด์บ็อกซ์ แต่ README บอกว่าแบบนี้ไม่มีพรีวิวในหน้าต่าง Open/Save</li>
<li><b>ตัวติดตั้งจาก GitHub</b>โหลด .exe หรือ .msi จาก <a href="https://github.com/QL-Win/QuickLook/releases/tag/4.5.0" rel="noopener">หน้ารุ่น 4.5.0</a> ได้ฟีเจอร์ครบ รวมหน้าต่าง Open/Save และโหมดพกพา</li>
<li><b>winget หรือ Scoop</b>winget มีแพ็กเกจ QL-Win.QuickLook (ในรายการ winget-pkgs มีรุ่น 4.5.0 แล้ว) ส่วน Scoop พิมพ์ scoop bucket add extras แล้ว scoop install quicklook</li>
<li><b>แบบพกพา</b>โหลดไฟล์ .zip หรือ .7z แตกแล้วรันได้เลย ไม่ต้องติดตั้ง</li>
</ol>

โหลดจาก GitHub หรือ Store ของโปรเจกต์เท่านั้นนะครับ โปรแกรมนี้เปิดอ่านไฟล์ที่เราเลือก ไฟล์ติดตั้งจากแหล่งอื่นไม่ควรเสี่ยง

</div>

</section>

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่เปิดไฟล์ดูผ่าน ๆ บ่อย และอิจฉาปุ่ม Space ของ Mac ครับ ผู้พัฒนาเขียนไว้ว่าฟรี ไม่มีโฆษณา ลองแล้วไม่ชอบก็ถอนออกได้

ก่อนลงมี 3 เรื่องที่ควรรู้ แบบ Store ไม่มีพรีวิวในหน้าต่าง Open/Save โปรแกรมไม่มีภาษาไทย และรุ่นเสถียรล่าสุดออกมาหลายเดือนแล้ว

ใครใช้ <a href="/news/everything-windows-app-review/">Everything</a> ค้นไฟล์อยู่ ใช้คู่กันได้เลยครับ ค้นเจอแล้วกด Space ดูก่อนค่อยเปิดจริง

สุดท้ายขอบอกตรง ๆ ว่าผมยังไม่ได้ลงแอปลองเองนะครับ ข้อมูลทั้งหมดในข่าวนี้มาจากหน้าทางการของโปรเจกต์บน GitHub
