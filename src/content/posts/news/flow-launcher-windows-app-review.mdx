## Flow Launcher คืออะไร

<div class="split">
<div class="prose">

หน้า GitHub อธิบายว่า Flow Launcher คือ "a quick file search and app launcher for Windows with community-made plugins" แปลง่าย ๆ คือช่องค้นหาที่เด้งขึ้นมากลางจอ ใช้ค้นแอปและไฟล์ แล้วเปิดได้ทันที แถมมีปลั๊กอินที่ชุมชนช่วยกันทำเพิ่มได้

กดแป้นลัด <kbd>Alt</kbd>+<kbd>Space</kbd> เพื่อเปิดช่องค้นหา (เป็นค่าเริ่มต้น เปลี่ยนได้) พิมพ์แล้วกด <kbd>Enter</kbd> เพื่อเปิด ส่วน <kbd>Ctrl</kbd>+<kbd>Enter</kbd> เปิดโฟลเดอร์ที่ไฟล์อยู่ และ <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> เปิดแบบผู้ดูแลระบบ

</div>
<figure class="split-fig"><img src="/media/posts/news/flow-launcher-windows-app-review/igv-1.jpg" width="1600" height="1593" loading="lazy" alt="อินโฟกราฟิกข้อมูลเร็ว ๆ ของ Flow Launcher โอเพนซอร์ส MIT ใช้ฟรี รุ่นล่าสุด 2.1.4 วันที่ 20 ก.ย. 2569 บน GitHub ต้องใช้ Windows 10 ขึ้นไป ติดตั้งด้วย Installer, Winget, Scoop หรือ Chocolatey กดเปิดค้นหาด้วย Alt+Space" /></figure>
</div>

</section>

## ค้นอะไรได้บ้าง

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/flow-launcher-windows-app-review/img-1.jpg" width="990" height="643" loading="lazy" alt="ภาพตัวอย่าง Flow Launcher พิมพ์ b แล้วแสดงรายการบุ๊กมาร์กของเบราว์เซอร์ ได้แก่ YouTube, Amazon, GitHub, Tailwind CSS และ Fluenticons พร้อมแป้นลัด Alt+1 ถึง Alt+5" /></div><figcaption><span class="news-fig__credit">ภาพ: Flow Launcher · <a href="https://github.com/Flow-Launcher/Flow.Launcher" rel="noopener">github.com</a></span></figcaption></figure>
<div class="prose">

ในภาพคือการค้นบุ๊กมาร์กของเบราว์เซอร์ พิมพ์ตัวอักษรนำหน้าแล้วรายการเว็บที่เซฟไว้ก็ขึ้นมา มีแป้นลัด <kbd>Alt</kbd>+เลข ให้เลือกผลลัพธ์ได้เร็วขึ้น

ตามหน้า GitHub ค้นได้ทั้งแอป ไฟล์ และเนื้อหาในไฟล์ (รองรับ Everything และ Windows Index) ค้นเว็บและเปิด URL ค้นบุ๊กมาร์ก ใช้คำสั่งระบบอย่างปิดเครื่อง ล็อกเครื่อง เปิดการตั้งค่า รวมถึงค้นการตั้งค่า Windows และ Control Panel ได้ด้วย

</div>
</div>

<div class="split">
<div class="prose">

พิมพ์ชื่อโฟลเดอร์ แล้วกด <kbd>F1</kbd> จะเปิดแผงพรีวิว ในภาพเป็นการดูรูปในโฟลเดอร์ wallpapers ไฟล์ภาพจะแสดงเป็นภาพใหญ่ ส่วนไฟล์ชนิดอื่นจะแสดงไอคอนใหญ่กับพาธเต็มครับ

ยังมีฟีเจอร์ลากไฟล์จากช่องค้นหาไปวางใน File Explorer หรือแม้แต่ Discord ได้ และ Dialog Jump ที่ค้นโฟลเดอร์แล้วกระโดดไปยังพาธนั้นในหน้าต่าง Open/Save As ได้เลย

</div>

## ปลั๊กอิน ธีม และภาษา

<div class="prose">

Flow Launcher มีร้านปลั๊กอินอยู่ในหน้า Settings เลือกดูและติดตั้งได้เลย หน้า GitHub ยกตัวอย่างปลั๊กอินที่ชุมชนทำไว้ เช่น SpotifyPremium, Clipboard+, Colors, GitHub และ Window Walker และเปิดให้เขียนปลั๊กอินเองได้หลายภาษา

ปรับแต่งหน้าตาได้ ทั้งขนาดหน้าต่าง แอนิเมชัน เสียง โหมดมืด และธีมจำนวนมาก (ทำธีมเองได้) รองรับหลายภาษา ผมดูรายการในหน้า GitHub แล้วยังไม่เห็นภาษาไทยในรายการที่ระบุ ถ้าจะใช้ต้องเผื่อว่าเมนูเป็นภาษาอังกฤษครับ นอกจากนี้ยังเป็นแอปแบบพกพา (portable) ได้ด้วย

</div>

</section>

<section class="section">

## ราคา ไลเซนส์ และรุ่นล่าสุด

<div class="prose">

Flow Launcher เป็นโอเพนซอร์สไลเซนส์ MIT ใช้ฟรี ผมดูข้อมูลไลเซนส์จากหน้า GitHub ของโปรเจกต์

รุ่นล่าสุดบน GitHub คือ **v2.1.4** วันที่ 20 กันยายน 2569 บันทึกรุ่นเขียนว่าแก้บั๊กหลายจุด เช่น การโหลดบุ๊กมาร์ก Firefox, ให้ช่องค้นหารับคีย์บอร์ดทันทีตอนเปิดเครื่อง, ปรับการรันคำสั่ง shell ที่มีพาธใส่เครื่องหมายคำพูด, ปรับการจับคู่ URL และแก้การค้นด้วยตัวย่อที่มีตัวเลข

**ระบบที่ใช้ได้:** Windows 10 ขึ้นไป · ไม่มีข้อมูลในหน้า GitHub ที่ผมอ่านว่ามีบน Microsoft Store จึงไม่ขอยืนยันเรื่องนี้ครับ

</div>

</section>

## วิธีติดตั้ง

<div class="prose">

ตามหน้า GitHub ติดตั้งได้ดังนี้

- **ไฟล์ติดตั้ง:** <a href="https://github.com/Flow-Launcher/Flow.Launcher/releases/latest/download/Flow-Launcher-Setup.exe" rel="noopener">Flow-Launcher-Setup.exe</a> หรือรุ่นพกพา <a href="https://github.com/Flow-Launcher/Flow.Launcher/releases/latest/download/Flow-Launcher-Portable.zip" rel="noopener">Flow-Launcher-Portable.zip</a>
- **Winget:** `winget install "Flow Launcher"`
- **Scoop:** `scoop install Flow-Launcher`
- **Chocolatey:** `choco install Flow-Launcher`

หน้า GitHub เตือนว่าตอนติดตั้งครั้งแรก Windows อาจขึ้นเตือนเรื่องความปลอดภัย เพราะโค้ดไม่ได้ลงลายเซ็น (not signed) ถ้าโหลดจากหน้า GitHub ของโปรเจกต์เอง ก็ติดตั้งต่อได้ และให้ใช้ช่องทางทางการเท่านั้น ระวังโดเมนที่หน้าตาคล้ายกัน เว็บทางการคือ <a href="https://www.flowlauncher.com" rel="noopener">flowlauncher.com</a> ครับ
