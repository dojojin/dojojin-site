## ShareX คืออะไร

<div class="split">
<div class="prose">

ShareX คือแอปจับภาพหน้าจอบน Windows ครับ หน้า GitHub เรียกตัวเองว่า "free and open source screenshot tool, screen recorder, file sharing tool and productivity application for Windows" พูดง่าย ๆ คือจับภาพ อัดจอ แชร์ไฟล์ ฟรีและโค้ดเปิด เว็บทางการบอกว่าไม่มีโฆษณา ส่วน README บอกว่าไม่ต้องสมัครบัญชี

จับภาพได้หลายแบบ ทั้งเต็มจอ เฉพาะหน้าต่างที่ใช้อยู่ เลือกเป็นช่วง หรือจับหน้าเว็บยาว ๆ แบบเลื่อนลง (scrolling) แล้วยังอัดวิดีโอกับ GIF ได้ด้วย

ในภาพคือหน้าต่าง Image Editor ของ ShareX แถบบนเป็นเครื่องมือเขียนทับภาพ แถบล่างเป็นปุ่มคัดลอก บันทึก พิมพ์ และอัปโหลด

เว็บทางการบอกว่ามีคนโหลดไปแล้วกว่า 34 ล้านครั้ง ตัวเลขนี้เขาประกาศเอง ผมหาที่อื่นมายืนยันไม่ได้นะครับ

ผมว่าเหมาะกับคนที่ต้องส่งภาพหน้าจอให้คนอื่นบ่อย ๆ เช่น ทีมซัพพอร์ต คนเขียนคู่มือ หรือคนที่ต้องแจ้งบั๊กให้โปรแกรมเมอร์ครับ

</div>

## ทำอะไรได้บ้าง

<div class="spec-list">

## อัปโหลดอัตโนมัติ: ค่าเริ่มต้นเก็บในเครื่อง

<div class="prose">

ใครกลัวภาพหน้าจอหลุดขึ้นเน็ต ผมเช็กให้แล้วครับ บอกก่อนว่าหน้าเอกสารทางการไม่ได้เขียนเรื่องค่าเริ่มต้นไว้ ผมเลยไปดูจากโค้ดต้นฉบับ ไฟล์ TaskSettings.cs ของรุ่น v22.4.0 บน GitHub แทน

<div class="news-cards">
<div class="news-card is-ok"><b>หลังจับภาพ</b>ค่าเริ่มต้นในโค้ดคือ CopyImageToClipboard กับ SaveImageToFile แปลว่าคัดลอกใส่คลิปบอร์ดแล้วเซฟเป็นไฟล์ ไม่มีการอัปโหลดอยู่ในค่าเริ่มต้น</div>
<div class="news-card is-warn"><b>ปลายทางภาพ</b>ในโค้ดตั้งปลายทางภาพเริ่มต้นไว้ที่ Imgur แต่จะถูกใช้ก็ต่อเมื่อเราเปิดการอัปโหลดเอง ใครเปิดแล้วควรเปลี่ยนปลายทางเป็นของตัวเอง เพราะภาพบน Imgur เป็นลิงก์สาธารณะ ใครได้ลิงก์ไปก็เปิดดูได้</div>
</div>

ถ้าอยากให้ภาพอยู่ในเครื่องอย่างเดียว เช็กตามนี้ครับ

<ol class="news-steps">
<li><b>เปิดการตั้งค่าหลังจับภาพ</b>ในหน้าต่างหลักของ ShareX ดูที่เมนู After capture tasks</li>
<li><b>เช็กว่าไม่ได้ติ๊ก Upload image to host</b>ถ้าไม่ติ๊ก ภาพจะไม่ถูกส่งออกไปไหน</li>
<li><b>ดูโฟลเดอร์ที่เซฟ</b>ภาพที่เซฟไว้เปิดดูได้จากเมนูของ ShareX</li>
</ol>

ชื่อเมนูข้างบนผมอิงจากรายการ after-capture tasks บนเว็บทางการ ยังไม่ได้ลงแอปแล้วกดดูเอง ถ้าในแอปหน้าตาไม่ตรง ให้ยึดตามที่เห็นในแอปครับ

</div>

</section>

## รุ่น 22.4.0 มีอะไรใหม่

<div class="prose">

changelog ของรุ่น 22.4.0 (8 พ.ย. 2569) มีของใหม่เยอะมาก ผมเลือกมาเฉพาะที่คนใช้ทั่วไปน่าจะเห็นชัดครับ

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-panel" /></svg><div><b>หน้าต่างหลัก</b>เลือกดูรายการแบบลิสต์หรือแบบภาพย่อได้ มีภาพตัวอย่างข้างรายการ และมีโหมด Compact</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-shapes" /></svg><div><b>ตัวแก้ภาพ</b>มีเครื่องมือปรับขนาดแคนวาส ขยายแคนวาสอัตโนมัติ และลูกศรแบบลากเส้นอิสระ</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-camera" /></svg><div><b>อัดจอ</b>รองรับ HDR tone mapping (ปรับภาพจากจอ HDR ให้แสดงบนจอทั่วไปได้) และสลับไปใช้ HEVC เองเมื่อพื้นที่ที่อัดใหญ่เกินกว่าที่ H.264 รับได้</div></div>
</div>

นอกจากนี้ยังมีหน้าต่าง after-capture แบบเลือกตามเป้าหมาย และหลังอัปเดตแอปจะถามว่าจะใช้ชุดไอคอนแบบไหน รายการเต็มดูที่ changelog ครับ

## วิธีติดตั้ง

<div class="prose">

<ol class="news-steps">
<li><b>ไปที่เว็บทางการ</b>เปิด <a href="https://getsharex.com" rel="noopener">getsharex.com</a> แล้วกดดาวน์โหลด ปุ่ม Setup กับ Portable จะพาไปหน้า GitHub releases</li>
<li><b>เลือกแบบที่ต้องการ</b>จะเอาตัวติดตั้ง (setup .exe) หรือ Portable (.zip) ที่แตกไฟล์แล้วรันได้เลยไม่ต้องติดตั้งก็ได้ ใครถนัด Store หรือ Steam ก็กดลิงก์จากเว็บทางการ</li>
<li><b>ตั้งภาษา</b>ถ้าอยากใช้ภาษาไทย ดูตัวเลือกภาษาในหน้าตั้งค่าของแอป</li>
</ol>

</div>

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่จับภาพหน้าจอวันละหลายรอบ และอยากเขียนลูกศรหรือเบลอข้อมูลก่อนส่ง ฟรีและโค้ดเปิด ลองได้ไม่เสียเงินครับ

ก่อนลงมี 3 อย่างที่ต้องดู เครื่องต้องเป็น Windows รุ่นที่รองรับ (ดูหมายเหตุในข้อมูลหลัก) ตัวเลือกในแอปเยอะมาก มือใหม่อาจงงช่วงแรก และถ้าเปิดอัปโหลดอัตโนมัติ ต้องรู้ว่าภาพไปอยู่ที่ไหน

บอกไว้ตรงนี้ว่าผมยังไม่ได้ลงแอปลองใช้เองนะครับ ข้อมูลทั้งหมดในข่าวนี้มาจากเว็บทางการ หน้า GitHub และโค้ดต้นฉบับ
