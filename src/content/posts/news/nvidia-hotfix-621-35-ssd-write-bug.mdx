## เกิดอะไรขึ้นกับไดรเวอร์ 621.14 และ 621.24

<div class="prose">

ผู้ใช้การ์ดจอ GeForce บน Windows พบปัญหาในไดรเวอร์ Game Ready รุ่น **621.14 และ 621.24** โดยโปรเซสเบื้องหลัง `NVDisplay.Container.exe` เขียนข้อมูลลงไฟล์ log ชื่อ `nvlog.nvlgstg` (ในโฟลเดอร์ `C:\ProgramData\NVIDIA Corporation\nvtopps\nct\` ตามที่ Windows Latest รายงาน) ซ้ำ ๆ อย่างต่อเนื่องแม้เครื่องจะอยู่เฉย ๆ ไม่ได้เล่นเกม

<div class="news-stats">
<div class="news-stat"><b>สูงสุด ~30 GB/ชม.</b>ปริมาณเขียนลง SSD ที่ผู้ใช้รายงาน (รุ่น 621.24)</div>
<div class="news-stat"><b>Bug 7116722</b>รหัสปัญหาในบันทึกของ NVIDIA</div>
<div class="news-stat"><b>621.01</b>รุ่นก่อนหน้า ที่ผู้ใช้ทดสอบแล้วไม่เจอบั๊กนี้</div>
</div>

ตัวเลขเหล่านี้เป็นที่ผู้ใช้วัดเอง ไม่ใช่ตัวเลขจาก NVIDIA เช่นผู้ใช้รายหนึ่งวัดได้ 515 MB ใน 5 นาทีบนรุ่น 621.14 เทียบกับไม่ถึง 2 MB บนรุ่น 621.01 และไม่ใช่ทุกเครื่องที่เจอ ผลคือค่าเขียนสะสมของ SSD (TBW คือปริมาณข้อมูลรวมที่ SSD รับเขียนได้ตลอดอายุ) วิ่งขึ้นเร็วโดยไม่จำเป็นครับ แต่รายงานที่ผมเปิดอ่านยังไม่ได้ยืนยันว่ามี SSD เสียหายจริง

</div>

## Hotfix 621.35 แก้ได้แค่ไหน และควรทำอย่างไร

<div class="split">
<div class="prose">

วันที่ 20 พฤศจิกายน 2569 NVIDIA ออกไดรเวอร์ **GeForce Hotfix 621.35** (สร้างต่อจาก 621.24 ตามที่ Notebookcheck รายงาน) เพื่อแก้ Bug `7116722` ซึ่งเป็นรายการแก้ไขเดียวในรุ่นนี้ โดยต้องดาวน์โหลดเองจากหน้า Customer Care ของ NVIDIA ครับ หน้าเดียวกันนี้ระบุว่า Hotfix เป็นรุ่นเบต้า ใช้เสริมและให้ใช้ตามสภาพ (as-is) ผ่านการทดสอบคุณภาพแบบย่อ ไม่ได้ผ่านการรับรอง WHQL (ใบรับรองไดรเวอร์ของ Microsoft) และ "ทางที่ปลอดภัยที่สุดคือรอไดรเวอร์ WHQL ตัวถัดไป"

ผู้ใช้ Reddit รายหนึ่ง (การ์ด RTX 4090) ที่ Droidsans อ้างถึง ทดสอบ 621.35 พบว่าชั่วโมงแรกเขียนแค่ราว 90 KB แต่เปิดทิ้งไว้ข้ามคืน 9 ชั่วโมงเขียนราว 40.85 GB (เฉลี่ยราว 4.5 GB/ชม.) เป็นผลทดสอบจากผู้ใช้รายเดียว จึงยังสรุปไม่ได้ว่าทุกเครื่องเป็นแบบนี้

**อัปเดต 26 พ.ย.:** NVIDIA ออก **GeForce Game Ready 621.40 WHQL** เมื่อ 24 พ.ย. 2569 Release Notes ของรุ่นนี้ (เอกสาร RN-08399-621.40 บน download.nvidia.com) ในหัวข้อ Fixed General Bugs มีรายการ "Excessive writes to file nvlog.nvlgstg may occur in background. [7116722]" ซึ่งเป็นหมายเลขบั๊กเดียวกับที่ Hotfix 621.35 แก้ ผมเปิดอ่านเอกสารนี้เองแล้ว แต่ยังไม่ได้ทดสอบว่าเครื่องจริงหายเขียนหรือไม่ ถ้าใครใช้ 621.14/621.24/621.35 อยู่ การอัปเป็น 621.40 WHQL จึงเป็นทางที่ตรงกับคำแนะนำของ NVIDIA ที่ให้รอรุ่น WHQL ครับ

ถ้าสงสัยว่าเครื่องเราเป็น ลองเช็กใน Task Manager / Resource Monitor ว่า `NVDisplay.Container.exe` เขียนดิสก์ต่อเนื่องตอนเครื่องว่างไหมครับ Droidsans แนะนำให้ถอยไป **621.01** (ออกเมื่อ 21 ต.ค. 2569) แต่ Notebookcheck เตือนว่าบน RTX 50 การถอยไป 621.01 อาจทำให้ปัญหาวิดีโอค้างและจอดำกลับมา (NVIDIA บอกว่ารุ่น RTX 50 ไม่โดนบั๊กเขียนไฟล์นี้ ตามที่ Droidsans รายงาน) ดังนั้นการถอยรุ่นควรตัดสินใจตามการ์ดที่ใช้
