## PowerToys คืออะไร

<div class="split">
<div class="prose">

PowerToys คือชุดเครื่องมือเสริมของ Windows จาก Microsoft เองครับ หน้าเอกสารบอกว่าเป็นยูทิลิตีฟรีและโอเพนซอร์ส สำหรับคนที่อยากใช้ Windows ให้คล่องขึ้น เช่น

- จัดหน้าต่างให้เป็นระเบียบ
- รีแมปแป้นพิมพ์
- เปลี่ยนชื่อไฟล์ทีละเยอะ ๆ
- ก๊อปข้อความจากรูป

ไลเซนส์เป็น MIT ตามที่หน้า GitHub ระบุ ลงตัวเดียวได้หลายเครื่องมือ เปิดปิดทีละอันได้ตามใจ ไม่ต้องใช้ทุกอย่างครับ

**เครื่องที่ใช้ได้** (ตามหน้า Install)

- Windows 11 หรือ Windows 10 เวอร์ชัน 2004 (build 19041) ขึ้นไป
- ตัวประมวลผล 64 บิต x64 หรือ ARM64
- ตอนติดตั้งจะมี WebView2 Runtime ให้ด้วย

</div>

## ติดตั้งยังไง

<div class="split">
<figure class="split-fig"><img src="/media/posts/news/powertoys-windows-app-review/igv-2.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกวิธีติดตั้ง PowerToys 3 วิธีหลัก คือ GitHub โหลดไฟล์ .exe, Microsoft Store ค้นหา PowerToys และ winget พิมพ์คำสั่งบรรทัดเดียว winget install --id Microsoft.PowerToys --source winget มี Chocolatey และ Scoop เป็นทางเลือกจากชุมชน" /></figure>
<div class="prose">

Microsoft แนะนำให้ติดตั้งจาก GitHub หรือ Microsoft Store ครับ เลือกทางเดียวพอ

1. **GitHub** เข้าหน้า <a href="https://github.com/microsoft/PowerToys/releases" rel="noopener">releases</a> เปิดส่วน Assets แล้วโหลด `PowerToysSetup-…-x64.exe` (หรือ `arm64` ถ้าเครื่องเป็น ARM) เปิดไฟล์แล้วทำตามหน้าจอ
2. **Microsoft Store** ค้นหา PowerToys แล้วกดติดตั้ง
3. **winget** เปิด PowerShell แล้วพิมพ์ `winget install --id Microsoft.PowerToys --source winget`

ข้อควรรู้เพิ่มเติม

- ที่ GitHub มีไฟล์สองแบบ **Per User** ติดตั้งให้ผู้ใช้คนเดียว ส่วน **Machine wide** ติดตั้งให้ทุกบัญชีในเครื่อง ทั้งสองแบบอัปเดตได้ปกติ
- ทางเลือกจากชุมชนมี Chocolatey (`choco install powertoys`) และ Scoop

ติดตั้งเสร็จจะมีหน้าต่างแนะนำแต่ละเครื่องมือขึ้นมา หน้าตั้งค่าเปิดได้จากไอคอนใน system tray ครับ แอปเช็กอัปเดตเองได้ หรือจะกดเช็กเองในหน้าตั้งค่าก็ได้

</div>

## Command Palette ช่องค้นหาลัดตัวใหม่

<div class="split">
<div class="prose">

Command Palette คือช่องค้นหาที่เด้งขึ้นกลางจอ ใช้เปิดแอป รันคำสั่ง ค้นไฟล์ คิดเลข หรือสลับหน้าต่าง กด <kbd>Win</kbd>+<kbd>Alt</kbd>+<kbd>Space</kbd> แล้วพิมพ์ได้เลยครับ

ในภาพคือหน้าแรกของ Command Palette มีรายการอย่าง All Apps, Run commands, Calculator และ Search files ให้เลือก

ตัวอย่างการพิมพ์ จากหน้าเอกสารของ Microsoft

- ชื่อแอป แล้วกด <kbd>Enter</kbd> เพื่อเปิด
- `>` ตามด้วยคำสั่ง เช่น `> cmd`
- `??` ตามด้วยคำค้น เพื่อค้นเว็บด้วยเบราว์เซอร์หลัก
- `23*47` หรือ `=` ตามด้วยสมการ เพื่อคิดเลข
- `$` ตามด้วยชื่อหน้าตั้งค่า เช่น `$ display`

อยากได้ความสามารถเพิ่ม มีส่วนเสริม (extensions) จากชุมชนให้ลงจาก Extension Gallery ในหน้าตั้งค่าด้วยครับ

</div>

- ลากเรียงลำดับได้ และเปิดโชว์คำสั่งที่เพิ่งใช้ไว้ข้าง ๆ ก็ได้

## PowerToys Run ตัวเดิมที่ยังใช้ได้

<div class="split">
<div class="prose">

หน้าเอกสารของ Run มีหมายเหตุว่า Run กำลังจะอัปเกรดเป็น v2 และชี้ว่า Command Palette คือวิวัฒนาการของ Run ผมเลยแนะนำว่า ถ้าเพิ่งเริ่ม ลอง Command Palette ก่อน ส่วนใครชิน Run อยู่แล้ว ใช้ต่อได้ครับ

## FancyZones แบ่งหน้าจอเป็นโซน

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/powertoys-windows-app-review/img-5.jpg" width="1600" height="900" loading="lazy" alt="ภาพ FancyZones ตอนลากหน้าต่าง Command Prompt โซนหมายเลข 1, 2 และ 3 ปรากฏเป็นสีฟ้าบนหน้าจอที่เปิดโค้ดอยู่" /></div><figcaption><span class="news-fig__credit">ภาพ: Microsoft Learn · <a href="https://learn.microsoft.com/en-us/windows/powertoys/fancyzones" rel="noopener">learn.microsoft.com</a></span></figcaption></figure>
<div class="prose">

FancyZones ให้เราแบ่งจอเป็นโซน แล้วลากหน้าต่างไปวางให้พอดีโซนครับ เหมาะกับจอกว้างที่อยากเปิดหลายหน้าต่างพร้อมกัน

วิธีใช้ตามหน้าเอกสาร

1. กด <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>`</kbd> เพื่อเปิดตัวแก้ไขเลย์เอาต์ แล้วเลือกแบบสำเร็จรูป
2. กด <kbd>Shift</kbd> ค้างไว้ระหว่างลากหน้าต่าง โซนจะขึ้นมา ปล่อยหน้าต่างลงในโซนที่ต้องการ
3. ถ้าเปิด Override Windows Snap ไว้ ใช้ <kbd>Win</kbd>+ลูกศรย้ายหน้าต่างระหว่างโซนได้

ในภาพคือโซนหมายเลข 1 ถึง 3 ที่ขึ้นตอนลากหน้าต่างครับ

</div>
</div>

<div class="split">
<div class="prose">

อยากได้เลย์เอาต์ของตัวเอง กด Create new layout ครับ มีสองแบบ

- **Grid** เริ่มจากสามคอลัมน์ แล้วแบ่งหรือรวมโซน และลากเส้นแบ่งได้ ขนาดปรับตามจออัตโนมัติ
- **Canvas** เป็นโซนอิสระที่ซ้อนกันได้

ในภาพคือตัวแก้ไขแบบ Grid ที่แบ่งโซน 1 กับ 2 ฝั่งซ้ายด้วยเส้นกลาง

สลับเลย์เอาต์เร็ว ๆ

- เลย์เอาต์ที่ตั้งเลขลัดไว้ สลับได้ด้วย <kbd>Win</kbd>+<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+เลข (ต้องเปิด quick layout switch ก่อน)
- รุ่น 0.102 เพิ่มการหมุนล้อเมาส์ตอนลากหน้าต่างเพื่อสลับเลย์เอาต์ (ปิดอยู่เป็นค่าเริ่มต้น)

</div>

## Text Extractor ก๊อปข้อความจากรูปและวิดีโอ

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/powertoys-windows-app-review/img-7.jpg" width="400" height="266" loading="lazy" alt="ภาพ Text Extractor ตัวอย่างหน้านิตยสารมีข้อความ Experiences built for focus ที่ถูกเลือก และหน้าต่าง Notepad แสดงข้อความเดียวกันที่ก๊อปมา" /></div><figcaption><span class="news-fig__credit">ภาพ: Microsoft · <a href="https://learn.microsoft.com/en-us/windows/powertoys/" rel="noopener">learn.microsoft.com</a></span></figcaption></figure>
<div class="prose">

Text Extractor อ่านตัวหนังสือบนหน้าจอด้วย OCR (ระบบอ่านตัวอักษรจากภาพ) แล้วส่งเข้าคลิปบอร์ดให้ครับ ไม่ว่าจะอยู่ในรูป วิดีโอ หรือหน้าต่างที่ก๊อปไม่ได้ ในภาพคือข้อความบนหน้านิตยสารที่ถูกดึงมาวางใน Notepad

1. กด <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> จะมีฉากครอบหน้าจอ
2. กดเมาส์ซ้ายค้างแล้วลากครอบข้อความ
3. ปล่อยเมาส์ ข้อความจะถูกก๊อปให้ ไปกดวางที่ไหนก็ได้

ข้อควรรู้

- กด <kbd>Esc</kbd> เพื่อยกเลิก
- กด <kbd>Shift</kbd> ค้างเพื่อย้ายกรอบแทนการปรับขนาด
- ภาษา OCR ขึ้นกับภาษาของ Windows และต้องลงชุดภาษา OCR ไว้
- ผลลัพธ์อาจไม่เป๊ะ ควรอ่านตรวจอีกรอบ
- ถ้าจะแคปภาพหน้าจอ เอกสารแนะนำให้ใช้ Snipping Tool ส่วน Text Extractor ไว้ดึงข้อความ

## Color Picker เลือกสีจากหน้าจอ

<div class="split">
<div class="prose">

Color Picker ดูดสีจากจุดไหนก็ได้บนหน้าจอครับ กด <kbd>Win</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> แล้วคลิกที่สี รหัสสีจะถูกก๊อปไว้ในรูปแบบที่ตั้งไว้ (ค่าเริ่มต้นคือ HEX)

ในภาพคือกำลังชี้สีบนหน้าจอ มีชื่อสีและรหัสโชว์ข้างเคอร์เซอร์ อยากเห็นละเอียดขึ้น เลื่อนล้อเมาส์ขึ้นเพื่อซูมได้

ปุ่มเมาส์ค่าเริ่มต้น (ปรับได้ในหน้าตั้งค่า)

- คลิกซ้าย: เลือกสีและเปิดตัวแก้ไข
- คลิกล้อกลาง: เลือกสีแล้วปิด
- คลิกขวา: ปิดโดยไม่ก๊อป

## PowerRename เปลี่ยนชื่อไฟล์ทีละเยอะ ๆ

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/powertoys-windows-app-review/img-15.jpg" width="1598" height="1080" loading="lazy" alt="ภาพหน้าต่าง PowerRename ฝั่งซ้ายมีช่องค้นหาและตัวเลือก Use regular expressions ฝั่งขวามีตารางชื่อเดิมและชื่อใหม่ของไฟล์ พร้อมปุ่ม Apply" /></div><figcaption><span class="news-fig__credit">ภาพ: Microsoft Learn (เฟรมจากภาพเคลื่อนไหว) · <a href="https://learn.microsoft.com/en-us/windows/powertoys/powerrename" rel="noopener">learn.microsoft.com</a></span></figcaption></figure>
<div class="prose">

PowerRename เปลี่ยนชื่อไฟล์หลายไฟล์ในทีเดียวครับ ค้นแล้วแทนที่ได้ ใช้ regular expression ได้ มีพรีวิวให้ดูผลก่อนเปลี่ยนจริง และย้อนกลับได้

1. เลือกไฟล์ใน File Explorer แล้วคลิกขวา เลือก Rename with PowerRename
2. ใส่ข้อความที่ค้นในช่อง Search for และข้อความใหม่ในช่อง Replace with
3. ดูตารางพรีวิวชื่อเดิมกับชื่อใหม่ (แบบในภาพ) แล้วกด Apply

ตัวเลือกที่ใช้บ่อย

- Match all occurrences แทนที่ทุกที่ที่เจอ ไม่ใช่แค่ที่แรก
- Case sensitive
- เลือกว่าจะแก้เฉพาะชื่อไฟล์หรือนามสกุล

ถ้าเปลี่ยนผิด กด <kbd>Ctrl</kbd>+<kbd>Z</kbd> ใน Explorer เพื่อย้อนได้ครับ

## รุ่น 0.102 มีอะไรใหม่

<div class="split">
<figure class="split-fig"><img src="/media/posts/news/powertoys-windows-app-review/igv-3.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกของใหม่ใน PowerToys 0.102 Mouse Button Lock ค้างปุ่มเมาส์ไว้, CursorHide ซ่อนเคอร์เซอร์, Command Palette ชั้นทางลัด Alt+1 ถึง 9, ZoomIt พูดอธิบายตอนแคป, Keyboard Manager รีแมปแตะปุ่มเดียว และเครื่องมือบรรทัดคำสั่ง" /></figure>
<div class="prose">

รุ่น 0.102 ออกวันที่ 21 ตุลาคม 2569 ครับ ไฮไลต์ตามบันทึกรุ่นมี

- เครื่องมือเมาส์ใหม่สองตัว
- ชั้นทางลัดของ Command Palette
- การพูดอธิบายตอนแคปใน ZoomIt
- เครื่องมือบรรทัดคำสั่งชุดใหม่
- ปรับ Keyboard Manager

ของใหม่อื่น ๆ ที่บันทึกรุ่นระบุ

- FancyZones: หมุนล้อเมาส์ตอนลากหน้าต่างเพื่อสลับเลย์เอาต์
- Peek: พรีวิว SQLite ข้อมูลโฟลเดอร์ และ <kbd>Alt</kbd>+<kbd>←</kbd> <kbd>→</kbd> เลื่อนไฟล์
- Screen Ruler: วัดเป็นพิกเซลที่ไม่ขึ้นกับสเกลจอ
- Environment Variables: ปุ่ม Remove duplicates ล้างค่าซ้ำใน PATH
- Grab and Move: ยกเว้นบางแอปได้
- Awake: ให้ Windows ดับจอตอนล็อกเครื่องได้โดยไม่ตัดการกันเครื่องหลับ

</div>
</div>

<div class="split">
<div class="prose">

**Mouse Button Lock** (ในภาพ) ช่วยตอนต้องลากหรือคลุมเลือกนาน ๆ ครับ กดปุ่มเมาส์ค้างสักครู่แล้วปล่อย Windows จะถือว่าปุ่มยังกดอยู่ จนกว่าเราจะคลิกปุ่มใดก็ได้ บันทึกรุ่นบอกว่าเหมาะกับเกม งานโปรแกรมมืออาชีพ และคนที่กดปุ่มเมาส์ค้างนาน ๆ ลำบาก

<section class="section">

## รุ่นล่าสุด 0.102.3101

<div class="prose">

รุ่นเสถียรล่าสุดคือ **v0.102.3101** วันที่ 6 พฤศจิกายน 2569 เป็นรุ่นแก้ด่วน (hotfix) ของ 0.102 บันทึกรุ่นสรุปไว้สามเรื่อง

- File Explorer: จัดการตัวสร้างภาพขนาดย่อที่ค้างได้ดีขึ้น แยกการขอไฟล์ SVG พร้อมกัน และคงรูปแบบ SVG กับชื่อไฟล์ STL แบบ UTF-8
- General: อัปเดต telemetry เป็นรุ่น 2.0.5 และคืนการส่งข้อมูลวินิจฉัยแบบเลือกได้ โดยไม่เปลี่ยนค่าที่ผู้ใช้ตั้งไว้
- Mouse Without Borders: แก้การจับคู่ล้มเหลวที่อาจขึ้นข้อความลายเซ็นไม่น่าเชื่อถือในบิลด์ที่ลงนามแล้ว

ใครลงไว้แล้ว อัปเดตผ่านหน้าตั้งค่าของ PowerToys ได้เลยครับ

</div>

</section>

## ใครควรใช้

<div class="prose">

- คนใช้ Windows ทำงานทุกวัน และอยากได้เครื่องมือเล็ก ๆ ที่ช่วยประหยัดเวลา โดยไม่ต้องหาแอปแยกทีละตัว
- คนที่ใช้จอกว้างหรือหลายจอ เริ่มจาก FancyZones กับ Always On Top ก่อน
- คนที่ต้องจัดไฟล์และรูปเยอะ ๆ PowerRename, Image Resizer และ Peek คุ้มมาก
- ไม่ต้องเปิดทุกเครื่องมือ เลือกเปิดเฉพาะที่ใช้ในหน้าตั้งค่าได้ครับ
