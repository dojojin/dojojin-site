## จุดเด่นใน Visual Studio Code 1.148 (25 พ.ย. 2569)

<div class="split">
<div class="prose">

Microsoft ปล่อย **Visual Studio Code 1.148** เวอร์ชันเสถียรเมื่อวันที่ 25 พฤศจิกายน 2569 โดยเน้นปรับปรุงการทำงานของระบบ Agent และ Remote Workspace ให้เสถียรและเร็วขึ้นกว่าเดิมครับ

<div class="news-stat"><b>Dev Container</b>สร้างสภาพแวดล้อม Linux แยกให้แต่ละงานได้ทันที</div>

### เบื้องหลังการปรับความเร็ว Agent Host
ทีมพัฒนา VS Code ระบุว่าหลังจากย้ายระบบการทำงานของ Agent มาอยู่บน **Agent Host** แบบใหม่ หลายคนบ่นว่าช่วงเริ่มตอบช้ากว่ารุ่นเดิม ในเวอร์ชัน **1.148** จึงปรับจูนจนเวลาเริ่มตอบเร็วขึ้น **30%** และห่างจากความเร็วของระบบเก่าเหลือเพียงราว **5%** เท่านั้น ส่วนฟีเจอร์ `sessions.keepAwakeWhileWorking` จะช่วยสั่งไม่ให้เครื่อง host เข้าโหมด idle-sleep ระหว่างที่ Agent กำลังรันงานยาวๆ แบบไม่ต้องเฝ้าหน้าจอครับ
