## Notepad++ คืออะไร

<div class="prose">

Notepad++ คือโปรแกรมแก้ไขข้อความ (text editor) สำหรับ Windows ครับ ใช้แทน Notepad ที่ติดมากับเครื่องได้เลย แต่ทำได้มากกว่าเยอะ เปิดหลายไฟล์เป็นแท็บ ใส่สีให้โค้ดตามภาษา ค้นและแทนที่ได้ละเอียด

ผมว่าเหมาะกับคนที่ต้องแก้ไฟล์ตั้งค่า ไฟล์ log หรือโค้ดบ่อย ๆ แต่ไม่อยากเปิดโปรแกรมใหญ่อย่าง IDE มาแก้แค่ไฟล์เดียวครับ

</div>

</section>

## หน้าตาและการใช้งาน

<div class="split">
<div class="prose">

ในภาพคือ Notepad++ 8.9.1 บน Windows 11 แบ่งหน้าต่างเป็นสองฝั่ง ฝั่งซ้ายเปิดไฟล์ README ฝั่งขวาเป็นโค้ด PHP ของ MediaWiki แต่ละฝั่งมีแท็บของตัวเอง มีเลขบรรทัดด้านซ้าย และโค้ดมีสีตามภาษา อ่านง่ายกว่า Notepad เดิมเยอะ

ตรงบรรทัด 1204 มีรายการเติมคำอัตโนมัติเด้งขึ้นมา ใครแก้โค้ดบ่อย ๆ ตรงนี้ช่วยได้พอสมควรครับ

ภาพนี้เป็นรุ่น 8.9.1 เก่ากว่ารุ่นล่าสุดนิดหน่อย ผมเลือกเพราะเป็นภาพใหม่และไลเซนส์ชัดที่สุดที่หาได้ หน้าตาหลักน่าจะไม่ต่างกันมากครับ

<div class="news-cards">
<div class="news-card is-ok"><b>เมนู Plugins Admin ในตัว</b>คู่มือบน npp-user-manual.org บอกว่าเข้าเมนู Plugins แล้วเลือก Plugins Admin ก็ดูรายการปลั๊กอินและติดตั้งเพิ่มได้เลย</div>
<div class="news-card is-warn"><b>ปลั๊กอินคือโค้ดของคนอื่น</b>ลงเท่าที่จำเป็น และเลือกตัวที่คนใช้เยอะครับ ขนาดปลั๊กอิน MIME Tools ที่มากับโปรแกรมเอง รุ่น 8.9.9 ยังต้องแก้ช่องโหว่เลย</div>

## มีอะไรใหม่ในรุ่น 8.9.9

<div class="prose">

8.9.9 คือรุ่นก่อนหน้า 8.9.9.1 ครับ หน้า Release บอกว่าอัปเดตเอนจินแสดงผลเป็น Scintilla 5.6.9 และ Lexilla 5.5.5 และค้นในหลายไฟล์ (Find in Files) ได้เร็วขึ้น

ฝั่งหน้าตาก็ปรับหลายจุด เลือกฟอนต์และขนาดของหน้าต่างโต้ตอบได้ ย้ายแถบ Incremental Search ไปไว้ด้านบนได้ และแผง Clipboard History ดีขึ้น นอกจากนี้ยังตั้งภาษาที่ผู้ใช้กำหนดเอง (UDL) เป็นภาษาเริ่มต้นของไฟล์ใหม่ได้ รองรับ Structured Text และแก้ memory leak

<div class="news-cards">
<div class="news-card is-warn"><b>แก้ช่องโหว่ความปลอดภัยหลายรายการ</b>ใครใช้รุ่นเก่ากว่านี้ ควรอัปเดตเป็น 8.9.9 ขึ้นไปครับ รายการที่แก้มี การตรวจผู้ส่งข้อความ WM_COPYDATA ที่ข้ามได้, การยกระดับสิทธิ์ผ่านคำสั่งปลั๊กอิน, ข้อมูลหน่วยความจำรั่ว (heap), การบันทึกไฟล์ชั่วคราวภายใต้ UAC (TOCTOU), การอ่านเกินขอบเขตผ่าน NPPM_MENUCOMMAND และ heap overflow ตอนถอดรหัส SAML ในปลั๊กอิน MIME Tools ตอนนี้หน้า Release ยังบอกว่ายังไม่ได้รับเลข CVE</div>
</div>

</div>

</section>

## เรื่องที่ควรรู้: เหตุการณ์ตัวอัปเดตถูกดักเมื่อปีก่อน

<div class="prose">

เรื่องนี้แก้ไปแล้ว แต่ใครเคยลงไว้นานก็ควรรู้ครับ

ตามประกาศทางการของผู้พัฒนา (กุมภาพันธ์ 2569) ตั้งแต่ราวมิถุนายน 2568 ผู้โจมตีเจาะระบบของผู้ให้บริการโฮสติ้งเดิมของเว็บ แล้วเปลี่ยนเส้นทางคำขออัปเดตของผู้ใช้บางส่วนไปยังตัวติดตั้งที่ถูกแก้ไข การเข้าถึงนั้นสิ้นสุดราววันที่ 2 ธันวาคม 2568

ผู้พัฒนาย้ำว่าปัญหาอยู่ที่ระดับโฮสติ้ง ไม่ใช่ในโค้ดของ Notepad++ ส่วนผู้โจมตีเป็นใคร นักวิจัยบางรายสงสัยว่าเป็นกลุ่มที่รัฐหนุนหลัง แต่ยังไม่มีการยืนยัน

หลังจากนั้นโปรเจกต์ย้ายไปโฮสต์ใหม่ และเพิ่มการป้องกันหลายชั้น ตัวอัปเดต (WinGup) ตรวจใบรับรองและลายเซ็นของตัวติดตั้งตั้งแต่รุ่น 8.8.9 ไฟล์ XML ของการอัปเดตก็มีลายเซ็น และรุ่น 8.9.2 (16 กุมภาพันธ์ 2569) บังคับตรวจทั้งหมดนี้ พร้อมแก้ CVE-2026-25926 ผมว่าโปรเจกต์รับมือได้จริงจังดีครับ

<div class="news-cards">
<div class="news-card is-ok"><b>สิ่งที่ควรทำ</b>โหลดจาก notepad-plus-plus.org หรือ GitHub ของโปรเจกต์เท่านั้น และอัปเดตเป็นรุ่นล่าสุดเสมอ ถ้าเคยใช้รุ่นเก่าช่วงมิถุนายนถึงธันวาคม 2568 ประกาศแนะนำให้พิจารณาติดตั้งใหม่จากเว็บทางการครับ</div>

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่แก้ไฟล์ข้อความเป็นประจำ เช่น ไฟล์ตั้งค่า log สคริปต์ หรือโค้ดเล็ก ๆ ครับ ฟรี ไม่หนักเครื่อง และทำได้มากกว่า Notepad เดิมเยอะ

ก่อนลงจำไว้ 2 อย่าง โหลดจากเว็บทางการเท่านั้น และใช้รุ่น 8.9.9 ขึ้นไป ส่วนใครเขียนโปรเจกต์ใหญ่เป็นหลัก คงอยากได้ editor ที่ทำได้มากกว่านี้

ขอบอกตรง ๆ ว่าผมยังไม่ได้ลงแอปลองใช้เองนะครับ ข้อมูลในข่าวนี้มาจากหน้าทางการ GitHub และคู่มือของโปรเจกต์
