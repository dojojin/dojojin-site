# งานสำหรับ Claude in Chrome: โพสต์รีวิว SlimQ F100 ลง Facebook

## กติกา (อ่านก่อนเริ่ม)
- โพสต์ในนามเจ้าของบัญชีที่ล็อกอินอยู่แล้วเท่านั้น ห้ามล็อกอิน ห้ามกรอกรหัสผ่าน
- **ห้ามกด "โพสต์" เอง** เตรียมทุกอย่างให้ครบ แล้วหยุดให้เจ้าของตรวจและกดเอง
- ใช้ข้อความตามไฟล์นี้ตรงตัว ห้ามแต่งตัวเลขหรือสเปกเพิ่ม
- กลุ่มเป้าหมาย (privacy) ใช้ค่าเดิมของบัญชี ไม่ต้องเปลี่ยน
- ถ้าหน้าเว็บ Facebook ไม่ตรงกับขั้นตอน (ปุ่มเปลี่ยนชื่อ/ตำแหน่ง) ให้หยุดและถามเจ้าของ

## ขั้นตอน
1. เปิด https://www.facebook.com/ กด "คุณกำลังคิดอะไรอยู่" เพื่อสร้างโพสต์
2. วางข้อความโพสต์ (ส่วน "ข้อความโพสต์" ด้านล่าง) ทั้งหมดลงช่องข้อความ
3. กด "รูปภาพ/วิดีโอ" แล้ว **ขอให้เจ้าของเลือกไฟล์ 14 รูป** จากโฟลเดอร์ `slimq-f100` (ชื่อไฟล์ขึ้นต้น 01–14) ตัวเลือกไฟล์ของระบบเป็นหน้าต่างนอกเบราว์เซอร์ รอจนรูปขึ้นครบ 14 รูป
4. กด "แก้ไขทั้งหมด" (Edit all) ตรวจลำดับรูปให้ตรง 01 → 14 ถ้าไม่ตรงให้ลากเรียงใหม่
5. ใส่คำบรรยายทีละรูปตามตาราง "คำบรรยายแต่ละรูป" (เทียบจากเลขชื่อไฟล์หรือภาพที่เห็น)
6. กด "เสร็จสิ้น" กลับมาหน้าสร้างโพสต์ ตรวจว่าลิงก์ dojojin.tech ขึ้นตัวอย่าง (ถ้าตัวอย่างลิงก์บังรูป ให้ปิดตัวอย่างลิงก์ด้วยปุ่ม ×)
7. **หยุด** แจ้งเจ้าของว่า "พร้อมโพสต์แล้ว รูปครบ 14 รูป ใส่คำบรรยายครบ ตรวจแล้วกดโพสต์ได้เลยครับ"
