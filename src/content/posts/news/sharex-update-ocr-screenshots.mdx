## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

ShareX ออกรุ่น **22.5.0** ครับ Changelog ทางการลงวันที่ 26 พฤศจิกายน 2569 ส่วนที่คนใช้จะรู้สึกที่สุดคือ OCR

ใครยังไม่รู้จัก ShareX อ่านแนะนำแอปตัวเต็มได้ที่ <a href="/news/sharex-windows-app-review/">แอปแนะนำ: ShareX จับภาพหน้าจอ อัดวิดีโอ ทำ GIF บน Windows</a> ครับ

รุ่นก่อนหน้า ShareX ใช้ OCR ที่มากับ Windows ซึ่งต้องลงชุดภาษาใน Windows ก่อนถึงจะอ่านภาษานั้นได้ รุ่นนี้เปลี่ยนเป็น PaddleOCR โดยทีมเขียนไว้ว่า "Replaced Windows OCR with AI powered PaddleOCR" แปลว่า เปลี่ยนจาก Windows OCR มาเป็น PaddleOCR ที่ใช้โมเดล AI

ทีมบอกด้วยว่าให้ผลแม่นกว่ามาก แต่ผมยังหาผลทดสอบความแม่นจากภายนอกไม่เจอครับ

## สิ่งที่เปลี่ยนในรุ่นนี้

<div class="split">
<div class="prose">

สิ่งที่เปลี่ยนเรื่อง OCR ตาม Changelog อยู่ในตารางครับ ทุกอย่างยังรันในเครื่อง ไม่ได้ส่งภาพขึ้นเซิร์ฟเวอร์ ตามที่ทีมเขียนไว้ว่า "everything still runs locally on your device" (ทุกอย่างยังรันในเครื่องของคุณ)

นอกจาก OCR ยังมี Pixel editor เครื่องมือวาดพิกเซลอาร์ตและทำแอนิเมชันสไปรต์ ปรับ image editor หลายจุด และ region capture (โหมดลากเลือกพื้นที่จับภาพ) ที่ทีมบอกว่าเปิดเร็วขึ้นราวสองเท่า รุ่นนี้ยังอัปเกรดโปรเจกต์เป็น .NET 11 และเอาช่องอัปเดตแบบ Dev ออกด้วย

## ภาษาไทย ระบบที่รองรับ และที่ดาวน์โหลด

<div class="split">
<div class="prose">

**ภาษาไทย:** Changelog บอกแค่ "กว่า 100 ภาษา" ไม่ได้ระบุชื่อภาษา ผมจึงยังยืนยันไม่ได้ว่า OCR รุ่นใหม่อ่านภาษาไทยได้หรือไม่ ตอนนี้ทีมยังไม่ได้ประกาศรายชื่อภาษาครับ (ตัวแอปมีเมนูภาษาไทยอยู่แล้ว แต่นั่นเป็นภาษาของหน้าจอแอป ไม่เกี่ยวกับ OCR)

**ราคาและใบอนุญาต:** ShareX ฟรี ไม่มีโฆษณา และเป็นโอเพนซอร์สภายใต้ GPL-3.0 ตามหน้าเว็บและไฟล์ LICENSE บน GitHub

**ระบบที่รองรับ:** รุ่น 22.5.0 มีไฟล์ให้โหลดเฉพาะ x64 (ตัวติดตั้งและแบบพกพา) ส่วน Windows ขั้นต่ำ ผมหาประกาศเฉพาะของรุ่น 22.5.0 ไม่เจอ สิ่งที่ยืนยันได้คือ Changelog รุ่น 18.0.0 ระบุว่า ShareX เลิกรองรับ Windows 7 และต้องใช้ Windows 10 แบบ 64 บิตขึ้นไป หน้าคู่มือ OCR บนเว็บยังเขียนข้อมูลของ Windows OCR แบบเดิมอยู่ ยังไม่ได้อัปเดตตามรุ่นนี้

**ดาวน์โหลด:** ทีมระบุช่องทางทางการ 4 ทาง คือ [เว็บ ShareX](https://getsharex.com/downloads), [GitHub Releases](https://github.com/ShareX/ShareX/releases/tag/v22.5.0), [Microsoft Store](https://apps.microsoft.com/detail/9nblggh4z1sp) และ [Steam](https://store.steampowered.com/app/400040/ShareX/) ผมแนะนำให้โหลดจากช่องทางเหล่านี้เท่านั้นครับ
