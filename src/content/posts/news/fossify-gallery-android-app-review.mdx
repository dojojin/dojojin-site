<div class="prose">

## ลบ EXIF และพิกัด GPS ออกจากรูป

<div class="prose">

รูปที่ถ่ายด้วยมือถือมักแนบข้อมูลที่เรียกว่า EXIF ไปด้วย มีทั้งรุ่นกล้อง วันเวลา และบางครั้งก็มีพิกัด GPS ว่าถ่ายที่ไหน

ส่งรูปให้คนแปลกหน้า หรือโพสต์สาธารณะโดยไม่ลบ ก็เท่ากับบอกที่อยู่ไปด้วยครับ DOJOJIN.TECH เองก็ล้างพิกัดออกก่อนขึ้นเว็บทุกรูป

README ของ Fossify Gallery เขียนว่า "Strip away EXIF metadata like GPS coordinates and camera details" ผมเลยไปเปิดซอร์สโค้ดดูว่าปุ่มนี้อยู่ตรงไหน

เจอว่าอยู่ในหน้าต่าง Properties (ภาษาไทยคือ "คุณสมบัติ") ปุ่มชื่อ "Remove EXIF" หรือ "ลบข้อมูล EXIF" ในภาษาไทย กดแล้วแอปจะถามยืนยันก่อนว่าจะลบค่า EXIF เช่นพิกัด GPS และรุ่นกล้อง

<ol class="news-steps">
<li><b>เปิดรูปแล้วเปิดหน้าคุณสมบัติ</b>ในหน้าดูรูปแตะไอคอนรูปตัว i ด้านบน หรือเมนูสามจุด แล้วเลือก Properties (ชื่อเมนูที่แน่นอนผมยังไม่ได้ลงแอปดูเอง)</li>
<li><b>กด ลบข้อมูล EXIF</b>ปุ่มอยู่ด้านล่างของหน้าต่าง ถ้าไม่เห็นปุ่ม ดูข้อจำกัดด้านล่าง</li>
<li><b>ยืนยัน แล้วเช็กผล</b>หลังลบ โค้ดสั่งให้แอปโหลดรายการคุณสมบัติใหม่ ดูอีกรอบว่าพิกัดหายไปหรือยัง</li>
</ol>

ข้อควรรู้ที่ผมอ่านจากโค้ดและหน้า issues บน GitHub ครับ

<div class="news-cards">
<div class="news-card is-warn"><b>ปุ่มไม่ได้ขึ้นทุกกรณี</b>จากโค้ด ปุ่มจะขึ้นเฉพาะรูปที่อยู่ในที่เก็บข้อมูลภายในเครื่อง ไม่ใช่รูปที่เปิดผ่านลิงก์แบบ content:// และต้องให้สิทธิ์เข้าถึงไฟล์ทั้งหมด (All files access) กับแอปก่อน รูปบนเมมโมรี่การ์ดเลยอาจไม่ขึ้นปุ่มนี้ ตรงกับ issue #60 บน GitHub ที่มีคนขอให้ลบ EXIF ในไฟล์บน SD card ได้ (ยังเปิดค้างตอนที่ผมเช็ก)</div>
<div class="news-card is-warn"><b>ลบที่ไฟล์ต้นฉบับเลย</b>จากโค้ด แอปลบค่า EXIF ที่ตัวไฟล์ตรง ๆ ไม่ได้ทำสำเนาใหม่ ถ้ายังอยากเก็บรูปที่มีพิกัดไว้ ให้สำรองไว้อีกชุดก่อน ข้อนี้ผมอ่านจากโค้ด ยังไม่ได้ลองกับรูปจริง</div>
<div class="news-card is-warn"><b>ไม่ลบอัตโนมัติตอนแชร์</b>มีคนขอฟีเจอร์ "ลบ EXIF อัตโนมัติตอนกดแชร์" ตั้งแต่ปี 2567 (issue #185) ตอนนี้ยังเปิดค้างอยู่ แปลว่าต้องกดลบเองก่อนส่งทุกครั้ง</div>
<div class="news-card is-bad"><b>มีคนรายงานว่าลบไม่หมด</b>issue #1214 (6 พ.ย. 2569, ยังเปิดอยู่ตอนที่ผมเช็ก) ผู้ใช้รายหนึ่งรายงานว่ารูป PNG ยังมีข้อมูลบางส่วนที่ระบุเครื่องเหลืออยู่หลังกดลบ อันนี้เป็นรายงานของผู้ใช้คนเดียว ผมไม่ได้ทดสอบซ้ำ ถ้าเป็นรูปที่ต้องระวังจริง ๆ ให้เช็กไฟล์หลังลบด้วยโปรแกรมดู EXIF ตัวอื่นอีกชั้น</div>
</div>

สรุปคือใช้เป็นด่านแรกได้ แต่อย่าเชื่อ 100% ครับ

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่อยากได้แกลเลอรีเรียบ ๆ ไม่มีโฆษณา ไม่ผูกคลาวด์ และใส่ใจเรื่องพิกัดในรูปก่อนส่งต่อครับ ฟรีและโค้ดเปิด ลองได้ไม่เสียเงิน
