## ภาพรวม

ระบบ AI inference แบบ self-hosted ที่รันบน GPU สำหรับผู้ใช้ทั่วไปทั้งหมด ไม่มี API key ไม่มีค่าใช้จ่ายรายครั้ง และไม่มีข้อมูลออกนอกเครื่อง ใช้ Ollama เป็นตัวรันโมเดล แล้วประกอบเครื่องมือที่เหมาะกับแต่ละงาน ได้แก่ หน้าแชต (Open WebUI), ค้นเว็บ (SearXNG) และผู้ช่วยเขียนโค้ด (Continue.dev)

## ทำไมต้องรันเอง

| | Cloud API | AI Stack |
|---|---|---|
| ความเป็นส่วนตัว | prompt ออกนอกเครื่อง | ทุกอย่างอยู่ในเครื่อง |
| ค่าใช้จ่าย | จ่ายตามการใช้งานรายเดือน | ซื้อฮาร์ดแวร์ครั้งเดียว |
| ใช้ได้เมื่อ | ผู้ให้บริการไม่ล่ม | แม้ไม่มีอินเทอร์เน็ต |
| เลือกโมเดล | ผู้ให้บริการเลือกให้ | เลือกเองได้ทั้งหมด |

## ใช้ทำอะไร

ใช้เป็นเครื่องมือประจำวัน: แชต, ช่วยเขียนโค้ด, วิเคราะห์เอกสาร และค้นคว้าด้วยผลค้นหาจากเว็บ
