## Keka คืออะไร

<div class="split">
<div class="prose">

Keka เป็นโปรแกรมจัดการไฟล์บีบอัดบน macOS ครับ งานหลักมีสองอย่าง คือรวมไฟล์หรือโฟลเดอร์เป็นไฟล์บีบอัด และแตกไฟล์ที่คนอื่นส่งมาให้ ลากไฟล์ไปวางบนหน้าต่าง Keka หรือไอคอนใน Dock ได้เลย

7z, ZIP และ RAR คือรูปแบบไฟล์บีบอัด ต้องดูแยกกันว่าโปรแกรม ‘สร้างได้’ หรือแค่ ‘เปิดได้’ ตัวอย่างที่ชัดที่สุดคือ Keka เปิดไฟล์ RAR ได้ แต่ในรายการรูปแบบที่สร้างได้บนเว็บผู้พัฒนาไม่มี RAR ครับ

ข้อมูลในโพสต์นี้อ้างอิงจากเว็บและคู่มือของผู้พัฒนาครับ

</div>

## รูปแบบไฟล์ ราคา และข้อจำกัด

<div class="prose">

<div class="table-frame">

| หัวข้อ | รายละเอียด |
| --- | --- |
| **แพลตฟอร์มที่รองรับ** | macOS (Apple Silicon & Intel) |
| **รุ่นที่ใช้อ้างอิง** | 1.6.8 จาก GitHub Releases |
| **ฟอร์แมตที่สร้างได้** | 7Z, ZIP, TAR, GZIP, BZIP2, XZ, LZIP, BROTLI, ZSTD, DMG, ISO |
| **ฟอร์แมตที่แตกได้** | 7Z, ZIP, RAR, TAR, GZIP, BZIP2, XZ, LZIP, ISO, CAB, MSI และอีกมากมาย |
| **การเข้ารหัสตามเว็บผู้พัฒนา** | 7z ใช้ AES-256 ส่วน ZIP ระบุ Zip 2.0 legacy ไม่ควรเหมารวมว่าไฟล์ทุกแบบใช้ AES-256 |
| **ราคา** | **ฟรี** เมื่อดาวน์โหลดจาก `keka.io` หรือ GitHub (รุ่น Mac App Store แบบเสียเงินเพื่อสนับสนุนผู้พัฒนา) |
| **ซอร์สโค้ด** | ไม่ได้เปิดซอร์สโค้ดของแอป ผู้พัฒนายืนยันเรื่องนี้ไว้บน GitHub แม้จะมี repository สาธารณะสำหรับปัญหา คู่มือ และไฟล์ดาวน์โหลด |

</div>

รุ่นใน Mac App Store เป็นอีกช่องทางสนับสนุนผู้พัฒนาครับ เว็บทางการบอกว่าเป็นแอปเดียวกัน แต่รับอัปเดตผ่าน App Store ส่วนราคาในร้านไทย ผมยังไม่ได้ยืนยัน ต้องดูตอนซื้ออีกครั้งครับ

</div>

</section>

## เริ่มใช้แบบง่าย ๆ

<div class="prose">

ผมสรุปจากคู่มือทางการไว้สามงานที่ใช้บ่อยครับ

<ol class="news-steps">
<li><b>รวมไฟล์ก่อนส่ง</b>เลือกชนิดไฟล์ใน Keka แล้วลากไฟล์หรือโฟลเดอร์ลงหน้าต่างหรือไอคอนใน Dock ถ้าปรับระดับการบีบอัดสูงขึ้น ไฟล์จะเล็กลงก็จริง แต่อาจต้องรอนานขึ้นด้วย</li>
<li><b>แตกไฟล์ที่ได้รับมา</b>ลากไฟล์บีบอัดไปวางบน Keka ได้เลย ถ้าตั้ง Keka เป็นแอปแตกไฟล์เริ่มต้นแล้ว ก็เปิดด้วยการดับเบิลคลิกไฟล์ได้</li>
<li><b>ใส่รหัสผ่านก่อนสร้างไฟล์</b>คู่มือระบุให้กรอกรหัสในช่อง Password และ Repeat สำหรับรูปแบบที่รองรับ เช่น 7z และ ZIP ส่วนตอนแตกไฟล์ที่มีรหัส โปรแกรมจะถามรหัสจากเรา</li>
</ol>

</div>

## เหมาะกับใคร

<div class="prose">

ใครต้องรับไฟล์หลายแบบ หรืออยากเลือกรูปแบบและรหัสผ่านของไฟล์ที่จะส่งเอง Keka มีตัวเลือกให้มากกว่าครับ แต่ถ้าเครื่องมือที่ใช้อยู่เปิดและบีบอัดงานได้ครบแล้ว ก็ไม่จำเป็นต้องเปลี่ยนแค่เพราะแอปนี้รองรับนามสกุลเยอะกว่า

ก่อนส่งงานให้คนอื่น ผมว่าถามผู้รับสักนิดว่าเปิดรูปแบบที่เราเลือกได้ไหม โดยเฉพาะไฟล์ที่ใส่รหัส และเก็บไฟล์ต้นทางไว้จนกว่าจะแน่ใจว่าผู้รับเปิดได้ครับ
