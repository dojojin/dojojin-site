## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

วันที่ 9 พฤศจิกายน 2569 Anthropic ประกาศ Claude Fable 5.2 และ Claude Mythos 5.2 ตามประกาศของบริษัท สองตัวนี้เป็นโมเดลเดียวกัน ต่างกันที่ Mythos ไม่มีตัวกันบางอย่างด้านไซเบอร์และชีววิทยา

Anthropic บอกว่า Fable 5.2 สร้างคำตอบเร็วขึ้นได้ถึง 30% เมื่อเทียบกับ Fable 5.1 และ Mythos 5.1 TechCrunch รายงานว่าราคาขาเข้าของ Fable ลดจากเดิม $10 เหลือ $8 ต่อล้านโทเค็น

โทเค็น พูดง่าย ๆ คือหน่วยนับข้อความที่ AI อ่านและเขียน ใช้คิดเงินครับ

</div>
<div class="note">

### สรุปสั้น

**ราคาปกติ:** $8 ขาเข้า / $40 ขาออก ต่อล้านโทเค็น

**Fast mode:** เร็วขึ้นได้ถึง 2.5 เท่า ราคา $16 / $80

**Model ID:** `claude-fable-5-2`

**มีบน:** Claude Platform, AWS, Google Cloud, Microsoft Azure

</div>
</div>

</section>

## Fable กับ Mythos ต่างกันอย่างไร

<div class="split">
<div class="prose">

Fable 5.2 มีตัวกันที่บล็อกงานเสี่ยงสูงด้านไซเบอร์และชีววิทยา ถ้าคำถามโดนบล็อก ระบบจะส่งไปให้โมเดลสำรองตอบแทน (Opus 4.8 สำหรับไซเบอร์ Opus 5 สำหรับชีววิทยา)

Mythos 5.2 คือโมเดลเดียวกันที่ไม่มีตัวกันบางส่วนนั้น ผู้ใช้ต้องสมัครผ่านโปรแกรมยืนยันตัวตน ได้แก่ Cyber Verification Program สำหรับผู้เชี่ยวชาญด้านความปลอดภัย และ Life Sciences Verification Program สำหรับนักวิจัยชีวศาสตร์ ลูกค้า Claude Enterprise ใช้ Mythos 5.2 ผ่าน Claude Security ได้ด้วย ส่วน fast mode ของ Mythos เปิดเฉพาะองค์กรที่อยู่ในโปรแกรมยืนยัน

ถ้าคุณไม่ได้ทำงานด้านนี้ ก็ใช้ Fable ตามปกติได้เลยครับ

</div>
<div class="note">

### ตัวเลขที่ Anthropic เลือกแสดง (Fable 5.2 เทียบ Opus 5.5)

**FrontierSWE v2 (เขียนโค้ดแบบ agent):** 69.9% เทียบ 62.3%

**AutomationBench (งานธุรกิจ):** 51.4% เทียบ 42.5%

**OSWorld 2.1 (ควบคุมคอมพิวเตอร์):** 89.3% เทียบ 87.2%

**Humanity's Last Exam (ใช้เครื่องมือ):** 74.2% เทียบ 67.7%

</div>
</div>

<div class="prose">

ตัวเลขเหล่านี้มาจาก Anthropic เองนะครับ ยังไม่มีการทดสอบจากภายนอกในข่าวนี้

</div>

## คนใช้งานและนักพัฒนาได้อะไร

<div class="split">
<div class="prose">

**ผู้ใช้ทั่วไป** ผู้สมัครแพ็กเกจเสียเงินบางแผนได้โควตา Fable เพิ่มในสัปดาห์นี้ (รีเซ็ตเพิ่ม 1-3 ครั้งตามอายุสมาชิก) และ Fable นับได้สูงสุด 50% ของโควตารายสัปดาห์บน Pro และที่นั่ง Team มาตรฐาน รายละเอียดดูที่หน้าประกาศของ Anthropic

**นักพัฒนาไทย** เรียกใช้ผ่าน API ด้วย model ID `claude-fable-5-2` หรือผ่านคลาวด์ที่ใช้อยู่แล้ว (AWS, Google Cloud, Azure) ได้ ราคาขาออก $40 ต่อล้านโทเค็นยังสูง ถ้างานไม่ซับซ้อนควรลองโมเดลเล็กกว่าก่อน แล้ววัดต้นทุนต่องานจริง อย่าดูแค่ราคาต่อโทเค็น

Fast mode แพงเป็น 2 เท่า ใช้เมื่อความเร็วคุ้มกับเงินเท่านั้น เช่น งานที่มีคนรอผลอยู่ครับ

</div>
<div class="note">

### ที่ TechCrunch เล่าเพิ่ม

**ZDR:** Fable 5.2 ใช้กับนโยบายไม่เก็บข้อมูล (zero data retention) ของลูกค้าองค์กรได้

**เรื่องความปลอดภัย:** Anthropic บอกว่าโมเดลสงสัยว่ากำลังถูกประเมินบ่อยขึ้น ทำให้คาดเดาพฤติกรรมจริงยากขึ้น
