## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

Alibaba ปล่อย Qwen4-Max เมื่อวันที่ 16 พ.ย. 2569 ครับ ข่าวแจกของ Alibaba Cloud เรียกว่าเป็นโมเดลที่ "most capable" (เก่งที่สุด) ในตระกูล Qwen จนถึงตอนนี้

ข่าวออกมาหลายวันแล้ว แต่ตอนนี้มีหน้าราคาของ Alibaba ให้เทียบแล้ว ผมเลยหยิบมาเขียน พร้อมแยกให้ชัดว่าตัวเลขไหนยืนยันได้ ตัวไหนเป็นคำอ้าง

ข่าวแจกระบุว่าใช้ได้ผ่าน QwenCloud ทั้ง Token Plan และ API รวมถึงแอป QwenWork และ QwenStudio

ตัวโมเดลรับภาพได้โดยตรง และมีหน้าต่างบริบท 1 ล้านโทเคน คือปริมาณข้อมูลที่ใช้ประกอบการตอบในแต่ละคำขอ โทเคนเป็นหน่วยที่โมเดลใช้ประมวลผล ไม่ใช่จำนวนคำหรือความจำถาวรครับ

</div>

## ตัวเลขที่ยืนยันกับหน้าทางการแล้ว

<div class="split">
<div class="prose">

ตัวเลขชุดนี้มาจากข่าวแจกของ Alibaba Cloud โดยตรงครับ พารามิเตอร์คือค่าที่โมเดลเรียนรู้ระหว่างฝึก จำนวนพารามิเตอร์บอกขนาดได้ส่วนหนึ่ง แต่ไม่ได้ยืนยันว่าโมเดลจะตอบดีกว่ารุ่นอื่นทุกงาน

แต่ Qwen4-Max ไม่ได้ใช้ทั้งก้อนทุกครั้ง มันใช้โครงสร้างแบบ Mixture-of-Experts (MoE) คือแบ่งโมเดลเป็น "ผู้เชี่ยวชาญ" หลายชุด แต่ละโทเคนเรียกใช้แค่บางส่วน Alibaba บอกว่าใช้จริงเพียง 71,000 ล้านต่อโทเคน น้อยกว่า Qwen3.8-Max ที่ขนาดรวมเท่ากัน 25%

ตัวเลข 2.4 ล้านล้านมาจากหน้าของ Alibaba เอง แต่ยังเป็นตัวเลขที่บริษัทแจ้ง ยังไม่มีผู้ตรวจอิสระครับ

</div>

## ราคา API เท่าไร

<div class="prose">

ราคาขึ้นกับภูมิภาคที่เลือกใช้ครับ ตัวเลขด้านล่างมาจากแถว qwen4-max ในหน้า "Model Invocation Pricing" ของ Alibaba Cloud Model Studio (ข้อมูล ณ 26 พ.ย. 2569 หน้านี้แจ้งว่าอัปเดตล่าสุด 26 พ.ย. 2569) คิดเป็นต่อล้านโทเคน

ข่าวแจกยังบอกอีกราคาหนึ่ง คือ $0.075 ต่อล้านโทเคน สำหรับขาเข้าที่แคชถูกใช้ซ้ำ (Implicit Cache Hit คือคำถามช่วงต้นซ้ำกับครั้งก่อน จนระบบดึงจากแคชได้)

ราคานี้มาจากข่าวแจก ซึ่งไม่ได้ระบุภูมิภาค จึงยังนำมาคิดรวมกับราคาสิงคโปร์ตรง ๆ ไม่ได้ครับ หน้า Model Studio อธิบายค่าแคชแยกไว้อีกส่วน ควรตรวจราคาในบริการและภูมิภาคที่ใช้ก่อนคำนวณค่าใช้จ่าย

เทียบกับรุ่นก่อน: ในหน้าราคาเดียวกัน qwen3.8-max ฝั่ง International อยู่ที่ $2 / $6 แปลว่า Qwen4-Max ถูกกว่า 25% ทั้งขาเข้าและขาออก (ผมคำนวณเอง) ตรงกับที่ TechNode พาดหัวว่า "lower API prices"

## อันดับและคะแนนทดสอบ เป็นคำอ้างของ Alibaba

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/alibaba-qwen4-max/arena.jpg" width="800" height="800" loading="lazy" alt="แผนภูมิแท่ง Code Arena WebDev จาก Arena แสดง Qwen4-Max (xHigh) อันดับ 6 ที่ 1,750 คะแนน" /></div><figcaption><span class="news-fig__credit">ภาพ: Arena (arena.ai) ตามที่ลงในข่าวแจก Alibaba Cloud · <a href="https://www.alibabacloud.com/press-room/alibaba-unveils-qwen4-max" rel="noopener">alibabacloud.com</a></span></figcaption></figure>
<div class="prose">

ข่าวแจกเขียนว่า Qwen4-Max "achieves top rankings across leading benchmarks" (ได้อันดับต้น ๆ ในการทดสอบชั้นนำ) โดยเฉพาะงานเขียนโค้ด งานแบบเอเจนต์ (AI ที่ทำงานหลายขั้นตอนต่อกันเอง) และการอ่านภาพ

ผมไม่ได้ทดสอบเอง และยังไม่เจอผลทดสอบอิสระที่ยืนยัน ส่วนนี้จึงเป็นคำอ้างของ Alibaba ทั้งหมดครับ

ที่เห็นเป็นรูปธรรมที่สุดคือแผนภูมิ Code Arena: WebDev ที่ Alibaba นำมาลงในหน้าข่าวแจกเอง ในภาพ Qwen4-Max (xHigh) ได้ 1,750 คะแนน อยู่อันดับ 6 ตามหลัง

- Claude Fable 5.2 (1,826)
- Claude Opus 5.5 (1,816)
- Claude Sonnet 5.5 (1,772)
- Gemini 4 Carbon (1,768)
- GPT-6 Astra (1,763)

สรุปง่าย ๆ คือ ไม่ได้ที่หนึ่ง แต่ห่างอันดับ 5 แค่ 13 คะแนน และในภาพแถบความคลาดเคลื่อนคาบเกี่ยวกัน (ข้อนี้ผมอ่านจากภาพเอง)

</div>
</div>

## น้ำหนักโมเดลเปิดไหม

<div class="prose">

เท่าที่ประกาศตอนนี้ Qwen4-Max ใช้ได้ผ่าน API และแอปของ Alibaba เท่านั้นครับ ข่าวแจกไม่ได้บอกว่าจะปล่อยน้ำหนัก (weights คือไฟล์โมเดลที่โหลดไปรันเองได้) ของตัว Max

ข่าวแจกบอกเพียงว่าจะปล่อยโมเดลขนาดเล็กกว่าในตระกูล Qwen4 แบบเปิดน้ำหนักเร็ว ๆ นี้ ยังไม่มีวันที่แน่นอน และไม่ได้ประกาศว่าจะเปิดน้ำหนักของ Max ด้วย ผมจึงยังไม่สรุปสถานะไลเซนส์ของ Max เกินกว่าที่บริษัทเขียนครับ

</div>

</section>

<section class="section">

## คนไทยเกี่ยวอะไร

<div class="prose">

ผมไม่พบข้อมูลเฉพาะของไทยครับ ทั้งราคาเป็นบาท ตัวแทนในไทย หรือการเปิดให้ใช้ในไทย

ที่เห็นจากหน้าราคาคือ ภูมิภาคสิงคโปร์ใกล้ไทยที่สุดในรายการ และมีทั้งราคา $1.5/$4.5 กับโควตาฟรี 1 ล้านโทเคน แต่ผมไม่ได้ตรวจว่าบัญชีที่สมัครจากไทยเลือกภูมิภาคไหนได้ หรือต้องใช้เอกสารอะไร

ผมยังไม่ได้ทดสอบว่า Qwen4-Max ตอบภาษาไทยดีแค่ไหน และข่าวแจกก็ไม่ได้พูดถึงภาษาไทย ผมว่าถ้าจะใช้งานภาษาไทยจริงจัง รอดูผลทดสอบอิสระก่อนจะดีกว่า ถ้ามีเมื่อไหร่ค่อยมาอัปเดตครับ

</div>
