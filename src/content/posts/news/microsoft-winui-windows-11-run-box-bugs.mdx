## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

ในงาน Microsoft Ignite 2026 มีเซสชันชื่อ "Building Windows apps with WinUI and agents" ผู้บรรยายคือ Jaylyn Barbee และ Beth Pan จากทีม Windows Developer Platform ครับ เซสชันนี้จัดวันที่ 18 พฤศจิกายน 2569 ตามเวลาสหรัฐฯ (ตรงกับราว 04:45 น. วันที่ 19 พฤศจิกายน เวลาไทย)

ช่วงท้ายเซสชัน ผู้บรรยายพูดว่า "We've heard you that there's many paper cuts on the WinUI platform. There's a lot of bugs." แปลว่า "เราได้ยินที่พวกคุณบอกมาแล้วว่า แพลตฟอร์ม WinUI มีรอยบาดเล็ก ๆ น้อย ๆ (paper cuts) เยอะ มีบั๊กเยอะ" ไฟล์คำบรรยายของคลิปที่ Microsoft เผยแพร่ไม่ได้ระบุว่าใครพูดประโยคนี้ ส่วน Windows Latest ระบุว่าเป็น Beth Pan ครับ

ประโยคถัดมาคือ "in the last couple years, we've really been like pounding down on these paper cuts" แปลว่า "ช่วงสองสามปีหลังเราจัดการรอยบาดพวกนี้อย่างหนัก" คือเป็นการยอมรับปัญหา พร้อมบอกว่ากำลังแก้อยู่

</div>

## WinUI คืออะไร และเกี่ยวกับกล่อง Run อย่างไร

<div class="split">
<div class="prose">

WinUI คือชุดเครื่องมือที่นักพัฒนาใช้วาดหน้าตาแอปบน Windows ครับ ปุ่ม เมนู ช่องกรอกข้อความ หน้าต่างที่ดูทันสมัยแบบ Windows 11 มาจากตรงนี้ ถ้ากรอบงานนี้มีบั๊ก แอปที่สร้างด้วยมันก็อาจพลอยมีอาการแปลก ๆ ตามไปด้วย

ทีม Windows Command Line ของ Microsoft เขียนในบล็อกเมื่อ 1 พฤษภาคม 2569 ว่ากล่อง Run ใหม่ "is a C#/WinUI 3 application" แปลว่า เป็นแอปที่เขียนด้วย C# และ WinUI 3 ส่วนในเซสชัน Ignite ผู้บรรยายก็เอ่ยว่า widgets และ "the new run experience" (กล่อง Run แบบใหม่) ย้ายมาใช้ WinUI แล้ว

</div>
<div>

<div class="news-stats">
<div class="news-stat"><b>94 ms</b>เวลาเปิดกล่อง Run ใหม่ (ค่ากลาง ตัวเลขของ Microsoft)</div>
<div class="news-stat"><b>103 ms</b>กล่อง Run แบบเก่า (ตัวเลขของ Microsoft)</div>

## ฟีเจอร์ที่รอนาน: InkCanvas

<div class="split">
<div class="prose">

Windows Latest ยกตัวอย่างว่า InkCanvas (พื้นที่ให้เขียนด้วยปากกาในแอป) รอนานราว 4 ปี โดยนับจากคำถามของนักพัฒนาในปี 2565 แต่ผมหาลิงก์ของคำถามนั้นไม่เจอครับ

ส่วนที่มีหลักฐานชัดคือ ต.ค. 2566 Microsoft ตอบในหน้า GitHub ว่า "inking are under investigation for 1.5" (ฟีเจอร์เขียนด้วยปากกากำลังอยู่ระหว่างศึกษาสำหรับรุ่น 1.5) และ 25 ส.ค. 2569 รุ่นทดลอง 2.4.1 ก็ออก InkCanvas, InkToolbar และ InkPresenter ให้ลองครับ

ในเซสชัน ผู้บรรยายบอกว่า TableView, ชาร์ต และ InkCanvas ยังเป็นรุ่นทดลอง และขอให้นักพัฒนาลองแล้วส่งความเห็น

## คนใช้ Windows 11 ในไทยควรรู้อะไร

<div class="prose">

สิ่งที่เซสชันยอมรับคือปัญหาของ WinUI โดยรวมครับ ไม่ได้บอกว่ากล่อง Run ใหม่มีบั๊กอะไรโดยเฉพาะ จึงยังบอกไม่ได้ว่าผู้ใช้จะเจออาการอะไร และผมยังไม่พบรายงานที่พูดถึงผู้ใช้ในไทยโดยตรง

ผมว่าข้อนี้น่าสนใจเพราะ Microsoft กำลังย้ายหน้าต่างเก่าของ Windows มาใช้ WinUI หลายจุด ถ้ากรอบงานดีขึ้น หน้าต่างพวกนั้นก็น่าจะลื่นขึ้น

ในเซสชัน Microsoft พูดถึงการเปิดซอร์ส WinUI ขึ้น GitHub การปรับประสิทธิภาพ การอุดช่องว่างของ API (ชุดคำสั่งที่แอปเรียกใช้) ด้านหน้าต่าง และคอนโทรลใหม่ว่าเป็นสิ่งที่กำลังทำอยู่
