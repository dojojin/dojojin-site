## คุณภาพเสียง

<div class="prose">

Default โทนออกทุ้มๆ ค่อนข้างมาทางเสียงทุ้ม หูฟังตัวนี้เน้นเสียงเบสครับ มีให้เลือกปรับ แบบ Pure Bass และ Deep Bass ยังไม่พอ คุณยังมาปรับ Dynamic Audio เพื่อเพิ่มเสียง Bass ได้อีก กระแทกแบบบึ้มบั้มมากครับ

</div>

</section>

<section class="section">

## Microphone และการสวมใส่

<div class="split">
<div class="prose">

### Microphone

ตัวนี้มี Microphone ทั้งหมด 6 ตัว (ข้างละ 3 ตัว) มี AI เข้ามาช่วย เสียงสนทนาชัดเจนดีครับ และมีระบบ ENC ช่วยตัดเสียงรบกวน โดยไมค์แต่ละตัวทำหน้าที่ต่างกันออกไป ในแต่ละข้าง

- **Talk MIC** : ไมโครโฟนรับเสียงพูดของผู้ใช้งาน
- **Feed Forward MIC** : ไมโครโฟนรับเสียงจากภายนอก
- **Feed Back MIC** : ไมโครโฟนลดเสียงสะท้อน (ในช่องหู)

**ตัวนี้ Mic ค่อนข้างดีครับ ไม่ขี้เหร่**

</div>
<div class="prose">

### FITTING : การสวมใส่

ตัวนี้สวมใส่สบายครับไม่เจ็บหู มีซิลิโคนมาให้อีกสองขนาด ใส่ฟังยาวๆ ได้สบายๆ ครับ หูฟังตัวนี้เบาครับ ไม่ทราบน้ำหนักก็จริง แต่ใส่สบายอยู่

</div>
</div>

</section>

<section class="section">

## ANC และ Transparency

<div class="split">
<div class="prose">

### ANC

ตัวนี้มีระบบ ANC ซึ่งปรับได้ 3 แบบหลักคือ

- **MAX** : ใช้กับสถานที่ ที่มีเสียงดังเป็นพิเศษ
- **Moderate** : ใช้กับสถานที่ มีเสียงดังเช่น บนถนน หรือในห้างฯ
- **Mild** : ใช้กับที่เงียบหน่อย เช่น บ้าน หรือ ออฟฟิศ

</div>
<div class="prose">

### Transparency / Ambient Mode

ทำได้ดีพอสมควรครับ โดยเมื่อเลือกแล้วจะมีตัวช่วยกรองเสียงลม และ ทำให้ได้ยินเสียงคุยกันเป็นปกติ เป็นธรรมชาติมากขึ้น (Enhance voices) เพราะฉะนั้นควรเปิดตามภาพครับ เสียงสะท้อนของหูฟังเวลาเคี้ยวอาหาร และ เดิน มีบ้าง แต่ทำได้ดีครับ

</div>
</div>

</section>

<section class="section">

## Control และ Application

<div class="split">
<div class="prose">

### CODECS

ตัวนี้รองรับ AAC, SBC เสียดายที่ไม่มี LDAC

### Control

ถือว่าเป็นหูฟังที่มี Control ได้น้อย มีแค่ แตะสองที แตะสามที และ แตะค้างไว้ครับ เสียดายที่ไม่มีเรื่อง Slide เพื่อคุมเสียง แต่สามารถตั้งค่าคุมเสียงได้ครับ

### Application & Seamless

ตัวนี้รองรับทั้ง iOS และ Android ครับ โดยแอปทั้งสอง Platform ทำงานได้ดีครับ และ ทำงานได้เท่ากันทุก Function ไม่มีที่ติครับ

</div>
<div class="prose">

### Features

- **Spatial Audio** : จำลองเสียง Surround Sound ก็มีกับเขาด้วย
- **MindFlow** : มันจะจำลองเสียงแวดล้อม เพิ่มอารมณ์ในการทำงานของเราครับ
- **Low Latency** : หรือ Game Mode นั่นแหละครับ ซึ่งเขาเคลมว่าดีเลย์ 45ms จากที่ลองมาก็ทำได้ดีครับ ไม่ดีเลย์มากขนาดที่ต้องรำคาญ

</div>
</div>
