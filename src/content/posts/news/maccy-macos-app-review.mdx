## Maccy คืออะไร

<div class="prose">

Maccy เป็นแอปจัดการคลิปบอร์ด (clipboard manager) บน macOS ครับ

คลิปบอร์ดคืออะไร? คือที่พักชั่วคราวที่เก็บสิ่งที่เราสั่งคัดลอก (Copy) ไว้ ปกติ Mac จำได้แค่ชิ้นล่าสุดชิ้นเดียว พอคัดลอกอันใหม่ อันเก่าก็หาย

Maccy จะเก็บประวัติสิ่งที่คัดลอกไว้ให้ แล้วเรียกกลับมาใช้ได้ภายหลัง หน้า GitHub สรุปว่า "a lightweight clipboard manager for macOS" (ตัวจัดการคลิปบอร์ดแบบเบาสำหรับ macOS) ส่วนเว็บทางการบอกว่ามันทำอยู่อย่างเดียว คือเก็บประวัติการคัดลอกให้หยิบใช้ได้ทันที "No fluff" (ไม่มีของแถม)

ผมว่าเหมาะกับคนที่ต้องคัดลอกไปวางบ่อย ๆ เช่น เขียนบทความ เขียนโค้ด หรือกรอกฟอร์มซ้ำ ๆ ครับ

</div>

</section>

## ใช้งานยังไง

<div class="split">
<div class="prose">

วิธีใช้พื้นฐานตามหน้า GitHub มีแค่นี้ครับ

<ol class="news-steps">
<li><b>เรียก Maccy</b>กด Shift + Command + C หรือคลิกไอคอนบนแถบเมนู</li>
<li><b>พิมพ์ค้นหา</b>พิมพ์คำที่อยากหาในประวัติ</li>
<li><b>เลือกรายการ</b>กด Enter หรือคลิกรายการ หรือกด Command + เลข เพื่อคัดลอกกลับมา</li>
<li><b>วางทันที</b>กด Option + Enter ถ้าอยากเลือกแล้ววางเลย หรือ Option + Shift + Enter ถ้าอยากวางแบบไม่เอาการจัดรูปแบบ (ตัวหนา สี ฯลฯ)</li>
</ol>

ภาพนี้เป็นภาพประกอบทางการของ Maccy ครับ ชี้ให้เห็นช่องค้นหา คีย์ลัดเลือกรายการ คำสั่งปักหมุดด้วย Option + P และเมนูล้างประวัติกับตั้งค่า

</div>

## ทำอะไรได้บ้าง

<div class="prose">

เว็บทางการสรุปจุดเด่นไว้ 6 ข้อครับ

<div class="news-cards">
<div class="news-card is-ok"><b>เบาและเร็ว</b>เว็บบอกว่าเปิดและค้นหาประวัติทั้งหมดได้ในเสี้ยววินาที</div>
<div class="news-card is-ok"><b>ใช้คีย์บอร์ดเป็นหลัก</b>พิมพ์สิ่งที่หาแล้วกด Enter ไม่ต้องจับเมาส์</div>
<div class="news-card is-ok"><b>เป็นส่วนตัว (ตามที่เว็บเขียน)</b>เว็บบอกว่าข้อมูลเก็บในเครื่อง ถ้าแอปจัดการรหัสผ่านลบรหัสที่คัดลอกออกจากคลิปบอร์ด Maccy ก็ไม่เก็บไว้ด้วย</div>
<div class="news-card is-ok"><b>หน้าตาแบบ macOS</b>ใช้ UI ของ macOS เอง เรียบง่าย</div>
<div class="news-card is-ok"><b>โอเพนซอร์ส</b>ไลเซนส์ MIT เว็บบอกว่าเปิดซอร์สโค้ดให้ตรวจสอบหรือแก้ได้</div>
<div class="news-card is-ok"><b>ปรับแต่งได้</b>หน้า App Store บอกว่าตั้งค่าได้ละเอียด และเชื่อมกับ Shortcuts actions (คำสั่งในแอป Shortcuts ของ Apple ที่ใช้ทำงานอัตโนมัติ) ได้</div>
</div>

หน้า GitHub ยังเขียนฟีเจอร์ไว้เพิ่มจากนี้ครับ

- ปักหมุดรายการไว้บนสุด (Option + P)
- ลบรายการเดียว (Option + Delete)
- ล้างประวัติที่ไม่ได้ปักหมุด (Option + Command + Delete)
- กดปุ่ม Option ค้างแล้วคลิกไอคอน เพื่อหยุดเก็บประวัติชั่วคราว

</div>

<div class="spec-list">

<ol class="news-steps">

เว็บทางการมีที่เดียวคือ maccy.app

## รุ่น 2.8.0 มีอะไรใหม่

<div class="prose">

บันทึกรุ่น 2.8.0 เพิ่มและแก้หลายอย่าง ผมเลือกที่น่าสนใจมาให้ครับ

<div class="news-cards">
<div class="news-card is-ok"><b>ปักหมุดลากจัดเรียงได้</b>ลากเรียงรายการที่ปักหมุดได้ และแก้ไขรายการที่ปักหมุดในหน้าตัวอย่างได้เลย (เอาหน้าตั้งค่า Pins ออกแล้ว)</div>
<div class="news-card is-ok"><b>รองรับ VoiceOver</b>เพิ่มการรองรับตัวอ่านหน้าจอ VoiceOver ของ macOS</div>
<div class="news-card is-ok"><b>OCR แม่นขึ้น</b>ปรับความแม่นของการอ่านข้อความจากภาพ ด้วยการตรวจภาษาอัตโนมัติ</div>
<div class="news-card is-ok"><b>แก้บั๊ก</b>หน่วยความจำรั่วจากทุกรายการในประวัติ เมนูแถบบนช้าเมื่อประวัติเยอะ และค้างบน macOS 26 เพราะอักขระพิเศษในชื่อรายการ</div>
</div>

ในบันทึกรุ่นยังมีอีกสองข้อครับ คือเลิกเก็บข้อมูล Safari WebArchives (ไฟล์ที่ Safari ใช้เก็บหน้าเว็บทั้งหน้า) และข้อมูลคลิปบอร์ดชนิดอื่นที่ไม่ได้เลือก และเพิ่มให้เมินแอปที่อยู่นอกโฟลเดอร์ /Applications

## ข้อควรรู้ก่อนใช้

<div class="prose">

<div class="news-cards">
<div class="news-card is-warn"><b>ต้อง macOS 14 ขึ้นไป</b>เครื่องที่ยังใช้ macOS 13 หรือเก่ากว่าลงรุ่นปัจจุบันไม่ได้</div>
<div class="news-card is-warn"><b>ประวัติอาจมีของสำคัญ</b>Maccy เก็บสิ่งที่คัดลอกไว้ในเครื่อง ถ้าคัดลอกข้อมูลอ่อนไหวบ่อย ให้ดูวิธีเมินบางชนิด (ignore) ในหน้า GitHub เช่น หยุดเก็บชั่วคราว หรือเมินรายการจากแอปจัดการรหัสผ่านบางตัว ซึ่งตั้งไว้ให้เมินบางตัวเป็นค่าเริ่มต้นอยู่แล้ว</div>
<div class="news-card is-warn"><b>คีย์ลัดชนกับของระบบ</b>ถ้าตั้งคีย์ลัดเรียก Maccy แล้วโปรแกรมบอกว่ามีอยู่แล้ว ให้ไปปิดคีย์ลัดนั้นใน System Settings → Keyboard → Keyboard Shortcuts ก่อน (วิธีละเอียดอยู่ใน FAQ ของ GitHub)</div>
<div class="news-card is-warn"><b>คีย์ลัดในช่องรหัสผ่าน</b>หน้า GitHub บอกว่าคีย์ลัดที่พิมพ์เป็นตัวอักษรได้ (เช่น Option + C) macOS อาจบล็อกในช่องรหัสผ่าน แนะนำให้เปลี่ยนเป็นคีย์ลัดอื่น เช่น Command + Shift + C</div>
</div>

ข้อมูลทั้งหมดนี้มาจากเว็บทางการ หน้า GitHub และหน้า App Store ครับ
