## Pearcleaner คืออะไร

<div class="split">
<div class="prose">

**Pearcleaner** เป็นแอปถอนการติดตั้ง (Uninstaller) แบบโอเพนซอร์สสำหรับ **macOS** (เขียนด้วย SwiftUI น้ำหนักเบา) ที่ช่วยค้นหาไฟล์ประกอบทั้งหมดของแอปที่ต้องการลบ ไม่ว่าจะเป็นไฟล์ใน `~/Library/Application Support`, `Caches`, `Preferences` หรือ `LaunchAgents` แล้วรวมมาให้ติ๊กเลือกหรือลบทิ้งพร้อมกันครับ

## จุดเด่นที่ทำได้มากกว่าการลากลงถังขยะ

<div class="prose">

- **กวาดไฟล์ตกค้าง (Orphaned Files):** ตรวจหาไฟล์ค้างของแอปเก่าที่เราเคยลากลงถังขยะไปแล้ว เพื่อช่วยคืนพื้นที่ SSD
- **รองรับ Homebrew & Updater:** ในรุ่นล่าสุด (5.4.3) มีมุมมองจัดการและอัปเดตแพ็กเกจ Homebrew พร้อมแถบความคืบหน้าและระบบเตือนก่อนอัปเดตแอปจาก Mac App Store ข้ามแหล่ง
- **Sentinel ตรวจจับอัตโนมัติ:** เปิดโหมดเฝ้าระวังได้ เมื่อเราลากแอปลงถังขยะตามปกติ Pearcleaner จะเด้งขึ้นมาถามให้ลบไฟล์ที่เกี่ยวข้องตามไปด้วยทันที

<div class="table-frame">

| หัวข้อ | รายละเอียด |
| --- | --- |
| **แพลตฟอร์มที่รองรับ** | macOS (เขียนด้วย SwiftUI น้ำหนักเบา) |
| **ราคาและไลเซนส์** | ฟรี โอเพนซอร์ส (ดาวน์โหลดจาก GitHub หรือ Homebrew) |
| **ตำแหน่งไฟล์ที่สแกน** | `~/Library/Application Support`, `Caches`, `Preferences`, `LaunchAgents` |
| **ฟีเจอร์เสริมเด่น** | Orphaned Files Finder, Homebrew UI, Sentinel เฝ้าระวังอัตโนมัติ |

</div>
