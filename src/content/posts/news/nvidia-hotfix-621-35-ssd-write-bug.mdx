## เกิดอะไรขึ้นกับไดรเวอร์ 621.14 และ 621.24

<div class="prose">

ผู้ใช้การ์ดจอ GeForce บน Windows พบปัญหาในไดรเวอร์ Game Ready รุ่น **621.14 และ 621.24** โดยโปรเซสเบื้องหลัง `NVDisplay.Container.exe` เขียนข้อมูลลงไฟล์ log ชื่อ `nvlog.nvlgstg` (ในโฟลเดอร์ `C:\ProgramData\NVIDIA Corporation\nvtopps\nct\`) ซ้ำ ๆ อย่างต่อเนื่องแม้เครื่องจะอยู่เฉย ๆ ไม่ได้เล่นเกม

<div class="news-stats">
<div class="news-stat"><b>3–30+ GB/ชม.</b>ปริมาณการเขียนไฟล์ลง SSD ที่ผู้ใช้รายงาน</div>
<div class="news-stat"><b>Bug 7116722</b>รหัสปัญหาในบันทึกแก้ไขของ NVIDIA</div>
<div class="news-stat"><b>621.01</b>รุ่นล่าสุดก่อนหน้า ที่ไม่เจอบั๊กนี้</div>
</div>

ผลกระทบตรง ๆ คือทำให้ค่าเขียนสะสม (TBW) ของ SSD วิ่งขึ้นเร็วผิดปกติและสึกหรอโดยไม่จำเป็นครับ

</div>

</section>

<section class="section">

## Hotfix 621.35 แก้ได้แค่ไหน และควรทำอย่างไร

<div class="split">
<div class="prose">

วันที่ 20 พฤศจิกายน 2569 NVIDIA ออกไดรเวอร์ **GeForce Hotfix 621.35** (สร้างต่อจากฐานของ 621.24) เพื่อแก้ Bug `7116722` โดยเฉพาะ โดยต้องดาวน์โหลดเองจากหน้า Customer Care ของ NVIDIA ไม่ได้อัปเดตผ่านแอป NVIDIA เพราะเป็นรุ่น Hotfix ที่ไม่ได้ผ่าน WHQL เต็มรูปแบบครับ

ผมว่าใครที่ตั้งเครื่องเปิดทิ้งไว้โหลดงานหรือทำงานทั้งคืน รีบเช็กใน Task Manager / Resource Monitor หรือถอยไป **621.01** ไว้ก่อนจะสบายใจกว่าครับ จนกว่า NVIDIA จะออกรุ่น WHQL ตัวใหม่ที่แก้ขาดจริง

</div>
