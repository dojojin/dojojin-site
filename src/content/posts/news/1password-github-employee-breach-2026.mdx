## เกิดอะไรขึ้นกับ 1Password

<div class="split">
<div class="prose">

1Password เปิดเผยเหตุการณ์ด้านความปลอดภัยเมื่อวันที่ 25 พฤศจิกายน 2569 (ตามเวลาสหรัฐฯ) หลังตรวจพบเมื่อวันที่ **19 พฤศจิกายน 2569** ว่าผู้โจมตีสามารถเข้ายึดบัญชี GitHub ของพนักงานรายหนึ่งได้ จากนั้นจึงใช้สิทธิ์ดังกล่าวเข้าไปยัง repository ภายในและแทรกโค้ดอันตรายลงในระบบ CI/CD และ backend บางส่วนเพื่อดึงข้อมูลออกไปครับ

## ข้อมูลอะไรที่หลุด และอะไรที่ยังปลอดภัย

<div class="split">
<div class="prose">

เหตุผลที่ข้อมูลรหัสผ่านของผู้ใช้ไม่หลุดเป็นเพราะสถาปัตยกรรมแบบ **Zero-Knowledge** ของ 1Password ครับ ตัวบริษัทเองไม่ได้เก็บรหัสผ่านหลัก (Master Password) หรือ Secret Key ของลูกค้าไว้บนเซิร์ฟเวอร์ ทำให้ต่อให้ผู้โจมตีเจาะระบบหลังบ้านได้ก็ไม่สามารถถอดรหัส Vault ได้

อย่างไรก็ตาม 1Password ยืนยันว่ามีข้อมูลเมตาดาต้าและบันทึกการดูแลระบบของลูกค้าบางส่วนถูกดึงออกไปตามตารางเปรียบเทียบครับ และเพื่อป้องกันการเดาสุ่มโทเคนคำเชิญหรือกู้คืนบัญชีที่หลุดไป บริษัทได้ปรับรหัสยืนยันทางอีเมลจากตัวเลข 6 หลักเป็นรหัส 10 ตัวอักษรผสมตัวเลขแล้ว

## ผู้ใช้ในไทยควรระวังอะไร

<div class="prose">

1Password ระบุว่าผู้ใช้ทั่วไป**ไม่จำเป็นต้องเปลี่ยน Master Password** ครับ แต่สิ่งที่ต้องระวังมากที่สุดหลังเหตุการณ์นี้คือ **อีเมลฟิชชิง (Phishing)** ที่อาจแอบอ้างเป็นอีเมลคำเชิญเข้าทีมหรืออีเมลกู้คืนบัญชี 1Password เพื่อหลอกให้กรอกรหัสผ่านหลักหรือ Secret Key ดังนั้นหากได้รับอีเมลแจ้งกู้คืนบัญชีที่ไม่ได้กดขอเอง ให้ลบทิ้งและเข้าจัดการผ่านแอปหรือเว็บทางการโดยตรงเท่านั้นครับ

*(หมายเหตุ: ยังไม่พบรายงานผลกระทบหรือเหตุโจมตีต่อเนื่องเฉพาะเจาะจงต่อผู้ใช้ในประเทศไทย)*
