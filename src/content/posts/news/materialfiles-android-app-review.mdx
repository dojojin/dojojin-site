## Material Files คืออะไร

<div class="split">
<div class="prose">

Material Files เป็นแอปจัดการไฟล์บน Android ของ Hai Zhang ครับ หน้า GitHub เรียกตัวเองว่า "An open source Material Design file manager" แปลง่าย ๆ คือแอปจัดการไฟล์โอเพนซอร์ส หน้าตาตามแนว Material Design ของ Google

โค้ดใช้ไลเซนส์ GPL-3.0 (หน้า F-Droid เขียนว่า GPL v3 หรือใหม่กว่า)

เรื่องโฆษณา ผมเช็กหน้าร้านมาให้แล้วครับ Google Play ไม่มีป้าย "Contains ads" ส่วน F-Droid ก็ไม่มีป้ายเตือนคุณสมบัติที่ไม่พึงประสงค์ (anti-features)

</div>
<figure class="split-fig"><img src="/media/posts/news/materialfiles-android-app-review/igv-1.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกข้อมูลเร็ว ๆ ของ Material Files ไม่มีป้ายโฆษณาในหน้าร้าน ไลเซนส์โอเพนซอร์ส GPL-3.0 รุ่นล่าสุด 1.7.5 วันที่ 20 ก.ย. 2569 บน GitHub ต้องใช้ Android 6.0 ขึ้นไปตามหน้า F-Droid ติดตั้งได้จาก Google Play, F-Droid และ GitHub" /></figure>
</div>

</section>

## เปิดมาแล้วเจออะไร

<div class="split">

<div class="prose">

เปิดมาเป็นรายการโฟลเดอร์ ดูสะอาดตาครับ

ในภาพ แถวบนสุดคือแถบเส้นทาง (breadcrumbs) บอกว่าตอนนี้อยู่ไหน ตัวอย่างนี้อยู่ใน Internal shared storage แล้วเข้าไปที่ Download จะย้อนกลับก็แตะชื่อโฟลเดอร์บนแถบได้เลย มุมขวาบนมีปุ่มค้นหา เรียงลำดับ และเมนู มุมขวาล่างเป็นปุ่มบวกสีน้ำเงิน

README เรียกจุดนี้ว่า "Breadcrumbs: navigate in the filesystem with ease" ข้างใต้แอปใช้ Linux system calls เลยเข้าใจ symbolic link, สิทธิ์ไฟล์ และ SELinux context แบบเดียวกับ Nautilus บน Linux

</div>
</div>

<div class="prose">

## รุ่นล่าสุด 1.7.5

<div class="prose">

รุ่นล่าสุดบน GitHub คือ v1.7.5 ออกวันที่ 20 กันยายน 2569 (F-Droid ลงวันที่ 22 ก.ย.) บันทึกรุ่นมีแค่สี่ข้อครับ

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-chip" /></svg><div><b>Shizuku</b>รองรับ Shizuku แล้ว</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-globe" /></svg><div><b>ภาษา</b>เพิ่มภาษาเดนมาร์กกับกาลิเซีย</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-file" /></svg><div><b>ZIP</b>สร้างไฟล์ ZIP แบบใส่รหัส จะเข้ารหัสด้วย AES-256 แทน ZipCrypto</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-display" /></svg><div><b>ธีม</b>ธีม Material Design 2 อาจถูกเอาออกในรุ่น 1.8.0 ที่จะตามมา</div></div>
</div>

รุ่นก่อนหน้าคือ 1.7.4 ออกเมื่อ 30 มิถุนายน 2567 ห่างกันกว่าสองปีครับ ฟังดูนาน แต่โปรเจกต์ไม่ได้ทิ้ง GitHub API บอกว่ามีการอัปเดตโค้ดล่าสุดเมื่อ 15 ตุลาคม 2569

</div>

</section>

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่อยากได้แอปไฟล์เรียบ ๆ ไม่มีโฆษณา แถมตรวจโค้ดได้ ใครต้องเปิดไฟล์บน NAS หรือเซิร์ฟเวอร์จากมือถือผ่าน SFTP, SMB หรือ WebDAV ก็ใช้ได้สบาย สาย root ที่ต้องแตะไฟล์ระบบ (ใช้อย่างระวังนะครับ) กับคนที่ชอบหน้าตา Material Design แบบเดิมของ Android ก็น่าลองครับ
