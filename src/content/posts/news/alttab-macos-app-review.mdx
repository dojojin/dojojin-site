## AltTab คืออะไร

<div class="split">
<div class="prose">

AltTab เป็นแอปสลับหน้าต่างบน macOS ครับ หน้า GitHub สรุปไว้สั้น ๆ ว่า "Windows alt-tab on macOS" ส่วนเว็บทางการ alt-tab.app เขียนว่า "See every window, even within the same app" คือเห็นทุกหน้าต่าง แม้จะเป็นแอปเดียวกัน

แอปโชว์ทุกหน้าต่าง รวมถึงที่ย่อไว้ ที่ซ่อนอยู่ และที่อยู่ใน Space อื่น แต่ละอันมีป้ายบอกตำแหน่ง และดูภาพตัวอย่างของหน้าต่างที่เลือกได้ก่อนสลับ

ผมว่าเหมาะกับคนที่เปิดเบราว์เซอร์หลายหน้าต่าง หรือแยกงานไว้หลาย Space ครับ

เรื่องปุ่ม เว็บทางการบอกว่า AltTab ใช้ Option-Tab เป็นค่าเริ่มต้น จะได้ไม่ชนกับ Command-Tab ของระบบ ถ้าอยากใช้แทนตัวเดิมเลยก็ตั้งเป็น Command-Tab ได้

</div>

## ฟรีแค่ไหน และ Pro คืออะไร

ส่วนรุ่นเสียเงินชื่อ AltTab Pro จ่ายครั้งเดียว ไม่มีรายเดือน ราคาในหน้า Pro เป็นดอลลาร์สหรัฐ ผมไม่ได้แปลงเป็นบาท เพราะเว็บบอกว่าตอนจ่ายจะแสดงสกุลเงินตามภูมิภาค ราคาจริงจึงขึ้นกับภูมิภาคและค่าเงิน

## วิธีติดตั้งและให้สิทธิ์

<div class="prose">

ติดตั้งตามหน้าดาวน์โหลดของเว็บทางการได้ใน 4 ขั้นครับ ใครใช้ Homebrew ก็มีอีกทาง

<ol class="news-steps">
<li><b>โหลดแอป</b>กดปุ่ม "Download Free for Mac" ที่ <a href="https://alt-tab.app" rel="noopener">alt-tab.app</a> หรือโหลดจากหน้า <a href="https://github.com/lwouis/alt-tab-macos/releases/latest" rel="noopener">Releases บน GitHub</a> ไฟล์รุ่น 11.10.1 เป็น .zip</li>
<li><b>ย้ายไปไว้ใน Applications</b>แตกไฟล์ แล้วย้ายแอป AltTab ไปไว้ในโฟลเดอร์ Applications ตามขั้นแรกของหน้าดาวน์โหลด</li>
<li><b>อนุญาตสิทธิ์ 2 อย่าง</b>เปิด System Settings → Privacy & Security แล้วเปิด Accessibility กับ Screen Recording ให้ AltTab</li>
<li><b>กด Option-Tab</b>เริ่มสลับหน้าต่างได้เลย</li>
</ol>

ใครใช้ Homebrew พิมพ์ <code>brew install --cask alt-tab</code> ใน Terminal ได้เลยครับ (คำสั่งนี้มาจากหน้าดาวน์โหลดของเว็บทางการ)

ระวังเว็บปลอมด้วยนะครับ โหลดจาก alt-tab.app หรือหน้า GitHub ของ lwouis เท่านั้น แอปที่ขอสิทธิ์ Accessibility กับ Screen Recording ต้องมาจากต้นทางที่แน่ใจ

<div class="news-cards">
<div class="news-card is-ok"><b>ทำไมต้องใช้ Accessibility</b>FAQ บอกว่า macOS บังคับให้แอปที่อ่านชื่อหน้าต่างหรือย้ายโฟกัสต้องมีสิทธิ์นี้ AltTab ใช้เพื่อสลับหน้าต่างเท่านั้น</div>
<div class="news-card is-warn"><b>ทำไมต้องใช้ Screen Recording</b>ใช้เพื่ออ่านภาพตัวอย่างหน้าต่าง FAQ บอกว่าถ้าไม่ให้สิทธิ์นี้ แอปยังทำงานได้ แต่แสดงภาพตัวอย่างไม่ได้</div>
</div>

แอปอัปเดตตัวเองเงียบ ๆ ในพื้นหลัง ถ้าอยากเช็กเองก็กดที่ไอคอนบนแถบเมนู → Check for updates

</div>

</section>

## เห็นทุกหน้าต่าง แม้อยู่ Space อื่น

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/alttab-macos-app-review/everywindow.jpg" width="1600" height="986" loading="lazy" alt="ภาพตัวอย่างทางการของ AltTab แสดงหน้าต่าง Safari สองหน้าต่างกับ Inbox ของแอปเมล หน้าต่างแรกมีป้าย Space 2 หน้าต่างที่เลือกมีป้าย Minimized และ Inbox มีป้าย Hidden" /></div><figcaption><span class="news-fig__credit">ภาพ: AltTab (lwouis) · <a href="https://alt-tab.app" rel="noopener">alt-tab.app</a></span></figcaption></figure>
<div class="prose">

ในภาพเป็นภาพตัวอย่างจากเว็บทางการ มี Safari สองหน้าต่างแยกกันชัด พร้อมป้ายบอกว่าอันไหนอยู่ Space 2 อันไหนถูกย่อ (Minimized) และอันไหนถูกซ่อน (Hidden)

ตรงนี้แหละที่ Command + Tab ทำไม่ได้ครับ ใครเคยกดวนหาหน้าต่างที่ย่อไว้แล้วหาไม่เจอ น่าจะเข้าใจว่าทำไมแอปนี้มีคนโหลดเยอะ

เว็บทางการบอกว่าโหลดไปแล้ว 9.4 ล้านครั้ง ตัวเลขนี้เป็นของเว็บเขาเอง ผมตรวจจากที่อื่นไม่ได้

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่เปิดหน้าต่างเยอะ ทั้งเบราว์เซอร์หลายหน้าต่าง ใช้หลาย Space หรือย้ายมาจาก Windows แล้วคิดถึง Alt-Tab ครับ แกนหลักฟรีและโอเพนซอร์ส ลองได้ไม่เสียอะไร

ก่อนลงเช็ก 3 อย่าง เครื่องต้องเป็น macOS 12 ขึ้นไป ต้องให้สิทธิ์ทั้ง Accessibility และ Screen Recording และถ้าอยากได้ค้นหาหน้าต่างหรือสไตล์อื่น ต้องซื้อ Pro

บอกไว้ก่อนว่าผมยังไม่ได้ลองใช้เองครับ ข้อมูลในข่าวนี้มาจากเว็บทางการและหน้า GitHub ทั้งหมด
