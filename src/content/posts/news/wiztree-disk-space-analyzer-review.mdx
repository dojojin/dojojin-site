## WizTree คืออะไร และทำไมถึงเร็วมาก

<div class="split">
<div class="prose">

**WizTree** (พัฒนาโดย Antibody Software) เป็นโปรแกรมวิเคราะห์พื้นที่จัดเก็บข้อมูลบน **Windows** (และปัจจุบันขยายมารองรับ macOS กับ Linux ด้วย) ที่ขึ้นชื่อเรื่องความเร็วในการสแกนครับ

สาเหตุที่ WizTree สแกนไดรฟ์ขนาดใหญ่ระดับ 1TB เสร็จภายในไม่กี่วินาที เป็นเพราะบนไดรฟ์แบบ **NTFS** ตัวโปรแกรมจะอ่านไฟล์ **Master File Table (MFT)** ของระบบไฟล์โดยตรง แทนการไล่เปิดดูทีละโฟลเดอร์แบบโปรแกรมรุ่นเก่า และยังจัดการกับไฟล์แบบ Hard Link ได้ถูกต้องไม่นับขนาดซ้ำครับ

## ฟีเจอร์เด่นที่ช่วยให้เคลียร์พื้นที่ได้ไว

<div class="prose">

- **Visual Treemap:** แสดงไฟล์และโฟลเดอร์เป็นบล็อกสี่เหลี่ยมขนาดตามสัดส่วนพื้นที่จริง มองปราดเดียวก็เห็นทันทีว่าโฟลเดอร์ไหนหรือไฟล์วิดีโอ/ZIP ก้อนไหนใหญ่ที่สุด
- **ค้นหาไฟล์และส่งออก CSV:** กรองหาไฟล์ตามชื่อ นามสกุล หรือขนาดได้ทันที และส่งออกรายการไฟล์เป็น `.csv` ได้
- **มีรุ่น Portable:** ดาวน์โหลดแบบไม่ต้องติดตั้ง (Portable) ใส่แฟลชไดรฟ์ไปใช้เช็กเครื่องอื่นได้สะดวก

<div class="table-frame">

| หัวข้อ | รายละเอียด |
| --- | --- |
| **แพลตฟอร์มที่รองรับ** | Windows (NTFS/MFT) และขยายรองรับ macOS / Linux |
| **ราคาและไลเซนส์** | ฟรีสำหรับใช้งานส่วนตัว (มีรุ่น Portable ไม่ต้องติดตั้ง) |
| **กลไกความเร็ว** | อ่าน Master File Table (MFT) ของ NTFS โดยตรง ไม่นับ Hard Link ซ้ำ |
| **การแสดงผลและส่งออก** | Visual Treemap สัดส่วนพื้นที่จริง, กรองค้นหาไฟล์, ส่งออก CSV |

</div>
