## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

S.Y. Hsu ผู้ร่วมซีอีโอ (Co-CEO) ของ ASUS พูดเรื่องนี้ในการประชุมนักลงทุนไตรมาส 3 เมื่อวันที่ **12 พฤศจิกายน 2569** ครับ ตอนนั้นนักวิเคราะห์จาก JP Morgan ถามว่า ถ้าตลาดพีซีหดลง 10-15% ในปีหน้า ASUS ยังผลักต้นทุนชิ้นส่วนที่แพงขึ้นไปที่ราคาขายได้อีกไหม

Hsu ตอบว่า ASUS เคยใส่แรม 16GB ในพีซีราคาไม่สูงบางรุ่นเพื่อให้ผู้ซื้อได้ประสบการณ์ที่ดี แต่ตอนนี้ Windows ปรับปรุงแล้ว จึง "even 8 GB is able to yield an acceptable experience" (แม้ 8GB ก็ให้ประสบการณ์ใช้งานที่ยอมรับได้) และบอกว่า "We have worked with Microsoft on this one" (เราทำเรื่องนี้ร่วมกับ Microsoft) ตามที่ Windows Latest รายงาน

สื่อไต้หวัน People News และบริษัทวิเคราะห์ Futurum รายงานตรงกันว่า ASUS กำลังพิจารณาลดแรมในพีซีระดับกลางถึงเริ่มต้นบางรุ่นจาก 16GB เหลือ 8GB คำที่ใช้คือ "อาจ" และ "กำลังพิจารณา" ยังไม่ใช่ประกาศว่าจะทำแน่

## ทำไมต้องลดแรม และ Microsoft ทำอะไรไป

<div class="split">
<div class="prose">

Hsu บอกว่า ASUS ซื้อหน่วยความจำสำรองไว้ล่วงหน้าตั้งแต่ครึ่งหลังของปี 2568 แต่พอของที่สต็อกไว้ใกล้หมด ราคาก็ขยับขึ้นเรื่อย ๆ People News อ้างคำของเขาว่าตอนนี้ ASUS คงผลักต้นทุนแรมไปที่ราคาขายไม่ได้ครบ 100% ผู้ซื้อบางส่วนจึงเลื่อนการซื้อออกไป

ฝั่ง Microsoft เขียนในบล็อกเมื่อ 3 พฤศจิกายน 2569 ว่าปรับ Windows 11 ให้ทำงานบนเครื่องแรม 8GB ได้ดีขึ้น แต่บล็อกนั้นไม่ได้พูดถึง ASUS เลยนะครับ ส่วนที่ว่าสองบริษัทร่วมกันทำอะไร Hsu ไม่ได้อธิบาย

Microsoft บอกว่า Windows เก็บข้อมูลที่ใช้อยู่ไว้ในแรมได้เพิ่มสูงสุด 2GB แทนที่จะย้ายไปที่เก็บข้อมูลที่ช้ากว่า และจากการทดสอบในแล็บของ Microsoft เอง (เครื่อง HP OmniBook 3 แรม 8GB) การทำหลายงานพร้อมกันเร็วขึ้นสูงสุด 40% ตัวเลขเหล่านี้เป็นผลทดสอบของ Microsoft ครับ ผลจริงขึ้นกับเครื่องและการใช้งาน

## กระทบคนไทยแค่ไหน

<div class="prose">

ตอนนี้ยังไม่พบข้อมูลว่า ASUS จะลดแรมรุ่นไหนที่ขายในไทย และยังไม่มีราคาไทยให้เทียบครับ ASUS ยังไม่บอกทั้งรุ่น ราคา และเวลา ส่วนทิศทางใหญ่เข้ากับข่าวที่เราเล่าไปก่อนหน้านี้ว่า [ค่ายมือถือใหญ่หั่นเป้ายอดส่งมอบปี 2570 เพราะชิปหน่วยความจำแพง](/news/smartphone-2027-shipment-cuts-memory-crisis/) คือต้นทุนแรมกำลังไล่ตามทุกอุปกรณ์

ถ้าคุณกำลังจะซื้อโน้ตบุ๊กราคาประหยัด ข้อควรดูโดยทั่วไปมีดังนี้ครับ

- **ดูตัวเลขแรมในสเปกทุกครั้ง** รุ่นเดียวกันหรือรุ่นที่หน้าตาคล้ายกัน อาจมีแรมต่างกันได้
- **เช็กว่าแรมบัดกรีติดบอร์ดหรือเปลี่ยนได้** ถ้าบัดกรีติดบอร์ด (soldered) อัปเกรดทีหลังไม่ได้ ถ้ามีช่องใส่แรมแบบ SO-DIMM ยังเพิ่มแรมได้ และดูว่ามีกี่ช่อง
- **ถ้าใช้เปิดเว็บหลายแท็บ ประชุมออนไลน์ และหลายโปรแกรมพร้อมกัน** 8GB จะตึงเร็วกว่า 16GB (People News ก็เตือนเรื่องนี้)
- **ถ้าใช้งานเบา ๆ** เช่น เอกสารและเว็บ 8GB อาจพอ ตามที่ Microsoft และ ASUS ว่า แต่ควรหาคนที่ใช้รุ่นนั้นจริงมาเทียบก่อนจ่าย
- **อย่าตัดสินจากแรมอย่างเดียว** Microsoft เองก็บอกว่าทั้งเครื่อง ไม่ใช่แค่ความจุแรม ที่กำหนดประสบการณ์ใช้งาน
