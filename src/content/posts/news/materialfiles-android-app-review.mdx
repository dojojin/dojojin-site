## Material Files คืออะไร

<div class="split">
<div class="prose">

Material Files เป็นแอปจัดการไฟล์บน Android ของ Hai Zhang ครับ หน้า GitHub เรียกตัวเองว่า "An open source Material Design file manager" แปลง่าย ๆ คือแอปจัดการไฟล์โอเพนซอร์ส หน้าตาตามแนวทาง Material Design ของ Google

ซอร์สโค้ดใช้ไลเซนส์ GPL-3.0 (หน้า F-Droid ระบุเป็น GPL v3 หรือใหม่กว่า)

เรื่องโฆษณา ผมเช็กหน้าร้านมาแล้วครับ

- Google Play ไม่มีป้าย "Contains ads"
- F-Droid ไม่มีป้ายคุณสมบัติที่ไม่พึงประสงค์ (anti-features)

</div>
<figure class="split-fig"><img src="/media/posts/news/materialfiles-android-app-review/igv-1.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกข้อมูลเร็ว ๆ ของ Material Files ไม่มีป้ายโฆษณาในหน้าร้าน ไลเซนส์โอเพนซอร์ส GPL-3.0 รุ่นล่าสุด 1.7.5 วันที่ 20 ก.ย. 2569 บน GitHub ต้องใช้ Android 6.0 ขึ้นไปตามหน้า F-Droid ติดตั้งได้จาก Google Play, F-Droid และ GitHub" /></figure>
</div>

</section>

## เปิดมาแล้วเจออะไร

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/materialfiles-android-app-review/img-1.jpg" width="900" height="1600" loading="lazy" alt="ภาพหน้าจอ Material Files โหมดสว่าง หน้า Files แสดงโฟลเดอร์ Alarms, Android, Audiobooks, DCIM, Documents, Download, Movies และ Music ในที่เก็บข้อมูลภายใน พร้อมแถบเส้นทางด้านบนและปุ่มบวกสีน้ำเงิน" /></div><figcaption><span class="news-fig__credit">ภาพ: Hai Zhang (Material Files) · <a href="https://github.com/zhanghai/MaterialFiles" rel="noopener">github.com</a></span></figcaption></figure>
<div class="prose">

หน้าแรกเป็นรายการโฟลเดอร์ ดูสะอาดตาครับ

ในภาพ แถวบนสุดคือแถบเส้นทาง (breadcrumbs) บอกว่าตอนนี้อยู่ตรงไหน คือ Internal shared storage แล้วเข้าไปที่ Download ไล่ดูทางเดินได้ง่าย มุมขวาบนมีปุ่มค้นหา เรียงลำดับ และเมนู มุมขวาล่างมีปุ่มบวกสีน้ำเงิน

README เรียกจุดเด่นนี้ว่า "Breadcrumbs: navigate in the filesystem with ease" และบอกว่าแอปใช้ Linux system calls เป็นฐาน เลยรู้จัก symbolic link, สิทธิ์ไฟล์ และ SELinux context แบบเดียวกับ Nautilus บน Linux

</div>
</div>

<div class="split">
<div class="prose">

ลากเมนูด้านข้างออกมา จะเห็นที่เก็บข้อมูลกับทางลัดครับ ในภาพมี

- Root กับ Internal shared storage พร้อมพื้นที่ว่าง
- ปุ่ม Add storage…
- โฟลเดอร์ทางลัด DCIM, Downloads, Movies, Music, Pictures และ Screenshots
- ท้ายเมนูเป็น FTP server, Settings และ About

README สรุปความสามารถหลักไว้แบบนี้

- ดูและจัดการไฟล์ด้วยสิทธิ์ root ได้
- ดู แตก และสร้างไฟล์บีบอัดทั่วไปได้
- รองรับเซิร์ฟเวอร์ FTP, SFTP, SMB และ WebDAV (NAS support)

</div>

## ตั้งค่าและธีม

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/materialfiles-android-app-review/img-3.jpg" width="900" height="1600" loading="lazy" alt="ภาพหน้าจอหน้า Settings ของ Material Files หัวข้อ Interface มี Theme color, Night mode ตั้งเป็น Follow system, Black night mode, File list animation, Display long file name และหัวข้อ Behavior มี Default folder, Storage, Standard folders" /></div><figcaption><span class="news-fig__credit">ภาพ: Hai Zhang (Material Files) · <a href="https://github.com/zhanghai/MaterialFiles" rel="noopener">github.com</a></span></figcaption></figure>
<div class="prose">

ในภาพคือหน้า Settings แบ่งเป็นสองกลุ่มครับ

- **Interface** มี Theme color (สีหลักของแอป), Night mode ที่ตั้งให้ตามระบบได้, Black night mode สำหรับโหมดมืดดำสนิท, File list animation และวิธีแสดงชื่อไฟล์ยาว
- **Behavior** มีโฟลเดอร์เริ่มต้น และการเลือกที่เก็บข้อมูลที่จะแสดง

</div>
</div>

<div class="split">
<div class="prose">

ในภาพคือโหมดมืดแบบดำสนิท (true black) ครับ README ระบุไว้ว่าธีมปรับสีได้ และมี night mode แบบดำสนิทให้เลือก

ใครเคยใช้แอปไฟล์ที่ติดมากับเครื่อง ลองเทียบดูครับ ตัวนี้เน้นความเรียบ ไม่มีโฆษณาให้เจอในหน้าร้าน และเปิดโค้ดให้ดูได้ทั้งหมดบน GitHub

## รุ่นล่าสุด 1.7.5

<div class="prose">

รุ่นล่าสุดบน GitHub คือ **v1.7.5** วันที่ 20 กันยายน 2569 (F-Droid ลงวันที่ 22 ก.ย.) บันทึกรุ่นสั้น ๆ มีสี่ข้อครับ

- เพิ่มการรองรับ Shizuku
- เพิ่มภาษาเดนมาร์กและกาลิเซีย
- เปลี่ยนการเข้ารหัสตอนสร้างไฟล์ ZIP จาก ZipCrypto เป็น AES-256
- ธีม Material Design 2 อาจถูกเอาออกในรุ่น 1.8.0 ที่จะมา

รุ่นก่อนหน้าคือ 1.7.4 ออกเมื่อ 30 มิถุนายน 2567 ห่างกันกว่าสองปีครับ แต่โค้ดยังขยับอยู่ ข้อมูลจาก GitHub API บอกว่าโปรเจกต์มีการอัปเดตโค้ดล่าสุดเมื่อ 15 ตุลาคม 2569

</div>

</section>

## ติดตั้งจากไหน

<div class="split">
<figure class="split-fig"><img src="/media/posts/news/materialfiles-android-app-review/igv-2.jpg" width="1600" height="1400" loading="lazy" alt="อินโฟกราฟิกฟีเจอร์เด่นของ Material Files เชื่อมเซิร์ฟเวอร์ NAS ผ่าน FTP, SFTP, SMB, WebDAV จัดการไฟล์บีบอัดโดยดู แตก และสร้าง ใช้สิทธิ์ root ดูและจัดการไฟล์ ธีมมีโหมดมืดดำสนิท และรองรับ Shizuku ที่เพิ่มในรุ่น 1.7.5" /></figure>
<div class="prose">

ติดตั้งได้สามทาง ตามปุ่มใน README ครับ

- <a href="https://play.google.com/store/apps/details?id=me.zhanghai.android.files" rel="noopener">Google Play</a> ได้ 4.6 ดาวจากรีวิว 7.9 พันรายการ ดาวน์โหลดเกิน 1 ล้าน ผู้พัฒนาคือ Hai Zhang
- <a href="https://f-droid.org/packages/me.zhanghai.android.files" rel="noopener">F-Droid</a> รุ่น 1.7.5 ต้องใช้ Android 6.0 ขึ้นไป
- ไฟล์ APK จาก <a href="https://github.com/zhanghai/MaterialFiles/releases/latest" rel="noopener">GitHub releases</a>

เรื่องความเป็นส่วนตัว หน้า Google Play มีข้อมูลที่ผู้พัฒนาแจ้งเองไว้ว่า

- ไม่แชร์ข้อมูลกับบุคคลที่สาม
- ข้อมูลที่อาจเก็บคือข้อมูลแอปกับประสิทธิภาพ และรหัสอุปกรณ์
- ข้อมูลเข้ารหัสระหว่างส่ง

## ใครควรใช้

<div class="prose">

- คนที่อยากได้แอปจัดการไฟล์เรียบ ๆ ไม่มีโฆษณา และตรวจโค้ดได้
- คนที่ต้องเข้าถึงไฟล์บน NAS หรือเซิร์ฟเวอร์ ผ่าน SFTP, SMB หรือ WebDAV จากมือถือ
- คนที่ใช้เครื่อง root และอยากจัดการไฟล์ระบบอย่างระวัง
- คนที่ชอบหน้าตาแบบ Material Design ตัวเดิมของ Android
