## Pearcleaner คืออะไร

<div class="split">
<div class="prose">

**Pearcleaner** เป็นแอปถอนการติดตั้ง (uninstaller) สำหรับ **macOS 13 ขึ้นไป** ครับ เลือกแอปที่จะลบ แล้วแอปจะหาไฟล์ที่เกี่ยวข้อง เช่น แคชและไฟล์ตั้งค่า มาให้ดูเป็นรายการก่อนลบ

เรื่องที่ต้องรู้ก่อนลงมี 3 ข้อครับ

- **ผู้พัฒนาพักโครงการอยู่** หน้า GitHub ขึ้นสถานะ "On Hold" (พักไว้ก่อน) และเขียนว่าการพัฒนาหยุดมาตั้งแต่ปลายปี 2025 รุ่นล่าสุดคือ 5.4.3 ออกเมื่อ 26 พ.ย. 2568 ยังไม่มีกำหนดออกรุ่นใหม่ แต่ผู้พัฒนาบอกว่ายังไม่ได้ทิ้งโครงการ
- **ไม่ใช่โอเพนซอร์สเต็มรูปแบบ** ผู้พัฒนาเรียกว่า "source-available and fair-code" (เปิดซอร์สให้ดูได้ และใช้แบบแฟร์โค้ด) ใช้สัญญาอนุญาต Apache 2.0 พ่วง Commons Clause คือดูและแก้ซอร์สได้ ใช้ฟรี แต่ห้ามเอาไปหารายได้
- **ระวังเว็บปลอม** ผู้พัฒนาเตือนว่าเว็บของเขามีที่เดียวคือ itsalin.com เว็บอื่นที่แจก Pearcleaner ไม่เกี่ยวกับเขา ให้โหลดจากหน้า Releases บน GitHub หรือ Homebrew เท่านั้น

## ติดตั้งและใช้ยังไง

<div class="prose">

ติดตั้งได้ 2 ทางครับ โหลดจาก<a href="https://github.com/alienator88/Pearcleaner/releases" rel="noopener">หน้า Releases บน GitHub</a> หรือสั่ง `brew install --cask pearcleaner` ผ่าน Homebrew

ตอนใช้ครั้งแรก แอปจะขอสิทธิ์ Full Disk Access เพื่อค้นไฟล์ และขอติดตั้งตัวช่วยที่มีสิทธิ์ระดับระบบ (Privileged Helper) สำหรับลบไฟล์ในโฟลเดอร์ของระบบ สิทธิ์ระดับนี้สูงมาก จึงควรลงจากแหล่งที่ผู้พัฒนาระบุเท่านั้น

<ol class="news-steps">
<li><b>เลือกแอป</b>ลากแอปมาวาง หรือเลือกจากรายการในแถบข้าง</li>
<li><b>ตรวจรายการไฟล์</b>แอปจะแสดงไฟล์ที่คิดว่าเกี่ยวข้อง อ่านให้ครบก่อน แล้วเอาติ๊กออกจากรายการที่ไม่แน่ใจ</li>
<li><b>ลบ</b>กดลบเฉพาะรายการที่เลือกไว้</li>
</ol>

ที่ต้องตรวจเอง เพราะแอปหาไฟล์จากชื่อที่ตรงกับแอป จึงอาจเจอไม่ครบ หรือดึงไฟล์ที่แอปอื่นใช้ร่วมกันมาด้วยครับ (ข้อนี้ผมอธิบายจากวิธีทำงานทั่วไปของแอปแนวนี้)

ในแอปปรับความละเอียดของการค้นหา และกำหนดโฟลเดอร์ที่ให้ค้นหรือไม่ให้ค้นได้

ฟีเจอร์อื่นที่ผู้พัฒนาเขียนไว้ในหน้า README

- **ค้นไฟล์ตกค้าง:** หาไฟล์ของแอปที่เคยลากลงถังขยะไปแล้ว
- **Sentinel Monitor:** เฝ้าดูถังขยะ พอเราลากแอปลงถัง จะถามว่าจะลบไฟล์ที่เกี่ยวข้องด้วยไหม ผู้พัฒนาระบุว่าใช้แรมราว 2 MB
- **จัดการ Homebrew และอัปเดตแอป:** ดูและอัปเดตแพ็กเกจในหน้าต่างเดียว
- **คลิกขวาใน Finder เพื่อถอนแอป** ผ่านส่วนขยายของ Finder

<div class="table-frame">

| หัวข้อ | รายละเอียด |
| --- | --- |
| **macOS ที่รองรับ** | 13 Ventura, 14 Sonoma, 15 Sequoia, 26 Tahoe (ต่ำกว่า 13 ใช้ไม่ได้) |
| **ราคาและสัญญาอนุญาต** | ฟรี · Apache 2.0 + Commons Clause (ดูซอร์สได้ ห้ามนำไปหารายได้) |
| **รุ่นล่าสุด** | 5.4.3 (26 พ.ย. 2568) · สถานะโครงการ: On Hold |
| **สิทธิ์ที่ต้องให้** | Full Disk Access และ Privileged Helper |
| **ติดตั้ง** | หน้า Releases บน GitHub หรือ `brew install --cask pearcleaner` |

</div>

ผมว่าแอปยังใช้ได้ดีกับ macOS ที่รองรับอยู่ครับ แต่เพราะไม่มีรุ่นใหม่มาเป็นปีแล้ว ถ้า macOS รุ่นถัดไปเปลี่ยนอะไร ก็อาจไม่มีใครตามแก้ให้ (ข้อนี้เป็นความเห็นผม)
