## เกิดอะไรขึ้น

<div class="split">
<div class="prose">

โปรเจกต์ **Silent Hill PC** ของ **Vladislav Tislenko (keklick1337)** บน GitHub เปิดให้ดาวน์โหลดแล้วภายใต้สัญญาอนุญาต **GPL-3.0** (สัญญาอนุญาตซอฟต์แวร์เสรีแบบโอเพนซอร์ส) โดยไม่เกี่ยวข้องกับ Konami และเป็นโปรเจกต์ส่วนบุคคลที่ไม่แสวงหากำไรครับ

จุดสำคัญคือโปรแกรมนี้ **ไม่ใช่ตัวจำลองเครื่อง PlayStation (emulator)** แต่เป็นการเขียนเอนจินเกมขึ้นใหม่ตั้งแต่ต้นด้วยภาษา **C++20** ครับ ตัวเอนจินอ้างอิงการทำงานจากข้อมูลของชุมชน **silent-hill-decomp** (โครงการถอดรหัสพฤติกรรมเกมต้นฉบับ) ทำให้เกมทำงานแบบเนทีฟบนอุปกรณ์ยุคใหม่ได้โดยตรง

ในรุ่นล่าสุด **v1.2.0** ที่ปล่อยออกมาเมื่อวันที่ 26 พฤศจิกายน 2569 เวลา 05:15 น. ตามเวลาไทย (25 พฤศจิกายน เวลา 22:15 UTC) ผู้พัฒนาเพิ่มไฟล์ APK สำหรับ **Android** ให้โหลดในหน้า Releases ของโปรเจกต์ (ข้อมูลเรื่อง Android มาจากหน้า Releases ของผู้พัฒนาเอง) นอกเหนือจากเวอร์ชัน **Windows**, **Linux** และ **macOS** ที่มีอยู่เดิมครับ

## จุดเด่นและข้อกำหนดของตัวเกม

<div class="prose">

โปรเจกต์นี้ไม่ได้แค่ทำให้เกมเปิดติด แต่ยังปรับปรุงระบบกราฟิกและการเล่นให้เข้ากับฮาร์ดแวร์ปัจจุบัน โดยมีตัวเลือกปรับภาพถึง 7 ระดับ ตั้งแต่แบบดั้งเดิมไปจนถึงโหมดที่เปิดใช้ความสามารถของ **Vulkan** (ตัวประมวลผลกราฟิกสมัยใหม่)

<div class="table-frame">

| หัวข้อ | รายละเอียดตามข้อมูลต้นทาง |
| --- | --- |
| **แพลตฟอร์มที่รองรับ** | Windows (x86_64), Linux (x86_64), macOS (Apple Silicon / Intel) และ Android |
| **ความต้องการขั้นต่ำ Android** | Android 10 (API 29) ขึ้นไป และชิปกราฟิกที่รองรับ Vulkan 1.1 ขึ้นไป |
| **ฟีเจอร์กราฟิกบน PC** | Ray Tracing (จำลองแสงเงาและภาพสะท้อน), HDR, ลบรอยหยักแบบ TAA, หมอกแบบมีมิติ (Volumetric Fog) และระบบขยายความละเอียดเท็กซ์เจอร์ (ยังเป็นแบบทดลอง) |
| **ข้อจำกัดบน macOS** | สื่อ Rely on Horror ระบุว่า macOS ยังไม่รองรับ Ray Tracing เนื่องจากข้อจำกัดของ MoltenVK |
| **ฟีเจอร์เสริมอื่น ๆ** | โหลดฉากทันที (ปรับกลับเป็นความเร็วแผ่นได้), รองรับม็อดด้วยภาษา Lua และรองรับจอยเกม/ระบบสัมผัสบนมือถือ |

</div>

สำหรับฝั่ง **Android** รุ่น v1.2.0 ออกไฟล์ APK แยกตามสถาปัตยกรรมชิปทั้ง `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86` และแบบ `universal` โดยผู้พัฒนาปรับแต่งตัวเรนเดอร์ให้เหมาะกับชิปกราฟิกมือถือ พร้อมปุ่มควบคุมบนหน้าจอและระบบสั่นของโทรศัพท์ครับ

ข้อควรรู้ที่สำคัญมากคือ **ในตัวโปรเจกต์ไม่มีไฟล์เกมลิขสิทธิ์แถมมาให้** (ยกเว้นข้อความภาษาอังกฤษของเกม) ผู้เล่นต้องนำเข้าไฟล์อิมเมจแผ่นเกมของตัวเองตอนเปิดใช้งานครั้งแรกครับ โดยตอนนี้รองรับเฉพาะแผ่นโซนอเมริกาเหนือรุ่น **NTSC USA v1.1 (รหัส SLUS-007.07)** เท่านั้น ส่วนแผ่นโซน PAL และญี่ปุ่นยังไม่ได้ทดสอบ

ทาง **Rely on Horror** บอกว่าไฟล์ ISO มาตรฐานขนาด 2,048 ไบต์ใช้ไม่ได้ ต้องเป็นไฟล์อิมเมจแผ่นดิบ ส่วนหน้า GitHub ของโปรเจกต์บอกชนิดไฟล์ที่รับไว้ คือ `.cue` คู่กับ `.bin`, `.bin` อย่างเดียว, `.iso` แบบเซกเตอร์ 2,352 ไบต์ หรือไฟล์ `.zip` ที่รวมไฟล์เหล่านี้ครับ

## คนไทยเล่นได้ไหม

<div class="prose">

คนไทยดาวน์โหลดได้ผ่านหน้า GitHub Releases ของผู้พัฒนาครับ แต่มีข้อจำกัดสองเรื่องที่ต้องรู้ก่อน

- **ภาษาในเกม:** จากเอกสารลิขสิทธิ์ของโปรเจกต์ ตัวเกมมีคำแปลเพิ่ม 12 ภาษานอกเหนือจากภาษาอังกฤษจากแผ่นเกม (เช่น จีน ญี่ปุ่น เกาหลี อาหรับ ฯลฯ) **ยังไม่มีภาษาไทย** ในชุดภาษาทางการของโปรเจกต์ครับ
- **ไฟล์แผ่นเกม:** ผู้เล่นต้องเตรียมไฟล์อิมเมจจากแผ่นเกมของตัวเองรหัส `SLUS-007.07` ของตัวเองมาแปลงข้อมูลเข้าตัวเกมในครั้งแรก ไม่อย่างนั้นจะเข้าเล่นไม่ได้ครับ
