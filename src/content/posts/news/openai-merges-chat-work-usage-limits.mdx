## เปลี่ยนแปลงอะไรใน ChatGPT รอบนี้

<div class="split">
<div class="prose">

รายงานจาก OpenAI และ TechCrunch (พร้อมสื่อไทย iPhoneMod) ระบุว่า OpenAI กำลังทยอยรวมหน้าต่าง **Chat** และ **Work** (รวมถึงการทำงานสาย Codex) เข้าเป็นประสบการณ์เดียวกันใน ChatGPT เพื่อให้นำความสามารถด้าน Agent มาใช้ต่อจากบทสนทนาได้ทันที โดยเปลี่ยนระบบนับโควตาเป็น**มิเตอร์กลางถังเดียว (Shared Usage Meter)** ครับ

## ผลกระทบต่อผู้ใช้งานแต่ละกลุ่ม

<div class="split">
<div class="prose">

OpenAI ชี้แจงว่าผู้ใช้ส่วนใหญ่จะไม่รู้สึกถึงการรีเซ็ตโควตาที่ถี่ขึ้น แต่ยอมรับว่า**ผู้ใช้งานหนักกลุ่มหนึ่งอาจชนลิมิตเร็วขึ้น** เพราะเดิมทีโควตาของ Chat และ Work แยกกัน พอจับมารวมถังเดียวเมื่อใช้โหมด Agent หรือคิดวิเคราะห์ขั้นสูงหนักๆ ก็จะกินโควตาแชตไปด้วย

อย่างไรก็ตาม หากโควตากลางเต็ม ระบบยังเปิดให้สลับไปใช้โมเดล **Instant** ได้แบบไม่จำกัดต่อได้ทันทีครับ

### กระแสตอบรับและข้อควรปรับตัว
หลังข่าวการรวมมิเตอร์เผยแพร่ออกมา ผู้ใช้ระดับ Power User บนโซเชียลมีเดียและฟอรัมของ OpenAI หลายรายแสดงความกังวลว่าการรวมถังโควตานี้เท่ากับลดปริมาณการใช้งานโมเดลคิดวิเคราะห์ขั้นสูง (Reasoning) ทางอ้อมโดยที่ค่าสมาชิกรายเดือนยังเท่าเดิม สำหรับคนที่ใช้งานจริงจังจึงควรแบ่งงานสรุป/ร่างข้อความทั่วไปไว้ใช้กับรุ่น **Instant** เพื่อประหยัดโควตากลางไว้สำหรับงานโค้ดหรือ Agent ที่ซับซ้อนครับ
