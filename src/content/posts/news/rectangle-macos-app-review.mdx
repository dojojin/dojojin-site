## Rectangle คืออะไร

<div class="split">
<div class="prose">

Rectangle เป็นแอปจัดหน้าต่างบน macOS ครับ หน้า GitHub บอกว่าสร้างโดยอิงจากแอป Spectacle

เว็บทางการ rectangleapp.com สรุปไว้ประโยคเดียว "Move and resize windows in macOS using keyboard shortcuts or snap areas" คือย้ายและปรับขนาดหน้าต่างด้วยปุ่มลัด หรือลากไปวางที่ขอบจอ

ผมว่ามันทำอยู่เรื่องเดียว แต่ทำได้ดีครับ ปกติบน macOS เราต้องลากขอบหน้าต่างเอง พอมี Rectangle ก็เหลือกดปุ่มเดียว เบราว์เซอร์ไว้ครึ่งซ้าย โน้ตไว้ครึ่งขวา ไม่ถึงวินาทีก็เสร็จ

ใครเคยใช้ Spectacle มาก่อนสบายเลยครับ เว็บทางการบอกว่า Rectangle ใช้แทน Spectacle ได้เกือบสมบูรณ์ เปิดแอปครั้งแรกเลือกชุดปุ่มลัดของ Spectacle ได้ ไม่ต้องจำปุ่มใหม่

</div>

## วิธีติดตั้ง

<div class="prose">

ติดตั้งได้ 2 วิธีตามหน้า GitHub ครับ

<ol class="news-steps">
<li><b>โหลดไฟล์ DMG</b>จากเว็บ <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a> หรือหน้า <a href="https://github.com/rxhanson/Rectangle/releases" rel="noopener">Releases บน GitHub</a> เปิดไฟล์ แล้วลากแอปไปไว้ในโฟลเดอร์ Applications</li>
<li><b>Homebrew</b>ใครใช้ Homebrew อยู่แล้ว เปิด Terminal แล้วพิมพ์ <code>brew install --cask rectangle</code></li>
</ol>

หน้า Releases ของรุ่น 2.0.4 มีไฟล์ 3 แบบ คือ .dmg, .pkg และ .zip เลือก .dmg ตามที่หน้าเว็บบอกก็พอครับ

ถอนการติดตั้งก็ง่าย ปิดแอปแล้วลากไปถังขยะ หน้า GitHub บอกเพิ่มอีก 2 ข้อตามด้านล่าง ส่วนนี้ผมยังไม่ได้ลองเองนะครับ

<div class="news-cards">
<div class="news-card is-ok"><b>อยากล้างค่าตั้งค่าด้วย</b>พิมพ์ <code>defaults delete com.knollsoft.Rectangle</code></div>
<div class="news-card is-ok"><b>ถ้าติดตั้งผ่าน Homebrew</b>ให้ถอนด้วย <code>brew uninstall --zap rectangle</code></div>
</div>

## เปิดครั้งแรกและให้สิทธิ์ Accessibility

<div class="prose">

Rectangle ต้องขยับหน้าต่างของแอปอื่น เลยต้องได้สิทธิ์ Accessibility ก่อนครับ สิทธิ์นี้คือสิทธิ์ช่วยการเข้าถึง ที่ macOS ใช้คุมว่าแอปไหนสั่งแอปอื่นได้ หน้า GitHub บอกว่าตอนเปิดแอป ให้เปิดสิทธิ์ตามที่ระบบถาม ขั้นตอนมีแค่นี้

<ol class="news-steps">
<li><b>เปิด Rectangle</b>เปิดแอปครั้งแรกตามปกติ</li>
<li><b>เลือกชุดปุ่มลัด</b>ใครเคยใช้ Spectacle เลือกชุดของ Spectacle ได้</li>
<li><b>ไปที่ Accessibility</b>พอ macOS ถาม ให้เปิด System Settings แล้วเข้า Privacy & Security → Accessibility</li>
<li><b>เปิดสวิตช์</b>เปิดสวิตช์ของ Rectangle เป็น ON เท่านี้ก็ใช้ได้</li>
</ol>

ทำแล้วหน้าต่างยังไม่ขยับ หน้า GitHub แนะนำให้ลองล็อกแล้วปลดล็อกเครื่อง อัปเดต macOS แล้วรีสตาร์ต

ยังไม่หายอีก ให้รีเซ็ตสิทธิ์ เลือกได้ 2 ทาง

<div class="news-cards">
<div class="news-card is-ok"><b>ทางที่ 1 ใช้คำสั่ง</b>พิมพ์ <code>tccutil reset All com.knollsoft.Rectangle</code></div>
<div class="news-card is-warn"><b>ทางที่ 2 ทำเอง</b>เข้า Accessibility ปิดสวิตช์ของ Rectangle ก่อน แล้วค่อยกดปุ่มลบ (-) รีสตาร์ตเครื่อง แล้วเปิดแอปให้ขอสิทธิ์ใหม่ หน้า GitHub เน้นว่าต้อง "ปิดก่อน ลบทีหลัง" ห้ามสลับกันครับ</div>
</div>

</div>

## ปุ่มลัด: กดทีเดียวหน้าต่างไปอยู่ที่ที่ต้องการ

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/rectangle-macos-app-review/img-1.jpg" width="1213" height="1600" loading="lazy" alt="ภาพหน้าต่างตั้งค่า Rectangle แท็บ Shortcuts รายการ Left, Right, Center, Top, Bottom, Top Left, Top Right, Bottom Left, Bottom Right, Maximize, Almost Maximize, Maximize Height, Larger, Smaller, Move to Center, Restore, Next Display, Previous Display พร้อมปุ่มลัดเช่น Control Option ลูกศรซ้าย" /></div><figcaption><span class="news-fig__credit">ภาพ: Rectangle (Ryan Hanson) · <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a></span></figcaption></figure>
<div class="prose">

ในภาพคือแท็บ Shortcuts ในหน้าตั้งค่า (ภาพจากเว็บทางการ) แถวละหนึ่งคำสั่ง ไอคอนซ้ายบอกว่าหน้าต่างจะไปอยู่ตรงไหน ช่องขวาคือปุ่มลัด

อยากเปลี่ยนปุ่ม คลิกที่ช่องแล้วกดปุ่มใหม่ได้เลยครับ ช่องไหนขึ้นว่า Record Shortcut แปลว่าคำสั่งนั้นยังไม่มีปุ่ม

คำสั่งในภาพแบ่งได้ 4 กลุ่ม

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-display" /></svg><div><b>ครึ่งจอ</b>Left, Right, Top, Bottom และ Center</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-shapes" /></svg><div><b>มุมจอ</b>Top Left, Top Right, Bottom Left, Bottom Right</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-expand" /></svg><div><b>ขนาด</b>Maximize, Almost Maximize, Maximize Height, Larger, Smaller, Move to Center, Restore</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-panel" /></svg><div><b>หลายจอ</b>Next Display, Previous Display ย้ายหน้าต่างไปจอถัดไปหรือจอก่อนหน้า</div></div>
</div>

ปุ่มลัดในภาพเป็นค่าที่เห็นบนเว็บทางการ เครื่องจริงอาจไม่ตรงกัน ขึ้นกับชุดที่เลือกตอนเปิดครั้งแรก ข้อนี้ผมยังไม่ได้ลองบนเครื่องตัวเองครับ

</div>
</div>

<div class="split">
<div class="prose">

ในภาพคือปุ่มหลักที่ผมสรุปไว้ครับ ทุกปุ่มขึ้นต้นด้วย Control + Option (⌃⌥) เหมือนกัน จำแค่ปุ่มท้ายพอ ยกเว้นย้ายจอที่ต้องกด Command (⌘) เพิ่ม

ลูกศรใช้กับครึ่งจอ ส่วน U I J K ใช้กับ 4 มุม ตัวอักษร 4 ตัวนี้เรียงเป็นสี่เหลี่ยมบนคีย์บอร์ดพอดี ผมว่าจำง่ายกว่าที่คิดครับ

อีกลูกเล่นหนึ่ง กดปุ่มลัดเดิมซ้ำ ๆ ขนาดหน้าต่างจะวนไปหลายขนาด เว็บทางการเขียนไว้ว่า "repeat shortcuts to cycle through window sizes"

คำสั่งแบ่ง 3 ส่วนของจอ (first third, center third, last third และแบบ 2 ใน 3) ก็มีในแอปเหมือนกัน แต่ผมหาไม่เจอว่าปุ่มตั้งต้นคืออะไร ติดตั้งแล้วเปิดดูในแท็บ Shortcuts ได้ครับ

</div>
<figure class="split-fig"><img src="/media/posts/news/rectangle-macos-app-review/igv-2.jpg" width="1600" height="1705" loading="lazy" alt="อินโฟกราฟิกปุ่มลัดหลักของ Rectangle ตามภาพจากเว็บทางการ กด Control + Option ค้างไว้ แล้วตามด้วย ซ้าย Control Option ลูกศรซ้าย ขวา Control Option ลูกศรขวา บน Control Option ลูกศรขึ้น ล่าง Control Option ลูกศรลง มุมซ้ายบน U มุมขวาบน I มุมซ้ายล่าง J มุมขวาล่าง K เต็มจอ Return ขยายเต็มความสูง Shift ลูกศรขึ้น ใหญ่ขึ้น เครื่องหมายเท่ากับ เล็กลง เครื่องหมายลบ กลางจอ C คืนขนาดเดิม Delete จอถัดไป Control Option Command ลูกศรขวา" /></figure>
</div>

## ลากหน้าต่างไปชนขอบจอ (Snap Areas)

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/rectangle-macos-app-review/img-2.jpg" width="1189" height="1329" loading="lazy" alt="ภาพหน้าต่างตั้งค่า Rectangle แท็บ Snap Areas มีสวิตช์ Snap windows by dragging เปิด Restore window size when unsnapped เปิด Provide haptic feedback ปิด Animate footprint ปิด Blur footprint ปิด และแผนผัง Snap Areas มีช่อง Top Left, Maximize, Top Right, Left side, Right side, Bottom Left, Thirds และ Bottom Right" /></div><figcaption><span class="news-fig__credit">ภาพ: Rectangle (Ryan Hanson) · <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a></span></figcaption></figure>
<div class="prose">

ไม่อยากจำปุ่ม ก็ลากหน้าต่างไปชนขอบจอแทนได้ครับ พอเมาส์ถึงขอบ จะมีกรอบขึ้นมาบอกว่าหน้าต่างจะไปอยู่ตรงไหน ปล่อยเมาส์ หน้าต่างก็เข้าที่ (ตามที่หน้า GitHub อธิบาย)

ในภาพคือแท็บ Snap Areas ที่ใช้ตั้งเรื่องนี้

<div class="spec-list">
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-display" /></svg><div><b>Snap windows by dragging</b>สวิตช์หลักของการลากชนขอบ เปิดอยู่เป็นค่าเริ่มต้น</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-expand" /></svg><div><b>Restore window size when unsnapped</b>ลากหน้าต่างออกจากขอบแล้ว ขนาดกลับไปเท่าเดิม</div></div>
<div class="spec-row"><svg class="icon spec-icon" aria-hidden="true"><use href="#icon-shapes" /></svg><div><b>Provide haptic feedback, Animate footprint และ Blur footprint</b>ตัวเลือกเสริม ในภาพปิดอยู่ทั้งหมด</div></div>
</div>

ใครชอบความเนียน เปิด Animate windows ที่ Behavior → Extras หน้าต่างจะย่อขยายแบบมีอนิเมชัน หรือเปิด Blur footprint ที่ Snap Areas ให้กรอบตัวอย่างเบลอ ทั้งสองอย่างปิดเป็นค่าเริ่มต้น ผู้พัฒนาบอกด้วยว่าอนิเมชันยังเป็นฟีเจอร์ทดลอง บางกรณีอาจมีปัญหาครับ

</div>
</div>

| มุมจอ | หนึ่งในสี่ของจอที่มุมนั้น |
| ขอบซ้ายหรือขวา ใกล้มุมบนหรือล่าง | ครึ่งบนหรือครึ่งล่าง |
| ขอบล่าง ช่วงซ้าย กลาง หรือขวา | หนึ่งในสามของจอส่วนนั้น |
| ขอบล่างช่วงซ้ายหรือขวา แล้วลากต่อไปกลาง | สองในสามแรกหรือสองในสามหลัง |

ไม่ชอบลากชนขอบ ก็เอาติ๊กที่ "Snap windows by dragging" ออกได้ หน้า GitHub บอกว่าผู้ใช้บางคนเจอ Notification Center ค้าง ทางแก้ที่แนะนำก็คือปิดตัวเลือกนี้เหมือนกันครับ

## ตั้งค่าและเทคนิคเสริม

<div class="prose">

ส่วนนี้สำหรับคนที่ใช้ไปสักพักแล้วอยากได้มากขึ้นครับ ข้อมูลมาจากหน้า GitHub ทั้งหมด ผมยังไม่ได้ลองครบทุกข้อ

<div class="news-cards">
<div class="news-card is-ok"><b>จัดหลายหน้าต่างเป็นแถวหรือคอลัมน์</b>ไปที่ Behavior → Extras เปิด Show Extra shortcuts in menu จะเห็น Rows กับ Columns ในเมนู Tiling จากนั้นเข้า Shortcuts กดขยาย ⋯ เลือก Extra แล้วตั้งปุ่มให้ Tile in Rows กับ Tile in Columns กดซ้ำจะวนไปหลายรูปแบบ จำนวนหน้าต่างสูงสุดต่อแถวหรือคอลัมน์ตั้งได้ ค่าเริ่มต้นคือ 3</div>
<div class="news-card is-ok"><b>วนดูหน้าต่างที่ซ้อนกัน</b>วางหลายหน้าต่างไว้ที่เดียวกัน เช่น ครึ่งซ้าย จะเห็นแค่อันบนสุด ไปที่ Behavior → Stacked Windows ตั้งปุ่มให้ Cycle stacked windows แล้วกดสลับหน้าต่างในกองได้</div>
<div class="news-card is-ok"><b>ปุ่มเมาส์เป็นปุ่มลัด</b>คลิกช่องปุ่มลัดในหน้าตั้งค่า แล้วกดปุ่มกลางหรือปุ่มข้างของเมาส์ (คลิกซ้ายกับคลิกขวาตั้งไม่ได้) ปุ่มข้างใช้คู่กับ Cycle stacked windows ได้ดี</div>
<div class="news-card is-ok"><b>ข้ามบางแอป (Ignore app)</b>แอปไหนใช้ปุ่มลัดชนกับ Rectangle ให้เปิดแอปนั้นไว้หน้าสุด แล้วเลือก Ignore app จากเมนู Rectangle ปุ่มลัดของ Rectangle จะหยุดทำงานเฉพาะตอนที่แอปนั้นอยู่หน้าสุด</div>
<div class="news-card is-ok"><b>สั่งผ่าน URL หรือสคริปต์</b>เปิดลิงก์รูปแบบ <code>rectangle://execute-action?name=left-half</code> ก็สั่งคำสั่งได้ จากเทอร์มินัลใช้ <code>open -g "rectangle://execute-action?name=left-half"</code> รายชื่อคำสั่งทั้งหมดอยู่ในหน้า GitHub</div>
<div class="news-card is-ok"><b>ย้ายค่าตั้งค่าไปเครื่องอื่น</b>แท็บ App Settings มีปุ่มนำเข้าและส่งออกค่าเป็นไฟล์ JSON</div>
<div class="news-card is-ok"><b>เปิดล็อกดูการทำงาน</b>กด Option ค้างไว้ตอนเปิดเมนู Rectangle แล้วเลือก View Logging จะเห็นว่าแอปคำนวณตำแหน่งยังไง ช่วยได้เวลาหาว่าทำไมหน้าต่างไม่ขยับ</div>

## ข้อจำกัดที่หน้า GitHub บอกไว้

<div class="prose">

ข้อจำกัดเหล่านี้ผู้พัฒนาเขียนไว้เองในหน้า GitHub ครับ รู้ไว้ก่อน จะได้ไม่งงตอนเจอ

<div class="news-cards">
<div class="news-card is-warn"><b>ย้ายไป Desktop/Space อื่นไม่ได้</b>เพราะ Apple ไม่เปิด API สาธารณะ (ช่องทางให้แอปอื่นสั่งระบบ) สำหรับเรื่องนี้ รุ่น Pro มีคำสั่งไป Space ถัดไปหรือก่อนหน้า แต่ยังไม่มีแผนใส่ใน Rectangle ฟรี</div>
<div class="news-card is-warn"><b>หน้าต่างซ้อนกันเวลาแบ่ง 3 ส่วน</b>บางแอปกำหนดขนาดเล็กสุดไว้ใหญ่กว่าที่ขอ Rectangle จะเก็บหน้าต่างไว้ในจอ แล้วขึ้นข้อความ "Minimum window size reached" เจอแบบนี้ให้ใช้ขนาดใหญ่ขึ้น เช่น ครึ่งจอ</div>
<div class="news-card is-warn"><b>iTerm2 ขนาดเพี้ยนนิดหน่อย</b>เพราะ iTerm2 ปรับขนาดเป็นช่วง ๆ ตามความกว้างตัวอักษร หน้า GitHub มีคำสั่งปิดพฤติกรรมนี้ไว้ให้</div>
<div class="news-card is-warn"><b>ติดตั้งผ่าน Homebrew แล้วค่าตั้งค่าหายหลังรีสตาร์ต</b>ให้ถอนด้วย <code>brew uninstall --zap rectangle</code> แล้วติดตั้งใหม่ตามที่หน้า GitHub แนะนำ</div>

## Rectangle Pro เป็นแอปแยก

<div class="prose">

เห็นชื่อ <a href="https://rectangleapp.com/pro" rel="noopener">Rectangle Pro</a> แล้วอย่าเพิ่งสับสนครับ หน้า GitHub บอกว่า Pro สร้างต่อยอดจาก Rectangle แต่เป็นแอปแยกต่างหาก เว็บทางการให้ลองใช้ฟรี 10 วันก่อนซื้อ

ของที่ Pro เพิ่มมา เช่น สร้างขนาดและตำแหน่งหน้าต่างเอง ซิงก์ค่าตั้งค่าผ่าน iCloud และจัดหลายแอปเป็นเวิร์กสเปซด้วยปุ่มเดียว

ราคาผมไม่ได้ใส่ไว้ เพราะตอนเปิดหน้าเว็บ ราคาไม่ได้อยู่ในข้อความที่อ่านได้ และผมเองก็ไม่ได้ลองใช้ Pro ครับ

อีกเรื่อง แถบบนสุดของเว็บทางการขึ้นว่า "Multitouch now includes all of Rectangle Pro!" Multitouch เป็นอีกแอปของผู้พัฒนาคนเดียวกัน ใครสนใจรุ่นเสียเงิน เทียบจากหน้าทางการก่อนซื้อครับ ส่วน Rectangle ตัวฟรีที่แนะนำในข่าวนี้ใช้งานได้ตามปกติ

## ใครควรใช้

<div class="prose">

ผมว่าเหมาะกับคนที่เปิดหลายหน้าต่างพร้อมกันเป็นประจำ เช่น เขียนโค้ดคู่กับเอกสาร ดูวิดีโอคู่กับจดโน้ต หรือใช้จอใหญ่ ต่อหลายจอ แล้วอยากจัดหน้าต่างให้เป็นระเบียบโดยไม่ต้องลาก คนที่ย้ายมาจาก Windows แล้วคิดถึงการลากหน้าต่างชนขอบจอ ก็ได้แบบเดียวกันบน Mac แถมเป็นแอปฟรีที่เปิดซอร์ส ใครอยากตรวจโค้ดก็ทำได้
