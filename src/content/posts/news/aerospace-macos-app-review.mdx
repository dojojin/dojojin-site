## AeroSpace คืออะไร

<div class="prose">

AeroSpace เป็นโปรแกรมจัดการหน้าต่างแบบ **tiling window manager** สำหรับ macOS ที่ได้แรงบันดาลใจจาก `i3` บน Linux ครับ

ถ้าเคยใช้แอปอย่าง Rectangle มาก่อน ตัวนั้นคือเราต้องกดปุ่มลัดสั่งย้ายหน้าต่างทีละอัน แต่แนวคิดของ tiling แบบ AeroSpace คือพอเปิดหน้าต่างใหม่ ระบบจะจัดแบ่งพื้นที่หน้าจอให้เป็นช่องต่อกันเป็นต้นไม้ (tree layout) อัตโนมัติ ไม่ซ้อนทับกัน และควบคุมทุกอย่างด้วยคีย์บอร์ดเป็นหลัก

ที่สำคัญคือ AeroSpace ใช้ระบบ workspace จำลองของตัวเองแทน macOS Spaces ปกติ เลยสลับหน้าต่างข้าม workspace ได้ทันทีแบบไม่มีแอนิเมชันหน่วง และ **ไม่ต้องปิด System Integrity Protection (SIP)** เหมือนบางตัวในสายเดียวกันครับ

</div>

</section>

## วิธีทำงาน ปุ่มลัด และไฟล์ตั้งค่า

<div class="split">
<div class="prose">

ในภาพแสดงโครงสร้างการจัดหน้าต่างแบบแบ่งช่อง (tree layout) ของ AeroSpace ครับ ตัวแอปเก็บการตั้งค่าไว้ในไฟล์ข้อความธรรมดา `~/.aerospace.toml` (หรือ `~/.config/aerospace/aerospace.toml`) ทำให้เอาขึ้น Git เพื่อซิงก์ข้ามเครื่อง Mac หลายเครื่องได้ง่ายมาก

<ol class="news-steps">
<li><b>ติดตั้งผ่าน Homebrew</b>รัน <code>brew install --cask nikitabobko/tap/aerospace</code> (วิธีนี้จะจัดการอัปเดตและล้าง quarantine ให้อัตโนมัติ)</li>
<li><b>เปิดสิทธิ์ Accessibility</b>เป็นแอปจัดหน้าต่าง ถ้า macOS ขอสิทธิ์ ให้อนุญาต <code>AeroSpace.app</code> ใน System Settings → Privacy & Security → Accessibility</li>
<li><b>คัดลอกไฟล์ config เริ่มต้น</b>คัดลอก <code>default-config.toml</code> จากในแอปมาวางที่ <code>~/.aerospace.toml</code> แล้วใช้งานได้ทันที</li>
</ol>

## ข้อควรรู้ก่อนใช้ (Public Beta)

<div class="prose">

ก่อนติดตั้งมี 2 เรื่องที่ผู้พัฒนาบอกไว้ชัดบน GitHub ครับ

<div class="news-cards">
<div class="news-card is-warn"><b>ยังเป็น Public Beta (v0.21.3-Beta)</b>ฟีเจอร์และรูปแบบคำสั่งในไฟล์ config อาจมีการปรับเปลี่ยนได้ในอนาคต เหมาะกับ power user หรือสาย dev ที่คุ้นกับไฟล์ config และคีย์บอร์ด</div>
<div class="news-card is-warn"><b>ไม่ได้ผ่าน Apple Notarization</b>ถ้าดาวน์โหลดไฟล์ zip จาก GitHub มาแตกเอง macOS อาจขึ้นเตือนความปลอดภัย ต้องล้าง quarantine ด้วย <code>xattr -d com.apple.quarantine /Applications/AeroSpace.app</code> หรือติดตั้งผ่าน Homebrew cask แทน</div>
