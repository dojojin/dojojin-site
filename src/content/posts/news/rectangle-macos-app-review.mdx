## Rectangle คืออะไร

<div class="split">
<div class="prose">

Rectangle คือแอปจัดหน้าต่างสำหรับ macOS ครับ หน้า GitHub บอกว่าสร้างโดยอิงจากแอป Spectacle

เว็บทางการ rectangleapp.com สรุปไว้สั้น ๆ ว่า "Move and resize windows in macOS using keyboard shortcuts or snap areas" แปลง่าย ๆ คือ ย้ายและปรับขนาดหน้าต่างด้วยปุ่มลัด หรือลากไปวางที่ขอบจอ

ผมว่ามันแก้ปัญหาอยู่เรื่องเดียว แต่แก้ได้ดีครับ ปกติบน macOS เราต้องลากขอบหน้าต่างเอง Rectangle ย่อให้เหลือกดปุ่มเดียว เช่น เบราว์เซอร์ไว้ครึ่งซ้าย โน้ตไว้ครึ่งขวา ไม่ถึงวินาทีก็เสร็จ

เว็บทางการยังบอกว่า Rectangle ใช้แทน Spectacle ได้เกือบสมบูรณ์ เปิดแอปครั้งแรกเลือกชุดปุ่มลัดของ Spectacle ได้เลย ใครเคยใช้ Spectacle มาก่อนก็ไม่ต้องจำปุ่มใหม่

</div>

## ราคา ไลเซนส์ และรุ่นล่าสุด

<div class="prose">

Rectangle ใช้ฟรี และเป็นโอเพนซอร์สครับ

- ไฟล์ LICENSE ในหน้า GitHub เป็น MIT License
- เว็บทางการเขียนว่า "Free and Open Source"
- ใครอยากสนับสนุนผู้พัฒนา มีปุ่ม Donate กับ Sponsor on GitHub ให้กด

รุ่นล่าสุดบน GitHub คือ **v2.0.4** ประกาศวันที่ 20 ตุลาคม 2569 (ตามเวลา UTC ของ GitHub) บันทึกรุ่น (release notes) มีของใหม่หลายข้อ ผมเลือกมาเฉพาะที่คนใช้ทั่วไปน่าจะเห็นชัด

- ตั้งปุ่มเมาส์เป็นปุ่มลัดของคำสั่งหน้าต่างได้ เช่น ปุ่มข้างเมาส์
- มีตัวเลือกให้หน้าต่างสแนปก่อนถึงขอบนอกของจอ
- เพิ่มคำสั่งแบ่งหน้าต่างเป็น 1 ใน 6 ส่วนแบบสูงเต็มจอ
- ตัวเลือกกดคำสั่งซ้ำแล้วสลับไปอีกฝั่ง
- เพิ่มภาษาเปอร์เซีย ยูเครน และเติมคำแปลภาษาจีนตัวย่อ กับโปรตุเกสบราซิลให้ครบ

**ระบบที่ใช้ได้:** รุ่นล่าสุดต้องใช้ macOS 14 ขึ้นไป ถ้าเครื่องเก่ากว่านั้น

- macOS 10.15 ถึง 13 โหลดรุ่น v1.100
- macOS 10.13 หรือ 10.14 ใช้ v0.73

ทั้งสองรุ่นมีลิงก์อยู่ในหน้า GitHub ครับ

## วิธีติดตั้ง

<div class="prose">

หน้า GitHub บอกไว้ 2 วิธีครับ

1. **โหลดไฟล์ DMG** จากเว็บ <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a> หรือหน้า <a href="https://github.com/rxhanson/Rectangle/releases" rel="noopener">Releases บน GitHub</a> เปิดไฟล์ แล้วลากแอปไปไว้ในโฟลเดอร์ Applications
2. **Homebrew** เปิดแอป Terminal แล้วพิมพ์ `brew install --cask rectangle`

รุ่น 2.0.4 มีไฟล์ให้โหลด 3 แบบ คือ .dmg, .pkg และ .zip ผมแนะนำ .dmg ตามที่หน้าเว็บบอกครับ

**ถอนการติดตั้ง:** ปิดแอป แล้วลากไปถังขยะ หน้า GitHub บอกเพิ่มว่า

- อยากล้างค่าตั้งค่าด้วย ให้พิมพ์ `defaults delete com.knollsoft.Rectangle`
- ถ้าติดตั้งผ่าน Homebrew ให้ใช้ `brew uninstall --zap rectangle`

ขั้นตอนถอนนี้ผมยังไม่ได้ลองเองนะครับ

</div>

</section>

## เปิดครั้งแรกและให้สิทธิ์ Accessibility

<div class="prose">

Rectangle ต้องคุมหน้าต่างของแอปอื่น เลยต้องได้สิทธิ์ Accessibility (สิทธิ์ช่วยการเข้าถึง ที่ macOS ใช้คุมว่าแอปไหนสั่งแอปอื่นได้) ก่อนครับ หน้า GitHub เขียนไว้ในส่วนแก้ปัญหาว่า ตอนเปิดแอปให้เปิดสิทธิ์ตามที่ระบบถาม ขั้นตอนคือ

1. เปิด Rectangle ครั้งแรก
2. เลือกชุดปุ่มลัด ถ้าเคยใช้ Spectacle เลือกชุดของ Spectacle ได้ตามที่หน้าเว็บบอก
3. เมื่อ macOS ถาม ให้ไปที่ System Settings แล้วเข้า Privacy & Security → Accessibility
4. เปิดสวิตช์ของ Rectangle เป็น ON

ถ้าทำแล้วหน้าต่างยังไม่ขยับ หน้า GitHub แนะนำให้ล็อกแล้วปลดล็อกเครื่อง อัปเดต macOS และรีสตาร์ตเครื่อง

ถ้ายังไม่หาย ให้รีเซ็ตสิทธิ์ เลือกได้ 2 ทาง

- พิมพ์คำสั่ง `tccutil reset All com.knollsoft.Rectangle`
- หรือเข้า Accessibility ปิดสวิตช์ของ Rectangle ก่อน แล้วกดปุ่มลบ (-) รีสตาร์ตเครื่อง และเปิดแอปให้ขอสิทธิ์ใหม่

ทางที่สอง ลำดับ "ปิดก่อน ลบทีหลัง" สำคัญครับ หน้า GitHub เน้นไว้

</div>

</section>

## ปุ่มลัด: กดทีเดียวหน้าต่างไปอยู่ที่ที่ต้องการ

<div class="split">
<figure class="news-fig news-fig--tall news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/rectangle-macos-app-review/img-1.jpg" width="1025" height="1415" loading="lazy" alt="ภาพหน้าต่างตั้งค่า Rectangle แท็บ Shortcuts รายการ Left, Right, Center, Top, Bottom, Top Left, Top Right, Bottom Left, Bottom Right, Maximize, Almost Maximize, Maximize Height, Larger, Smaller, Move to Center, Restore, Next Display, Previous Display พร้อมปุ่มลัดเช่น Control Option ลูกศรซ้าย" /></div><figcaption><span class="news-fig__credit">ภาพ: Rectangle (Ryan Hanson) · <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a></span></figcaption></figure>
<div class="prose">

ในภาพคือแท็บ Shortcuts ในหน้าตั้งค่า (ภาพจากเว็บทางการ) แต่ละแถวคือคำสั่งหนึ่งอย่าง มีไอคอนบอกว่าหน้าต่างจะไปอยู่ตรงไหน และมีช่องปุ่มลัดอยู่ทางขวา

อยากเปลี่ยนปุ่ม ก็คลิกที่ช่อง แล้วกดปุ่มใหม่ได้เลยครับ ช่องไหนเขียนว่า Record Shortcut แปลว่าคำสั่งนั้นยังไม่มีปุ่ม

คำสั่งในภาพแบ่งเป็นกลุ่มแบบนี้

- **ครึ่งจอ:** Left, Right, Top, Bottom และ Center
- **มุมจอ:** Top Left, Top Right, Bottom Left, Bottom Right
- **ขนาด:** Maximize, Almost Maximize, Maximize Height, Larger, Smaller, Move to Center, Restore
- **หลายจอ:** Next Display, Previous Display ย้ายหน้าต่างไปจอถัดไปหรือจอก่อนหน้า

ปุ่มลัดในภาพเป็นค่าที่เห็นบนเว็บทางการ ติดตั้งจริงอาจต่างไปตามชุดที่เลือกตอนเปิดครั้งแรก อันนี้ผมยังไม่ได้ลองบนเครื่องตัวเองครับ

</div>
</div>

<div class="split">
<div class="prose">

ในภาพคือปุ่มหลักที่ผมสรุปเป็นตารางสั้น ๆ ครับ ทุกปุ่มขึ้นต้นด้วย Control + Option (⌃⌥) เหมือนกัน เหลือจำแค่ปุ่มท้าย

- ลูกศร สำหรับครึ่งจอ
- ตัวอักษร U I J K สำหรับ 4 มุม เรียงเป็นสี่เหลี่ยมบนคีย์บอร์ดพอดี

ผมว่าจำง่ายกว่าที่คิดครับ

เว็บทางการยังบอกว่า กดปุ่มลัดเดิมซ้ำ ๆ ขนาดหน้าต่างจะวนไปหลายขนาด ตามที่เขียนว่า "repeat shortcuts to cycle through window sizes"

ส่วนคำสั่งแบ่ง 3 ส่วนของจอ (first third, center third, last third และแบบ 2 ใน 3) ก็อยู่ในรายการคำสั่งของแอปเหมือนกัน แต่ผมไม่เห็นว่าปุ่มตั้งต้นคืออะไร ให้เปิดดูในแท็บ Shortcuts หลังติดตั้งแล้วครับ

</div>

## ลากหน้าต่างไปชนขอบจอ (Snap Areas)

<div class="split">
<figure class="news-fig news-fig--zoom"><div class="news-fig__img"><img src="/media/posts/news/rectangle-macos-app-review/img-2.jpg" width="1025" height="1165" loading="lazy" alt="ภาพหน้าต่างตั้งค่า Rectangle แท็บ Snap Areas มีสวิตช์ Snap windows by dragging เปิด Restore window size when unsnapped เปิด Provide haptic feedback ปิด Animate footprint ปิด Blur footprint ปิด และแผนผัง Snap Areas มีช่อง Top Left, Maximize, Top Right, Left side, Right side, Bottom Left, Thirds และ Bottom Right" /></div><figcaption><span class="news-fig__credit">ภาพ: Rectangle (Ryan Hanson) · <a href="https://rectangleapp.com" rel="noopener">rectangleapp.com</a></span></figcaption></figure>
<div class="prose">

ไม่อยากจำปุ่ม ก็ลากหน้าต่างไปที่ขอบจอแทนได้ครับ หน้า GitHub อธิบายว่า พอเมาส์ถึงขอบ จะมีกรอบสีบอกว่าหน้าต่างจะไปอยู่ตรงไหน ปล่อยเมาส์ หน้าต่างก็เข้าที่

ในภาพคือแท็บ Snap Areas

- **Snap windows by dragging** สวิตช์แรก เปิดอยู่เป็นค่าเริ่มต้น
- **Restore window size when unsnapped** สวิตช์ที่สอง ดึงหน้าต่างออกจากขอบแล้ว ขนาดกลับไปเท่าเดิม
- **Provide haptic feedback, Animate footprint และ Blur footprint** เป็นตัวเลือกเสริม ในภาพปิดอยู่

ใครชอบความเนียน หน้า GitHub บอกให้เปิด Animate windows ที่ Behavior → Extras หน้าต่างจะย่อขยายแบบมีอนิเมชัน หรือเปิด Blur footprint ที่ Snap Areas ให้กรอบตัวอย่างเบลอ ทั้งสองอย่างปิดเป็นค่าเริ่มต้น และผู้พัฒนาบอกว่าอนิเมชันยังเป็นฟีเจอร์ทดลอง บางกรณีอาจมีปัญหา

</div>
</div>

<div class="prose">

ลากไปแต่ละจุดได้ผลตามตารางนี้ครับ (จากหน้า GitHub)

| ลากไปที่ | ผลที่ได้ |
|---|---|
| ขอบซ้ายหรือขวา | ครึ่งจอซ้ายหรือขวา |
| ขอบบน | เต็มจอ |
| มุมจอ | หนึ่งในสี่ของจอที่มุมนั้น |
| ขอบซ้ายหรือขวา ใกล้มุมบนหรือล่าง | ครึ่งบนหรือครึ่งล่าง |
| ขอบล่าง ช่วงซ้าย กลาง หรือขวา | หนึ่งในสามของจอส่วนนั้น |
| ขอบล่างช่วงซ้ายหรือขวา แล้วลากต่อไปกลาง | สองในสามแรกหรือสองในสามหลัง |

ไม่ชอบฟีเจอร์ลากชน ก็เอาติ๊กที่ "Snap windows by dragging" ออกได้ หน้า GitHub บอกด้วยว่า ผู้ใช้บางส่วนเจอ Notification Center ค้าง วิธีที่แนะนำก็คือปิดตัวเลือกนี้ครับ

## ตั้งค่าและเทคนิคเสริม

<div class="prose">

ข้อมูลส่วนนี้มาจากหน้า GitHub ทั้งหมด ผมยังไม่ได้ลองครบทุกข้อครับ

- **จัดหลายหน้าต่างเป็นแถวหรือคอลัมน์:** ที่ Behavior → Extras เปิด Show Extra shortcuts in menu จะเห็น Rows กับ Columns ในเมนู Tiling จากนั้นไปที่ Shortcuts กดขยาย ⋯ แล้วเลือก Extra เพื่อตั้งปุ่มให้ Tile in Rows และ Tile in Columns กดซ้ำจะวนไปหลายรูปแบบ ตั้งจำนวนหน้าต่างสูงสุดต่อแถวหรือคอลัมน์ได้ ค่าเริ่มต้นคือ 3
- **วนดูหน้าต่างที่ซ้อนกัน:** สแนปหลายหน้าต่างไว้ที่เดียวกัน เช่น ครึ่งซ้าย จะเห็นแค่หน้าต่างบนสุด ไปที่ Behavior → Stacked Windows ตั้งปุ่มให้ Cycle stacked windows แล้วกดสลับหน้าต่างในกองได้
- **ปุ่มเมาส์เป็นปุ่มลัด:** คลิกช่องปุ่มลัดในหน้าตั้งค่า แล้วกดปุ่มกลางหรือปุ่มข้างของเมาส์ (คลิกซ้าย คลิกขวา ตั้งไม่ได้) ปุ่มข้างใช้คู่กับ Cycle stacked windows ได้ดี
- **ข้ามบางแอป (Ignore app):** แอปไหนใช้ปุ่มลัดซ้ำกับ Rectangle ให้เอาแอปนั้นขึ้นหน้าสุด เปิดเมนู Rectangle แล้วเลือก Ignore app ปุ่มลัดของ Rectangle จะปิดเฉพาะตอนที่แอปนั้นอยู่หน้าสุด
- **สั่งผ่าน URL หรือสคริปต์:** เปิดลิงก์รูปแบบ `rectangle://execute-action?name=left-half` ก็สั่งคำสั่งได้ จากเทอร์มินัลใช้ `open -g "rectangle://execute-action?name=left-half"` รายชื่อคำสั่งทั้งหมดอยู่ในหน้า GitHub
- **ย้ายค่าตั้งค่าไปเครื่องอื่น:** แท็บ App Settings มีปุ่มนำเข้าและส่งออกค่าเป็นไฟล์ JSON
- **เปิดล็อกดูการทำงาน:** กดปุ่ม Option ค้างตอนเปิดเมนู Rectangle แล้วเลือก View Logging จะเห็นว่าแอปคำนวณตำแหน่งยังไง ช่วยได้เวลาหาสาเหตุที่หน้าต่างไม่ขยับ

</div>

</section>

## ข้อจำกัดที่หน้า GitHub บอกไว้

<div class="prose">

- **ย้ายไป Desktop/Space อื่นไม่ได้:** Apple ไม่เปิด API สาธารณะ (ช่องทางให้แอปอื่นสั่งระบบ) สำหรับเรื่องนี้ หน้า GitHub บอกว่ารุ่น Pro มีคำสั่งไป Space ถัดไปหรือก่อนหน้า แต่ยังไม่มีแผนใส่ใน Rectangle ฟรี
- **หน้าต่างซ้อนกันเวลาแบ่ง 3 ส่วน:** บางแอปตั้งขนาดหน้าต่างเล็กสุดไว้ใหญ่กว่าที่ขอ Rectangle จะเก็บหน้าต่างไว้ในจอ และขึ้นข้อความ "Minimum window size reached" เจอแบบนี้ให้ใช้ขนาดใหญ่ขึ้น เช่น ครึ่งจอ
- **iTerm2 ขนาดเพี้ยนนิดหน่อย:** เพราะ iTerm2 ปรับขนาดเป็นช่วง ๆ ตามความกว้างตัวอักษร หน้า GitHub มีคำสั่งปิดพฤติกรรมนี้ให้
- **ติดตั้งผ่าน Homebrew แล้วค่าตั้งค่าไม่อยู่หลังรีสตาร์ต:** ให้ถอนด้วย `brew uninstall --zap rectangle` แล้วติดตั้งใหม่ตามที่หน้า GitHub แนะนำ

</div>

</section>

## Rectangle Pro เป็นแอปแยก

<div class="prose">

หน้า GitHub บอกว่า <a href="https://rectangleapp.com/pro" rel="noopener">Rectangle Pro</a> สร้างต่อยอดจาก Rectangle และเป็นแอปแยกต่างหาก เว็บทางการเขียนว่าลองใช้ฟรี 10 วันแล้วค่อยซื้อ

สิ่งที่ Pro เพิ่มมา เช่น

- สร้างขนาดและตำแหน่งหน้าต่างเอง
- ซิงก์ค่าตั้งค่าผ่าน iCloud
- จัดหลายแอปเป็นเวิร์กสเปซด้วยปุ่มเดียว

ผมไม่ได้ใส่ราคา เพราะตอนเปิดหน้าเว็บ ราคาไม่ได้อยู่ในข้อความที่อ่านได้ และผมเองก็ไม่ได้ลองใช้ Pro ครับ

ข้อสังเกตอีกอย่าง เว็บทางการขึ้นแถบบนสุดว่า "Multitouch now includes all of Rectangle Pro!" ซึ่ง Multitouch เป็นอีกแอปของผู้พัฒนาคนเดียวกัน ใครสนใจรุ่นเสียเงิน ลองเทียบจากหน้าทางการก่อนซื้อครับ ส่วน Rectangle รุ่นฟรีที่แนะนำในข่าวนี้ใช้งานได้ตามปกติ

</div>

## ใครควรใช้

<div class="prose">

- คนที่เปิดหลายหน้าต่างพร้อมกัน เช่น เขียนโค้ดคู่กับเอกสาร หรือดูวิดีโอคู่กับจดโน้ต
- คนที่ใช้จอใหญ่หรือต่อหลายจอ และอยากจัดหน้าต่างให้เป็นระเบียบโดยไม่ต้องลาก
- คนที่ย้ายมาจาก Windows ที่ลากหน้าต่างไปชนขอบจอแล้วย่อได้ อยากได้แบบเดียวกันบน Mac
- คนที่อยากได้แอปฟรีที่เปิดซอร์ส ตรวจสอบโค้ดได้

ข้อควรรู้มี 2 อย่าง รุ่นล่าสุดต้องใช้ macOS 14 ขึ้นไป และต้องให้สิทธิ์ Accessibility ก่อนใช้ครับ
