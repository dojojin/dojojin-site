## WizTree คืออะไร และทำไมถึงเร็วมาก

<div class="split">
<div class="prose">

WizTree ของ Antibody Software เป็นโปรแกรมดูการใช้พื้นที่ดิสก์ครับ สำหรับ Windows จุดที่ทำให้สแกนเร็วคือการอ่าน Master File Table หรือ MFT ซึ่งเป็นตารางข้อมูลไฟล์ของระบบ NTFS โดยตรง แทนการเดินอ่านทุกโฟลเดอร์ตามปกติ

วิธีนี้ต้องใช้สิทธิ์ผู้ดูแลระบบ และไม่ได้ใช้กับทุกกรณีครับ ถ้าไดรฟ์ไม่ใช่ NTFS หรือไม่มีสิทธิ์ดังกล่าว โปรแกรมจะกลับไปอ่านผ่านระบบ Windows ส่วนไดรฟ์เครือข่ายก็อ่าน MFT จากระยะไกลแบบเดียวกันไม่ได้ จึงไม่ควรคาดว่าเวลาในการสแกนจะเท่ากันทุกไดรฟ์

ตอนนี้มีรุ่นทางการแยกชื่อ WizTreeMac สำหรับ macOS และ WizTreeNix สำหรับ Linux แล้วด้วย แต่กลไกการอ่านดิสก์และการขอสิทธิ์ต่างกันตามระบบ ผมจึงไม่ใช้คำอธิบายเรื่อง MFT เหมารวมทั้งสามรุ่นครับ

## ฟีเจอร์เด่นที่ช่วยให้เคลียร์พื้นที่ได้ไว

<div class="prose">

- **Visual Treemap:** แสดงไฟล์และโฟลเดอร์เป็นบล็อกสี่เหลี่ยมขนาดตามสัดส่วนพื้นที่จริง มองปราดเดียวก็เห็นทันทีว่าโฟลเดอร์ไหนหรือไฟล์วิดีโอ/ZIP ก้อนไหนใหญ่ที่สุด
- **ค้นหาไฟล์และส่งออก CSV:** กรองหาไฟล์ตามชื่อ นามสกุล หรือขนาดได้ทันที และส่งออกรายการไฟล์เป็น `.csv` ได้
- **มีรุ่น Portable:** ดาวน์โหลดแบบไม่ต้องติดตั้ง (Portable) ใส่แฟลชไดรฟ์ไปใช้เช็กเครื่องอื่นได้สะดวก

<div class="table-frame">

| หัวข้อ | รายละเอียด |
| --- | --- |
| **รุ่นแยกตามระบบ** | WizTree สำหรับ Windows, WizTreeMac สำหรับ macOS และ WizTreeNix สำหรับ Linux |
| **ราคาและไลเซนส์** | ฟรีสำหรับใช้งานส่วนตัว รุ่น Windows มีไฟล์ Portable แบบไม่ต้องติดตั้ง |
| **กลไกความเร็วใน Windows/NTFS** | อ่าน Master File Table (MFT) โดยตรงเมื่อมีสิทธิ์ผู้ดูแลระบบ ไฟล์แบบ Hard Link ที่ใช้พื้นที่ชุดเดียวกันจะไม่นับซ้ำในยอดรวมโฟลเดอร์ |
| **การแสดงผลและส่งออก** | Visual Treemap สัดส่วนพื้นที่จริง, กรองค้นหาไฟล์, ส่งออก CSV |

</div>

<div class="news-stat"><b>MFT Direct Scan</b>อ่านตารางไฟล์ NTFS โดยตรงได้เมื่อมีสิทธิ์ที่จำเป็น ไม่ใช่ทุกไดรฟ์หรือทุกกรณี</div>
<div class="news-stat"><b>Windows / Mac / Linux</b>เลือกดาวน์โหลดรุ่นให้ตรงระบบและตรวจข้อกำหนดของแต่ละรุ่นก่อน</div>
</div>

ตัวเลข ‘เร็วกว่า 46 เท่า’ ที่เห็นบนเว็บเป็นผลทดสอบของผู้พัฒนาครับ เขาเทียบ WizTree 3.40 กับ WinDirStat 1.1.2.80 บน HDD 25GB ที่ฟอร์แมตเป็น NTFS ส่วน SSD 460GB ในการทดสอบอีกชุดได้ 22 เท่า เป็นคนละเครื่อง คนละไดรฟ์ และคนละรุ่นกับที่เราอาจใช้อยู่ ผมไม่ได้วัดซ้ำ จึงไม่ใช้ตัวเลขนี้รับรองความเร็วของเครื่องคุณ

## อ่านผลแล้วทำอะไรต่อ

<div class="prose">

กล่องใหญ่ใน Treemap แปลว่าไฟล์หรือโฟลเดอร์นั้นใช้พื้นที่มาก ไม่ได้แปลว่าเป็นไฟล์ขยะครับ ผมว่าเริ่มจากดูชื่อและตำแหน่งก่อน ว่าเป็นวิดีโอที่เก็บไว้ ไฟล์สำรอง หรือข้อมูลของโปรแกรมที่ยังใช้อยู่ แล้วค่อยตัดสินใจว่าจะย้าย เก็บ หรือลบ

ขอบเขตของเครื่องมือนี้คือช่วยให้เราเห็นว่า ‘พื้นที่ไปอยู่ตรงไหน’ ส่วนข้อมูลไหนยังจำเป็น คนใช้เครื่องต้องเป็นคนตัดสินใจครับ ไม่ควรสรุปว่าไฟล์ใหญ่ที่สุดคือไฟล์ที่ควรลบก่อนเสมอ
